# A20_Const_0203.h 상세 Spec

## 1. 파일 역할 요약 (1~2 줄)
Smart Nature Wind 공용 상수/타입/구조체 선언 파일로, 전역 구성 루트 객체(`g_A20_config_root`) 및 접근 규약(화이트리스트)을 정의합니다.

## 2. 주요 클래스/구조체/열거형
- **`ST_A20_ConfigRoot_t`**: 전역 보관용 구조체 (시스템, 와이파이, 모션, NVS 스펙, 풍속 사전, 스케줄, 사용자 프로필, 웹 페이지 설정 포인터 포함).
- **`CL_M10_MotionLogic`**: 전방 선언된 클래스 (모션 로직 객체 참조용).

## 3. 주요 함수/메서드 및 동작
- **전역 객체 접근 (`g_A20_config_root`)**: `ST_A20_ConfigRoot_t` 타입의 전역 변수로, 시스템 설정 루트 객체를 제공하며, 특정 화이트리스트 위치(예: `A00_Main_0203.cpp`, `CT10_Ctl_*`) 에서만 직접 접근이 허용됩니다.
- **모션 로직 참조 (`g_M10_motionLogic`)**: `CL_M10_MotionLogic*` 타입의 전역 변수로, 모션 로직 객체를 참조합니다.

## 4. 외부 의존성 / 공유 상태 / 락(Mutex 등) 특이사항
- **외부 의존성**: `ArduinoJson v7.x.x` 사용 (v6 이하 금지), `JsonDocument` 단일 타입만 사용하며, `createNestedArray/Object/containsKey` 함수는 사용하지 않습니다.
- **공유 상태 및 락**: `g_A20_config_root` 접근 시 `s_stateMutex` 보유가 권장되며, `async_tcp` 작업은 반드시 `CL_C10_ConfigManager::getRootSnapshot()` 를 사용해야 합니다.
