```js
html(strings, ...vals) {
    const div = document.createElement('div');
    div.innerHTML = strings.reduce((acc, s, i) => {
        const v = vals[i];
        let safe;
        if (v == null) {
            safe = '';
        } else if (typeof v === 'string') {
            safe = this.escape(v);
        } else if (typeof v === 'number' || typeof v === 'boolean') {
            safe = String(v);
        } else if (v && typeof v === 'object' && typeof v.__raw === 'string') {
            // 명시적 opt-in (raw()로 감싼 값만 HTML 삽입 허용)
            safe = v.__raw;
        } else {
            // 배열/객체/Date 등 → 문자열화 후 escape
            safe = this.escape(String(v));
        }
        return acc + s + (i < vals.length ? safe : '');
    }, '').trim();
    return div.firstElementChild;
},

// 안전 HTML 명시 삽입용 헬퍼 (기존 tooltip() 등을 tpl에 그대로 넣을 때 사용)
raw(str) {
    return { __raw: String(str) };
},
```

변경 전

```js

        const hm = getHmFn();

```

변경 후

```js
// 내부 레지스트리 (WeakMap)
const _clocks = new WeakMap();

SNW.TimeUtil = {
    // ...

    /**
     * @returns {number} interval ID (기존 호환)
     * @usage SNW.TimeUtil.stopClock(el) 로 정리
     */
    startClock(el, getHmFn) {
        const T = SNW.TimeUtil;
        T.stopClock(el); // 기존 인터벌 정리 (중복 방지)

        const tick = () => {
            const hm = getHmFn();
            el.textContent = T.clockStr(hm.hour ?? -1, hm.min ?? -1);
        };
        tick();
        const id = setInterval(tick, 1000);
        _clocks.set(el, id);
        return id;
    },

    stopClock(el) {
        const id = _clocks.get(el);
        if (id) { clearInterval(id); _clocks.delete(el); }
    }
};
```

이유: 기존 반환 타입(number) 유지 → 호환성 유지. stopClock(el) 편의 API로 정리 누락 방지. 동일 엘리먼트 중복 시작 시 자동 정리.

```js
/**
 * @param {string} level  'L1'~'L4'
 * @param {object} [opts] { reload?: boolean }  기본 true (하위 호환)
 */
set(level, opts = {}) {
    if (!this.LEVELS.includes(level)) return;
    const changed = (this.current() !== level);
    try { localStorage.setItem(SNW.CFG.LS_KEY.LEVEL, level); } catch {}

    // 이미 적용된 요소 즉시 갱신
    this.applyTo(document);

    // SPA 리스너가 있으면 이벤트로 재구성 (예: 메뉴 재렌더)
    if (changed) {
        document.dispatchEvent(new CustomEvent('snw:levelchange', {
            detail: { level }
        }));
    }

    // 하위 호환: 기본은 리로드. opts.reload=false로 억제 가능
    if (opts.reload !== false) {
        location.reload();
    }
},
```


이유: 기본 동작 유지(호환성 100%), opts.reload=false로 SPA 최적화 경로 제공. snw:levelchange 이벤트는 메뉴·라우트 재검증을 리스너가 처리하도록 위임.

(B-3) z-index 토큰 불일치 — --snw-z-np: 95 vs 실제 1005

· _variables.css 주석: header(50) < nowplaying(95) < fab(990) < bottom-nav(1000) …
· _nowplaying.css: z-index: 1005; (하드코딩)

(B-4) .snw-nowplaying { bottom: ... } 중복 선언

(B-5) .gz 확장자 — 서버 Content-Encoding 전제

```html
<link rel="stylesheet" href="./common_base_0203.css.gz">
<script defer src="./app_core_0203.js.gz"></script>
```

· 파일명이 .gz이지만 브라우저는 MIME으로 판단. 서버가 Content-Encoding: gzip + Content-Type: text/css/application/javascript를 함께 보내지 않으면, 브라우저는 raw gzip 바이트를 CSS/JS로 파싱 시도 → CSS/JS 전체 무효.
· ESP32 등 임베디드 서버에서 정적 서빙 시 흔한 함정. Content-Type: text/css + Content-Encoding: gzip을 명시적으로 설정해야 함.
· 권장: 파일명은 .css/.js로 유지하고 서버가 gzip_static on(nginx) 등으로 Content-Encoding만 붙이는 구성. 또는 .css.gz 파일명 유지 시 서버 라우트에서 강제 헤더 지정.

(B-6) document.write로 70+ defer 스크립트 주입

```js
].forEach(function (src) {
    document.write('<script defer src="' + src + '"><\/script>');
});
```

· 초기 파싱 중 document.write는 동기적으로 DOM에 삽입되어 defer가 정상 동작하지만, PWA 서비스워커 캐싱·Content-Security-Policy 엄격 모드에서는 차단될 수 있음.
· 개발 편의 목적이라면 유지 가능. 다만 CSP에 script-src 'unsafe-inline'이 필요해짐 → 프로덕션 정책과 상충.
· 개선: <script type="module" src="./js/dev-loader.js">로 옮기고, 로더가 import('./js/...') 동적 import하도록 변경.

(B-7) SNW_OFFLINE 판정 — dev/prod 경계 모호

```js
window.SNW_OFFLINE = (location.protocol === 'file:') ||
    location.hostname === 'localhost' ||
    location.hostname === '127.0.0.1' ||
    new URLSearchParams(location.search).has('offline');
```

· localhost 개발 서버에서 항상 오프라인 모드 → 프로덕션 번들 검증 경로 없음.
· 장치(ESP32)의 AP IP 192.168.4.1에서는 정상 온라인 모드. 의도된 동작이지만, 로컬에서 .gz 번들을 테스트할 방법이 없음.
· 권장:

```js
window.SNW_OFFLINE = location.protocol === 'file:' ||
    new URLSearchParams(location.search).has('offline') ||
    (['localhost','127.0.0.1'].includes(location.hostname)
     && !new URLSearchParams(location.search).has('prod'));
```

?prod 쿼리로 로컬에서 프로덕션 번들 강제 테스트 가능.

(B-8) <title data-i18n="app.title"> — 언어 전환 시 갱신 안 됨

I18n.applyTo()는 document를 순회하며 [data-i18n]을 갱신하지만, <title>에 textContent를 넣으면 DOM 트리 내 title 텍스트가 갱신됨 (실제로 동작함). 다만 탭 제목은 갱신되지만 history.pushState로 라우팅되면 다시 원복되는 이슈가 있을 수 있음(문서 루트 title은 유지). 실제 검증 필요.

(B-9) viewport-fit=cover — 상단 노치 대응 누락

```css
.snw-header {
```

7. 구조적 제안 — 오프라인 핸들러 재설계

현재 substring if-체인은 선언 순서에 의존해 이런 shape 오염이 반복 발생합니다. 권장 구조:

```js
const OFFLINE_ROUTES = [
    { test: /^\/api\/v001\/sim\/state$/,   method: 'GET',  get: () => ({ sim: rt.sim || {} }) },
    { test: /^\/api\/v001\/config\/save$/, method: 'POST', get: () => ({ success: true, offline: true }) },
    { test: /^\/api\/v001\/config\/dirty$/,method: 'GET',  get: () => ({ dirty: false }) },
    { test: /^\/api\/v001\/config\/init$/, method: 'POST', get: () => ({ success: true }) },
    { test: /^\/api\/v001\/state$/,        method: 'GET',  get: () => ({ control, sim: rt.sim, runtime }) },
    { test: /^\/api\/v001\/simulation$/,   method: 'GET',  get: () => ({ sim: rt.sim || {} }) },
    { test: /^\/api\/v001\/simulation$/,   method: 'POST',
      set: (b) => { Object.assign(rt.sim, b.sim || b); return { result: 'ok', sim: rt.sim }; } },
    { test: /^\/api\/v001\/session\/(start|pause|resume|stop|current|rule|schedule-override)$/,
      method: '*', set: () => ({ result: 'ok' }) },
    // ...
];

function _offlineFetch(path, opts) {
    const M = (opts.method || 'GET').toUpperCase();
    // 정확 매칭 우선 (line-by-line 순서 의존 제거)
    for (const r of OFFLINE_ROUTES) {
        if (!r.test.test(path)) continue;
        if (r.method !== '*' && r.method !== M) continue;
        return (M === 'GET') ? r.get?.(path, opts) : r.set?.(opts.body, path, opts);
    }
    return { result: 'ok', updated: true };
}
```

이 구조로 바꾸면:

· 경로 우선순위 오염 제거 (/sim/state vs /state, /config/save vs /config)
· method 별 응답 분기 명시
· cache mutation(POST)을 명시적으로 정의
· 위 표의 40여 개 케이스를 테이블화해 관리 가능

📄 040.api.js — 전체 교체본

```javascript
// =========================================================
// 040.api.js — SNW.Api (REST 클라이언트)
// Layer 2 (서비스) — Layer 0~1 참조
//  - 모든 REST 호출은 이 모듈 경유 (fetch 직접 호출 금지)
//  - 타임아웃 / 401 처리 / 에러 파싱 / in-flight dedupe
//  - 업로드 진행률 (XHR)
//  - [P0] 오프라인 라우트 테이블 (선언적, 순서 무관, shape 계약 준수)
// =========================================================
window.SNW = window.SNW || {};
(function (SNW) {
	'use strict';

	const inflight = new Map(); // key → Promise (중복 요청 방지)

	// =====================================================
	// API Key (localStorage)
	// =====================================================
	function getApiKey() {
		try { return localStorage.getItem(SNW.CFG.LS_KEY.API_KEY) || ''; }
		catch { return ''; }
	}

	function setApiKey(k) {
		try {
			if (k) localStorage.setItem(SNW.CFG.LS_KEY.API_KEY, k);
			else localStorage.removeItem(SNW.CFG.LS_KEY.API_KEY);
		} catch { }
	}

	// =====================================================
	// Query string 빌더
	// =====================================================
	function buildQuery(params) {
		if (!params) return '';
		const q = new URLSearchParams();
		for (const [k, v] of Object.entries(params)) {
			if (v != null) q.append(k, v);
		}
		const s = q.toString();
		return s ? `?${s}` : '';
	}

	// =====================================================
	// ApiError
	// =====================================================
	class ApiError extends Error {
		constructor(status, data) {
			super((data && data.error) || `HTTP ${status}`);
			this.name = 'ApiError';
			this.status = status;
			this.data = data;
		}
	}

	// =====================================================
	// [P0] 오프라인 저장소 헬퍼 — SNW.Offline 없이도 안전
	// =====================================================
	function _ensureOfflineStore() {
		SNW.Offline = SNW.Offline || {};
		if (!SNW.Offline._runtime) SNW.Offline._runtime = {};
		if (!SNW.Offline._cache) SNW.Offline._cache = {};
		return { rt: SNW.Offline._runtime, cache: SNW.Offline._cache };
	}
	const _rt = () => _ensureOfflineStore().rt;
	const _cache = () => _ensureOfflineStore().cache;

	/** path에서 query string 제거 — 정규식 `$` 매칭을 위해 */
	function _pathOnly(path) {
		const q = path.indexOf('?');
		return q >= 0 ? path.slice(0, q) : path;
	}

	// =====================================================
	// [P0] 오프라인 라우트 테이블
	// -----------------------------------------------------
	// 규칙:
	//  - `re`는 query string이 제거된 pathOnly에 대해 테스트
	//  - **specific → generic** 순서로 정의해야 함 (/sim/state BEFORE /state)
	//  - `method`는 'GET'|'POST'|'PUT'|'DELETE'|'PATCH'|'*'
	//  - `handle(body, ctx)` — ctx = { path, pathOnly, opts, method }
	//  - GET이면 body=undefined, 그 외는 opts.body
	// =====================================================
	const OFFLINE_ROUTES = [
		// =================== 메타 ===================
		{ re: /\/version$/i, method: 'GET',
			handle: () => ({ fw: 'FW_Ver_2.0.3', offline: true }) },
		{ re: /\/diag$/i, method: 'GET',
			handle: () => ({ heap: 120000, fs_used: 160000, fs_total: 1000000, offline: true }) },

		// =================== System: specific first ===================
		{ re: /\/system\/time\/set$/i, method: 'POST',
			handle: (body) => {
				const c = _cache();
				c.system = Object.assign({}, c.system, { time: body });
				return { result: 'ok', offline: true };
			} },
		{ re: /\/system\/firmware\/check$/i, method: 'GET',
			handle: () => ({ current: '2.0.3', latest: '2.0.3', hasUpdate: false, offline: true }) },
		{ re: /\/system$/i, method: 'GET',
			handle: () => _cache().system || {} },
		{ re: /\/system$/i, method: 'POST',
			handle: (body) => {
				const c = _cache();
				c.system = Object.assign({}, c.system, body || {});
				return { result: 'ok', offline: true };
			} },

		// =================== Sim: /sim/state BEFORE /state ===================
		{ re: /\/sim\/state$/i, method: 'GET',
			handle: () => ({ sim: _rt().sim || {} }) },
		{ re: /\/sim\/chart$/i, method: 'GET',
			handle: () => ({ series: [], offline: true }) },
		{ re: /\/simulation$/i, method: 'GET',
			handle: () => ({ sim: _rt().sim || {} }) },
		{ re: /\/simulation$/i, method: 'POST',
			handle: (body) => {
				const r = _rt();
				r.sim = r.sim || {};
				Object.assign(r.sim, (body && body.sim) || body || {});
				return { result: 'ok', sim: r.sim, offline: true };
			} },

		// =================== State (generic, after /sim/state) ===================
		{ re: /\/state$/i, method: 'GET',
			handle: () => ({
				control: _rt().control || {},
				sim: _rt().sim || {},
				runtime: _rt().runtime || {}
			}) },

		// =================== Session (Stage 5) ===================
		{ re: /\/session\/start$/i, method: 'POST',
			handle: (body) => {
				const r = _rt();
				r.session = {
					active: true,
					type: body && body.type,
					payload: (body && body.payload) || {},
					trigger: body && body.trigger,
					startedAt: Date.now(),
					paused: false
				};
				return { result: 'ok', session: r.session, offline: true };
			} },
		{ re: /\/session\/pause$/i, method: 'POST',
			handle: () => {
				const r = _rt();
				if (r.session) r.session.paused = true;
				return { result: 'ok', offline: true };
			} },
		{ re: /\/session\/resume$/i, method: 'POST',
			handle: () => {
				const r = _rt();
				if (r.session) r.session.paused = false;
				return { result: 'ok', offline: true };
			} },
		{ re: /\/session\/stop$/i, method: 'POST',
			handle: () => {
				_rt().session = { active: false };
				return { result: 'ok', offline: true };
			} },
		{ re: /\/session\/current$/i, method: 'GET',
			handle: () => ({ session: _rt().session || { active: false } }) },
		{ re: /\/session\/rule$/i, method: 'PATCH',
			handle: (body) => {
				_rt().sessionRule = body;
				return { result: 'ok', offline: true };
			} },
		{ re: /\/session\/schedule-override$/i, method: 'POST',
			handle: (body) => {
				_rt().scheduleOverride = !!(body && body.override);
				return { result: 'ok', offline: true };
			} },

		// =================== Control: specific first ===================
		// Timer: GET/POST/DELETE

			handle: () => {
				_rt().timer = { active: false };
				return { success: true, active: false, offline: true };
			} },
		{ re: /\/control\/timer$/i, method: 'POST',
			handle: (body) => {
				const mins = (body && body.minutes) || 30;

					active: true, remainSec: mins * 60, durationMin: mins,
					startedAt: Date.now()

			} },

	// [P0] 오프라인 fetch — 라우트 테이블 기반

	async function _offlineFetch(path, opts = {}) {
		const method = (opts.method || 'GET').toUpperCase();
		const pathOnly = _pathOnly(path);
		const ctx = { path, pathOnly, opts, method };
		const log = (SNW.LogUtil && SNW.LogUtil.debug) || console.debug.bind(console);
		const warn = (SNW.LogUtil && SNW.LogUtil.warn) || console.warn.bind(console);

		for (const route of OFFLINE_ROUTES) {
			if (!route.re.test(pathOnly)) continue;
			if (route.method !== '*' && route.method !== method) continue;
			try {
				const body = method === 'GET' ? undefined : opts.body;
				const result = route.handle(body, ctx);
				log(`[Offline] ${method} ${pathOnly} ✓ ${route.re}`);
				return result;
			} catch (e) {
				warn(`[Offline] handler error ${method} ${pathOnly}`, e);
				throw new ApiError(0, { error: 'offline-handler-error', detail: String(e) });
			}
		}

		warn(`[Offline] unhandled ${method} ${pathOnly} → fallback`);
		return { result: 'ok', updated: true, offline: true, unhandled: true };
	}

	// =====================================================
	// Core fetch (_fetch)
	// =====================================================
	async function _fetch(path, opts = {}) {
		// [P0] 오프라인 판정: 레거시 전역 플래그 + 신규 네임스페이스 모두 인식
		const isOffline = window.SNW_OFFLINE || (SNW.Offline && SNW.Offline.active);
		if (isOffline) {
			return _offlineFetch(path, opts);
		}

		// GET 요청에 대해서만 in-flight dedupe
		const dedupeKey = (opts.method || 'GET') === 'GET' ?
			path + (opts.body ? JSON.stringify(opts.body) : '') :
			null;

		if (dedupeKey && inflight.has(dedupeKey)) {
			return inflight.get(dedupeKey);
		}

		const promise = (async () => {
			const controller = new AbortController();
			const timeoutMs = opts.timeoutMs || SNW.CFG.TIMEOUT_MS.DEFAULT;
			const timer = setTimeout(() => controller.abort(), timeoutMs);

			const headers = {
				'X-API-Key': getApiKey(),
				...(opts.body ? { 'Content-Type': 'application/json; charset=utf-8' } : {}),
				...(opts.headers || {})
			};

			try {
				const res = await fetch(path, {
					method: opts.method || 'GET',
					headers,
					body: opts.body ? JSON.stringify(opts.body) : undefined,
					signal: controller.signal,
					credentials: 'omit'
				});
				clearTimeout(timer);

				// 401 즉시 처리
				if (res.status === SNW.C.HTTP.UNAUTHORIZED) {
					SNW.LogUtil.warn(`[API] 401 ${path}`);
					throw new ApiError(401, { error: 'unauthorized' });
				}

				// 응답 파싱
				let data = null;
				const ct = res.headers.get('Content-Type') || '';
				if (ct.includes('application/json')) {
					data = await res.json().catch(() => null);
				} else {
					data = await res.text();
				}

				if (!res.ok) {
					const msg = (data && data.error) || `HTTP ${res.status}`;
					throw new ApiError(res.status, { error: msg });
				}

				SNW.LogUtil.debug(`[API] ${opts.method || 'GET'} ${path} → ${res.status}`);
				return data;
			} catch (e) {
				clearTimeout(timer);
				if (e.name === 'AbortError') {
					throw new ApiError(SNW.C.HTTP.TIMEOUT, { error: 'timeout' });
				}
				throw e;
			}
		})();

		if (dedupeKey) {
			inflight.set(dedupeKey, promise);
			promise.finally(() => inflight.delete(dedupeKey));
		}
		return promise;
	}

	// =====================================================
	// Multipart 업로드 (진행률 지원)
	// =====================================================
	function uploadWithProgress(url, formData, onProgress, timeoutMs) {
		return new Promise((resolve, reject) => {
			const xhr = new XMLHttpRequest();
			xhr.open('POST', url);
			xhr.setRequestHeader('X-API-Key', getApiKey());
			xhr.timeout = timeoutMs || SNW.CFG.TIMEOUT_MS.UPLOAD;

			xhr.upload.onprogress = (e) => {
				if (e.lengthComputable && typeof onProgress === 'function') {
					onProgress(e.loaded / e.total);
				}
			};
			xhr.onload = () => {
				let data = null;
				try { data = JSON.parse(xhr.responseText); }
				catch { data = xhr.responseText; }

				if (xhr.status >= 200 && xhr.status < 300) resolve(data);
				else reject(new ApiError(xhr.status, data || { error: xhr.statusText }));
			};
			// [P1] ApiError(0) → TypeError('network') — ErrorHandler의 네트워크 분기 정상 동작
			xhr.onerror = () => reject(new TypeError('network'));
			xhr.ontimeout = () => reject(new ApiError(SNW.C.HTTP.TIMEOUT, { error: 'timeout' }));
			xhr.send(formData);
		});
	}
```

🔴 핵심 발견 1 — 998이 040.api.js의 OFFLINE_ROUTES를 거의 전부 shadowing

998.offline_0203.js의 ensureApi()가 약 90%의 SNW.Api 메서드를 mock으로 재정의합니다. DOMContentLoaded에서 재실행되어 040.api.js의 _fetch 기반 메서드를 덮어씁니다:

```js

    ensureApi();  // ← 040.api.js 메서드 재덮어쓰기
    ...
});
```

주석에도 명시:

P010_bundle_0203.js의 040.api.js가 Object.assign으로 _fetch 기반 메서드를 정의... DOMContentLoaded에서 ensureApi()를 재실행 → 오프라인 mock으로 재덮어씀

실효 관계

메서드 그룹 실제 실행 경로
getState, startSession, overrideFixed, patchSim, gemini, addSchedule, ... (약 50개) 998 mock (OFFLINE_ROUTES 무시됨)

즉, 제가 작성한 OFFLINE_ROUTES는 "미커버 메서드 9개"를 위한 폴백으로만 작동합니다.

✅ 다행히도 데이터는 공유됨

998이 아래처럼 SNW.Offline._cache / _runtime을 정확히 노출하므로, 폴백 경로가 동일한 상태를 읽고 씁니다:

```js
    ...

```

이는 설계상 올바른 통합입니다. mock과 폴백이 한 몸처럼 동작합니다.
