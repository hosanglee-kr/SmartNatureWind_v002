# `A30_LED_0203.h` 상세 Spec

 1. **파일 역할 요약**
   `A30_LED_0203.h` 파일은 ESP32-S3 C++17 임베디드 시스템에서 독립형 RGB LED 제어를 관리하는 클래스입니다. 이 파일은 Arduino와 Adafruit_NeoPixel 라이브러리를 사용하여 RGB LED의 상태를 조절하고 표시합니다.

 2. **주요 클래스 및 함수/메서드**
   - `CL_A30_LED`: 클래스 이름으로, 독립형 RGB LED 제어를 관리하는 클래스입니다.
   - 생성자: `CL_A30_LED(uint8_t p_pin, uint16_t p_num)`: 클래스의 인스턴스를 생성하고 초기화합니다. 파라미터로 LED의 핀 번호와 LED의 개수를 전달받습니다.
   - `begin(uint8_t p_brightness)`: LED 제어를 시작합니다. 파라미터로 LED의 최대 밝도를 전달받습니다.
   - `setBrightness(uint8_t p_brightness)`: LED의 밝도를 설정하고 표시합니다. 파라미터로 새로운 밝도 값을 전달받습니다.
   - `update(uint8_t p_isConnected)`: LED의 상태를 업데이트합니다. 파라미터로 현재 연결 상태 (외부에서 주입)을 전달받습니다.

 3. **외부 의존성**
   - Arduino.h: Arduino 라이브러리를 사용하여 시스템에 필요한 기능을 제공합니다.
   - Adafruit_NeoPixel.h: NeoPixel 라이브러리를 사용하여 RGB LED의 상태를 조절하고 표시합니다.

 4. **특이사항**
   - `_lastLedMs`: 내부 타이머로 현재 점멸 시간을 저장합니다.
   - `_ledState`: 현재 점멸 상태 (On/Off)을 저장합니다.
   - `_pixel`: NeoPixel 객체를 사용하여 RGB LED의 상태를 조절하고 표시합니다.

 5. **메서드 설명**
   - `begin(uint8_t p_brightness)`: LED 제어를 시작합니다. 파라미터로 LED의 최대 밝도를 전달받습니다.
      - `_pixel.setBrightness(p_brightness);`: LED의 밝도를 설정합니다.
      - `_pixel.clear();`: LED의 색상을 지웁니다.
      - `_pixel.show();`: LED의 상태를 표시합니다.
   - `setBrightness(uint8_t p_brightness)`: LED의 밝도를 설정하고 표시합니다. 파라미터로 새로운 밝도 값을 전달받습니다.
      - `_pixel.setBrightness(p_brightness);`: LED의 밝도를 설정합니다.
      - `_pixel.show();`: LED의 상태를 표시합니다.
   - `update(uint8_t p_isConnected)`: LED의 상태를 업데이트합니다. 파라미터로 현재 연결 상태 (외부에서 주입)을 전달받습니다.
      - `if (v_now - _lastLedMs >= v_interval)`: 현재 시간이 타이머 설정 시간보다 크거나 같다면, `_ledState`의 값을 반대로 업데이트합니다.
      - `_pixel.setPixelColor(0, 255, 0);`: LED를 빨초색으로 설정합니다.
      - `_pixel.clear();`: LED의 색상을 지웁니다.
      - `_pixel.show();`: LED의 상태를 표시합니다.

이 클래스는 독립형 RGB LED 제어를 관리하는 라이브러리를 사용하여 시스템에서 RGB LED의 상태를 조절하고 표시하며, 외부에서 주입된 연결 상태에 따라 점멸 색상을 변경합니다.
