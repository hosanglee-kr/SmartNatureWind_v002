# `A00_Main_0203.cpp` 상세 Spec

## 1. 파일 역할 요약
Smart Nature Wind v0203 펌웨어의 **부팅 진입점(`A00_init`)**과 **메인 루프(`A00_run`)**를 구현하며, LittleFS/NVS/Config/Wi-Fi/Time/PWM/Control/Motion/Web/WS/WDT 초기화 순서와 전역 인스턴스 생명주기를 관리합니다.

## 2. 전역 인스턴스 및 접근자
| 심볼 | 타입 / 역할 | 비고 |
|---|---|---|
| `g_M10_motionLogic` | `CL_M10_MotionLogic` | PIR 인체감지 모션 로직 전역 인스턴스 |
| `g_A00_ledController` | `CL_A30_LED` | WS2812B NeoPixel 상태 LED 제어기 |
| `A00_getControl()` | `CL_CT10_ControlManager&` | 중앙 제어 매니저 싱글턴 접근자 |
| `g_A20_config_root` | `ST_A20_ConfigRoot` | 시스템·Wi-Fi·스케줄·프로필 전역 설정 루트 |

## 3. 주요 함수 및 동작

### `void A00_init()`
시스템 부팅 시퀀스를 순차 실행합니다:
1. **파일시스템 마운트**: `LittleFS.begin(true)` (실패 시 포맷 폴백).
2. **설정 로드 및 Null 방어**: `CL_C10_ConfigManager::begin()` 호출. 실패 시 In-memory 폴백 및 Recovery AP 기동. `g_A20_config_root.system` / `wifi`가 `nullptr`이면 `new (std::nothrow)`로 기본값 할당.
3. **LED 유효성 검사**: 핀 번호(0~48) 및 픽셀 수(1~16) 범위 검증 후 `CL_A30_LED` 초기화.
4. **네트워크·시간·하드웨어 초기화**: Wi-Fi(STA/SoftAP) → NTP/TM10 시간 → 25kHz PWM(`CL_P10_PWM`) → ControlManager(`CL_CT10_ControlManager`) → Motion(`CL_M10_MotionLogic`) → AsyncWebServer & WebSocket 브로커 기동.
5. **Watchdog 초기화**: `esp_task_wdt_init(A20_Const::G_A00_WDT_TIMEOUT_SEC, true)` 등록.

### `void A00_run()`
메인 루프(`loop()`)에서 주기적으로 호출됩니다:
1. `esp_task_wdt_reset()`으로 Task WDT 피드.
2. `CL_CT10_ControlManager::consumePendingReload()`를 확인하여 지연된 설정 리로드/재부팅 처리.
3. Control / WebSocket / Motion(`M10`) / Time(`TM10`) 틱(Tick) 순차 실행.

## 4. 외부 의존성 / 공유 상태 / 락 특이사항
- **OOM 방어**: `new (std::nothrow)`를 사용해 메모리 부족 시에도 부팅이 중단되지 않고 Recovery AP로 진입합니다.
- **동시성 경계**: `A00_init()`은 단일 스레드 부팅 컨텍스트에서 실행되며, 이후 태스크 기동 후에는 `CL_CT10_ControlManager`의 위임 플래그(`consumePendingReload()`)를 통해 안전하게 상태를 갱신합니다.
