지금까지 도출된 1차 검토 항목(7건)과 **2차 사용자 관점 UI/UX 개선 사항(11건)** 전체에 대한 통합 구현 방안임. 기존 L1~L4 아키텍처(CT10 FSM, ST_A20_TriggerRule_t, 2폴더 + 3JS/2CSS 청크, 계약 문서 6종)와 충돌 없이 통합되도록 백엔드·프론트엔드·계약 문서 계층별로 구조화함.
### 1. 백엔드 펌웨어 (ESP32-S3 / CT10 / W10) 구현 방안
 * **PIR 시작 직후 오작동 방지 유예 기간 적용 (CT10_Ctl_Basic_0203.cpp)**
   * checkTriggers() 내 3-A. PIR 판정 시 현재 시각과 세션 시작 시각(_session.startedAt)의 경과 시간이 holdMs 미만이면 재실 부재(absent) 판정을 유예함.
   * 구체적 조건식: bool graceActive = (_session.startedAt > 0) && ((now - _session.startedAt) < holdMs);를 추가하고 if (!graceActive && absent)일 때만 CT10_PAUSE_MASK_MOTION 비트를 세트함.
   * 원격 앱 실행이나 수동 버튼 기동 직후 40ms 만에 즉시 ENV_PAUSED로 꺼지는 현상을 원천 차단함.
 * **ENV_PAUSED 강제 수동 재개(Override Resume) 및 조건 일시 유예 (CT10_Ctl_0203.h, CT10_Ctl_Ctl_0203.cpp, W10_Web_Routes_Session_0203.cpp)**
   * ST_CT10_TriggerRuntime_t에 uint32_t pauseBypassUntilMs; 필드를 추가함.
   * POST /api/v001/session/resume 호출 시 현재 상태가 EN_CT10_STATE_ENV_PAUSED이면 triggerRt.pauseBypassUntilMs = millis() + 3600000UL (1시간 유예)를 설정하고 triggerRt.pauseMask = 0으로 클리어함.
   * checkTriggers()에서 now < triggerRt.pauseBypassUntilMs인 동안은 PAUSE 비트마스크 갱신을 스킵하되, STOP 조건(타이머, 예약시각, mode=STOP 저온/저DI)은 안전을 위해 정상 감시함.
 * **실행 중 현재 세션 규칙 실시간 갱신 (PATCH /api/v001/session/rule)**
   * W10_Web_Routes_Session_0203.cpp에 PATCH /session/rule 엔드포인트를 신설함.
   * CL_CT10_ControlManager::updateActiveSessionRule(const JsonObjectConst& p_ruleJs) 메서드를 추가하여 s_stateMutex 보호 아래 C10_fromJson_TriggerRule()로 파싱 후 applyRuleToTriggerRt()를 재호출함.
   * 단, 타이머를 이미 경과한 시간보다 짧게 수정할 경우를 대비해 triggerRt.timerStartMs 및 pausedAccumMs를 보존하거나 잔여 분 기준으로 재계산하도록 처리함.
 * **AUTO_FULL / AUTO_SELECT 자동 전환 사유 기록 및 상태 노출 (CT10_Ctl_0203.h, CT10_Ctl_Comfort_0203.cpp, CT10_Ctl_IOWS_0203.cpp)**
   * ST_CT10_SessionContext_t에 char autoSwitchReason[64]; 및 uint32_t autoSwitchAtMs; 필드를 추가함.
   * tickAutoComfort()에서 프리셋이나 스타일이 자동 전환될 때 snprintf(_session.autoSwitchReason, sizeof(...), "DI %.0f · %.1f°C", di, tempC) 형태로 사유를 기록함.
   * exportStateJson_v02()의 control.session 객체에 autoSwitchReason과 autoSwitchAtMs를 직렬화하여 프론트엔드에서 즉시 이유를 표시할 수 있게 함.
 * **AUTO_FULL / AUTO_SELECT 수동 조작 시 MANUAL 전환 보장 (CT10_Ctl_Ctl_Ovr_0203.cpp)**
   * startOverrideFixed() 및 startOverridePreset() 시그니처에 bool p_isUserManual = true 기본 인자를 추가함.
   * tickAutoComfort() 내부에서 호출할 때만 p_isUserManual = false를 전달하고, 웹 API나 슬라이더 조작 등 외부 호출(p_isUserManual == true) 시에는 _session.trigger = EN_CT10_TRIGGER_MANUAL 및 _session.type을 FIXED 또는 PRESET으로 즉시 전환하여 자동 개입을 정지시킴.
 * **수면·유아 시나리오 가동 시 본체 RGB LED 자동 소등 (CT10_Ctl_Ctl_0203.cpp, L10_LedCtrl)**
   * ST_A20_TriggerRule_t에 bool ledOff = false; 옵션을 추가하고 cfg_userProfile_0203.json의 수면모드(profileNo=10)와 아기/유아 케어(profileNo=80)에 "ledOff": true를 설정함.
   * applyRuleToTriggerRt()에서 _session.rule.ledOff == true이면 LED 컨트롤러에 페이드 아웃 소등(brightness = 0)을 요청하고, stopSession() 또는 onTriggerStop() 시 설정된 원래 밝기로 복원함.
 * **유아(baby) 시나리오 임계 온도 통일 (cfg_userProfile_0203.json)**
   * profileNo=80 (아기/유아 케어)의 tempLow.threshold를 24.0°C (mode: "STOP")로 상향 통일하여 UI 카드 메타 텍스트 및 규칙 편집기 템플릿(babySafe)과 100% 일치시킴.
### 2. 프론트엔드 UI/UX (js/core/ 및 js/app/) 구현 방안
 * **수면 원터치 트리거 정합화 및 원터치 토글·활성 표시 (js/app/200.page.dashboard.js, css/_dashboard.css)**
   * _onScenarioClick('sleep') 호출 시 L1 설계 의도대로 AUTO_SELECT (baseType: 'PLAYLIST', profileId: 1)로 실행하도록 수정하여 밤새 환경에 맞춘 스타일 자동 조절을 활성화함.
   * _renderScenarioGrid() 렌더링 시 현재 SNW.Store.get().control의 활성 세션(profileNo 또는 session.type)과 일치하는 카드에 is-running 클래스를 부여해 실시간 테두리 글로우 및 파형 배지를 표시하고, 활성 카드를 재탭할 경우 즉시 정지 토글이 동작하도록 구현함.
   * 🎯 취향 맞춤 Auto 카드는 localStorage의 snw.lastAutoSelectBase 값을 읽어 원탭으로 즉시 실행하고, 카드 우측 상단 [▾] 뱃지 또는 500ms 롱프레스 시에만 _showAutoSelectDialog() 기준 선택 모달을 호출함.
 * **AUTOOFF_STOPPED 야간 종료 리포트 및 1클릭 복구 (js/app/200.page.dashboard.js)**
   * control.stateCode === 5 (AUTOOFF_STOPPED) 감지 시 히어로 카드 최상단에 종료 시각 및 사유(reasonCode 9: 타이머, 10: 예약시각, 12: 저온 감기방지, 13: 저불쾌지수)를 문장으로 렌더링함.
   * 카드 하단에 [🔄 직전 설정으로 다시 켜기] 버튼을 배치하여 클릭 시 POST /control/ack 호출 후 직전 세션 파라미터를 재전송해 1클릭 복구를 지원함.
 * **ENV_PAUSED 즉시 수동 재개 버튼 및 먼저 도래하는 종료 시각 안내 (js/app/999a.nowplaying.js, js/app/200.page.dashboard.js)**
   * stateCode === 7 (ENV_PAUSED)일 때 btnPause를 숨기는 대신 아이콘과 라벨을 [▶ 지금 재개]로 전환하여 노출하고, 클릭 시 POST /session/resume을 호출해 1시간 유예 후 즉시 가동함.
   * triggerRt.timerArmed와 triggerRt.offTimeEnabled가 동시에 활성화된 경우, 두 종료 예정 시각(timerStartMs + timerMinutes vs offTimeMinutes)을 비교해 **더 빨리 도래하는 시각**을 계산하여 06:00 종료 예정 (약 6시간 40분 남음) 형태로 단일 표기함.
   * session.autoSwitchReason 값이 존재하면 Now Playing 서브 텍스트에 ✨ DI 76 상승으로 전환됨 형태로 1줄 설명을 병기함.
 * **실시간 풍속 목표 vs 실제 출력 이중 게이지 (js/app/200.page.dashboard.js, css/_dashboard.css)**
   * 히어로 카드 및 일반 선풍기 슬라이더 하단 게이지 바를 목표 출력(점선/고스트 트랙)과 현재 실측 PWM/풍속(실선 채움 트랙)의 이중 구조로 구현하여 BLDC 모터 가감속 관성 지연을 시각적으로 피드백함.
   * 프리셋 카드와 히어로 카드의 평균 풍속 표기 옆에 (약 N단 세기) 환산 뱃지를 추가함.
 * **규칙 편집기 즉시 적용 옵션 및 현재 환경 기준 미리보기 (js/core/150.ui.rule_editor.js)**

   * WebSocket 연결 상태(wsConnected === false) 감지 시 제어 카드 영역에 반투명 오버레이(📡 기기와 다시 연결하는 중...)를 표시해 단절 중 버튼 연타를 차단함.
