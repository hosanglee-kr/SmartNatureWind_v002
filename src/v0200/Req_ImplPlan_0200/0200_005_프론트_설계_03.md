# FRONTEND_IMPL_0200.md — 프론트엔드 최적 재설계 v3.0 (그린필드)

> **완전 원점 재설계** — 기존 HTML/CSS/JS 전면 폐기, 마이그레이션 없음  
> **모체 문서**: `FRONTEND_REQ_0200.md` v1.2  
> **준수 대상**: `SPEC_0200.md` §5/§5.3, `CONTRACT_0200.md` §4  
> **목표**: 최소 HTTP 요청 + 명확한 SoC + 확장 용이 + 배포 단순성

## 1. 설계 철학

### 1.1 3대 원칙

| # | 원칙 | 근거 |
|---|---|---|
| **P1** | **단일 번들, 단일 진입점** — 모든 페이지가 동일 JS/CSS 자산 로드 | 브라우저 캐시로 페이지 간 이동 시 0 HTTP |
| **P2** | **선언적 페이지 = 데이터** — 페이지는 `<body data-page>` + 템플릿만 | 페이지 추가 시 JS 재빌드 불필요 |
| **P3** | **계층형 모듈 = 넘버링** — 000~999 정렬이 로드 순서 | 자동화된 빌드 (glob) |

### 1.2 도출된 배포 자산 (총 3파일)

```text
[빌드 산출물]
├── P010_bundle_0200.js    # 모든 로직 (1 HTTP)
├── P000_common_0200.css   # 모든 스타일 (1 HTTP)
└── P010_main_0200.html    # 단일 HTML Shell (1 HTTP)
```

**모든 페이지 = 같은 HTML + `data-page` 힌트** → URL은 `/#/dashboard`, `/#/chart` 등 해시 라우팅  
- 페이지 이동 시 **JS/CSS 재요청 0** (캐시)
- HTML도 재요청 없음 (SPA)
- 총 초기 로드: **3 HTTP**

### 1.3 성능 예측

| 시나리오 | v2.0 (페이지별 HTML) | **v3.0 (SPA + 해시)** |
|---|---|---|
| 첫 방문 | 3 HTTP | **3 HTTP** |
| Dashboard → Chart | HTML + JS 재확인 = ~2 HTTP | **0 HTTP** (캐시 + 해시) |
| 세션 전체 (5페이지 이동) | ~8~10 HTTP | **3 HTTP** (초기 1회) |
| 배포 파일 수 | 15 | **3** |
| LittleFS 사용 | ~99KB | **~30KB** |

**LWIP TCP PCB 사용 극소화**, ESP32 부하 대폭 감소.

## 5. 라우팅 설계 (`070.router.js`)

```javascript
window.SNW = window.SNW || {};
(function (SNW) {
    'use strict';

    const ROUTES = {
        '/dashboard':  { page: 'dashboard',  level: 'L1' },
        '/chart':      { page: 'chart',      level: 'L2' },
        '/schedule':   { page: 'schedule',   level: 'L2' },
        '/profiles':   { page: 'profiles',   level: 'L2' },
        '/sensors':    { page: 'sensors',    level: 'L2' },
        '/settings':   { page: 'settings',   level: 'L3' },
        '/network':    { page: 'network',    level: 'L3' },
        '/logs':       { page: 'logs',       level: 'L3' },
        '/diagnostics':{ page: 'diagnostics',level: 'L4' },
        '/firmware':   { page: 'firmware',   level: 'L4' },
        '/ai':         { page: 'ai',         level: 'L4' },
        '/info':       { page: 'info',       level: 'L1' }
    };

    let currentPage = null;   // 활성 SNW.Page.* 인스턴스
    let currentPath = null;

    function parseHash() {
        const h = location.hash.replace(/^#/, '') || '/dashboard';
        return ROUTES[h] ? h : '/dashboard';
    }

    async function dispatch() {
        const path = parseHash();
        if (path === currentPath) return;

        const route = ROUTES[path];

        // 레벨 검사
        if (!SNW.LevelUtil.atLeast(route.level)) {
            SNW.ToastUtil.warn(SNW.I18n.t('msg.accessDenied'));
            location.hash = '/dashboard';
            return;
        }

        // 이전 페이지 unmount
        if (currentPage && typeof currentPage.unmount === 'function') {
            try { currentPage.unmount(); } catch (e) { SNW.LogUtil.error(e); }
        }

        // 컨텐츠 비우기
        const main = document.getElementById('snw-main');
        main.innerHTML = '';
        main.appendChild(SNW.DomUtil.html`<div class="snw-loading">${SNW.I18n.t('common.loading')}</div>`);

        // 새 페이지 인스턴스
        const PageClass = SNW.Page[capitalize(route.page)];
        if (!PageClass) {
            main.innerHTML = '';
            main.appendChild(SNW.DomUtil.html`<div class="snw-error">Page not found: ${route.page}</div>`);
            return;
        }

        try {
            currentPage = new PageClass(main);
            currentPath = path;
            await currentPage.mount();
            // 사이드바 활성 표시
            document.querySelectorAll('#nav-menu a').forEach(a => {
                a.classList.toggle('is-active', a.getAttribute('data-route') === path);
            });
        } catch (e) {
            SNW.ErrorHandler.handle(e, `page.${route.page}`);
        }
    }

    function capitalize(s) {
        return s.charAt(0).toUpperCase() + s.slice(1);
    }

    function renderNavMenu() {
        const nav = document.getElementById('nav-menu');
        nav.innerHTML = '';
        const items = [
            { path: '/dashboard',  labelKey: 'nav.dashboard',  icon: '📊' },
            { path: '/chart',      labelKey: 'nav.chart',      icon: '📈', minLevel: 'L2' },
            { path: '/schedule',   labelKey: 'nav.schedule',   icon: '📅', minLevel: 'L2' },
            { path: '/profiles',   labelKey: 'nav.profiles',   icon: '👤', minLevel: 'L2' },
            { path: '/sensors',    labelKey: 'nav.sensors',    icon: '🌡', minLevel: 'L2' },
            { path: '/settings',   labelKey: 'nav.settings',   icon: '⚙',  minLevel: 'L3' },
            { path: '/network',    labelKey: 'nav.network',    icon: '📶', minLevel: 'L3' },
            { path: '/logs',       labelKey: 'nav.logs',       icon: '📜', minLevel: 'L3' },
            { path: '/diagnostics',labelKey: 'nav.diagnostics',icon: '🔧', minLevel: 'L4' },
            { path: '/firmware',   labelKey: 'nav.firmware',   icon: '💾', minLevel: 'L4' },
            { path: '/ai',         labelKey: 'nav.ai',         icon: '🤖', minLevel: 'L4' },
            { path: '/info',       labelKey: 'nav.info',       icon: 'ℹ' }
        ];
        const cur = SNW.LevelUtil.current();
        items.forEach(it => {
            if (it.minLevel && SNW.C.LEVEL.ORDER.indexOf(cur) < SNW.C.LEVEL.ORDER.indexOf(it.minLevel)) return;
            const a = SNW.DomUtil.html`<a href="#${it.path}" data-route="${it.path}">
                <span class="snw-nav-icon">${it.icon}</span>
                <span>${SNW.I18n.t(it.labelKey)}</span>
            </a>`;
            nav.appendChild(a);
        });
    }

    SNW.Router = {
        init() {
            window.addEventListener('hashchange', dispatch);
            // 사이드바 토글
            document.getElementById('btn-menu').addEventListener('click', () => {
                const sb = document.getElementById('snw-sidebar');
                sb.hidden = !sb.hidden;
            });
            renderNavMenu();
            // 언어 변경 시 네비 재렌더
            document.addEventListener('snw:langchange', renderNavMenu);
            // 최초 디스패치
            dispatch();
        },
        navigate(path) {
            location.hash = path;
        },
        current() { return currentPath; }
    };

})(window.SNW);
```

// 모든 페이지 클래스가 구현할 인터페이스
class PageInterface {
    /**
     * @param {HTMLElement} container   <main id="snw-main">
     */
    constructor(container) {
        this.el = container;
        this._unsubs = [];   // Store 구독 해제 함수들
        this._timers = [];   // setInterval/Timeout ID
        this._wsUnsubs = []; // WS 구독 해제 함수들
    }

    /** 페이지 렌더 + 초기 데이터 로드 (async) */
    async mount() { /* 하위 클래스 구현 */ }

    /** 페이지 이탈 시 정리 (필수) */
    unmount() {
        this._unsubs.forEach(fn => fn());
        this._wsUnsubs.forEach(fn => fn());
        this._timers.forEach(id => { clearInterval(id); clearTimeout(id); });
        this._unsubs = [];
        this._wsUnsubs = [];
        this._timers = [];
    }
}

### 6.2 예시: Dashboard (`200.page.dashboard.js`)

```javascript
window.SNW = window.SNW || {};
(function (SNW) {
    'use strict';

    SNW.Page = SNW.Page || {};

    SNW.Page.Dashboard = class Dashboard {
        constructor(container) {
            this.el = container;
            this._unsubs = [];
            this._wsUnsubs = [];
            this._timers = [];
            this.components = {};
        }

        async mount() {
            this.el.innerHTML = '';
            this.el.appendChild(SNW.Tpl.dashboard());   // 033.util.template.js

            // 초기 데이터
            try {
                const data = await SNW.Api.getState();
                SNW.Store.set({ control: data.control, sim: data.sim,
                                time: data.control?.time, system: data.control?.system,
                                fsmState: data.control?.stateCode || 0,
                                fsmReason: data.control?.reasonCode || 0 });
            } catch (e) {
                SNW.ErrorHandler.handle(e, 'dashboard.init');
            }

            this._mountComponents();
            this._bindStore();

            // 헤더 시계
            const clockId = SNW.TimeUtil.startClock(
                document.getElementById('header-clock'),
                () => {
                    const t = SNW.Store.get().time || {};
                    return { hour: t.hour ?? -1, min: t.min ?? -1 };
                }
            );
            this._timers.push(clockId);
        }

        _mountComponents() {
            const q = sel => this.el.querySelector(sel);

            this.components.badge = SNW.UI.stateBadge(q('[data-slot="badge"]'));
            this.components.gauge = SNW.UI.gauge(q('[data-slot="gauge"]'));
            this.components.toggle = SNW.UI.toggle({
                root: q('[data-slot="power"]'),
                on: false,
                onToggle: next => this._onPowerToggle(next)
            });
            this.components.slider = SNW.UI.slider({
                root: q('[data-slot="intensity"]'),
                min: 0, max: 100, value: 70,
                label: SNW.I18n.t('dashboard.intensityLabel'),
                unit: '%',
                debounceMs: SNW.C.DEBOUNCE_MS.SLIDER,
                onChange: v => this._onIntensityChange(v)
            });
            this.components.presets = SNW.UI.presetGrid({
                root: q('[data-slot="presets"]'),
                items: [],
                selected: '',
                onSelect: code => this._onPresetSelect(code)
            });
            this.components.sensors = SNW.UI.sensorCards(q('[data-slot="sensors"]'));

            this._loadPresets();
        }

        _bindStore() {
            const store = SNW.Store;
            this._unsubs.push(
                store.watch('fsmState', code => {
                    this.components.badge.set(code, store.get().fsmReason);
                }),
                store.watch('sim', sim => {
                    if (!sim) return;
                    this.components.gauge.set(sim.pwmDuty ?? 0);
                    this.components.slider.set(sim.intensity ?? 70);
                    this.components.presets.setSelected(sim.presetCode || '');
                    const w = this.el.querySelector('[data-slot="cur-wind"]');
                    if (w) w.textContent = (sim.windSpeed ?? 0).toFixed(1);
                }),
                store.watch('control', ctl => {
                    if (!ctl) return;
                    this.components.toggle.set(!!ctl.active);
                    if (ctl.sensor) this.components.sensors.set(ctl.sensor);
                })
            );
        }

        async _onPowerToggle(next) {
            const prev = SNW.Store.get().control?.active;
            SNW.Store.set({ control: Object.assign({}, SNW.Store.get().control, { active: next }) });
            try {
                if (next) {
                    const intensity = SNW.Store.get().sim?.intensity ?? 70;
                    await SNW.Api.overrideFixed(intensity, 0, true);
                } else {
                    await SNW.Api.overrideClear();
                }
            } catch (e) {
                SNW.Store.set({ control: Object.assign({}, SNW.Store.get().control, { active: prev }) });
                SNW.ErrorHandler.handle(e, 'dashboard.power');
            }
        }

        async _onIntensityChange(v) {
            const prev = SNW.Store.get().sim?.intensity;
            const sim = Object.assign({}, SNW.Store.get().sim, { intensity: v });
            SNW.Store.set({ sim });
            try { await SNW.Api.patchSim({ intensity: v }); }
            catch (e) {
                SNW.Store.set({ sim: Object.assign({}, SNW.Store.get().sim, { intensity: prev }) });
                SNW.ErrorHandler.handle(e, 'dashboard.intensity');
            }
        }

        async _onPresetSelect(code) {
            try {
                await SNW.Api.patchSim({ presetCode: code });
                SNW.ToastUtil.success(SNW.I18n.t('msg.saveSuccess'));
            } catch (e) { SNW.ErrorHandler.handle(e, 'dashboard.preset'); }
        }

        async _loadPresets() {
            try {
                const data = await SNW.Api.listWindProfiles();
                const items = (data.windDict?.presets || []).map(p => ({
                    code: p.code,
                    name: SNW.I18n.t('preset.' + p.code) || p.name
                }));
                this.components.presets.setItems(items);
            } catch (e) { SNW.LogUtil.warn('preset load failed', e); }
        }

        unmount() {
            this._unsubs.forEach(fn => fn());
            this._wsUnsubs.forEach(fn => fn());
            this._timers.forEach(id => { clearInterval(id); clearTimeout(id); });
        }
    };

})(window.SNW);
```

## 7. 템플릿 시스템 (`033.util.template.js`)

### 7.1 설계

각 페이지의 HTML 구조를 **JS 템플릿 함수**로 관리 (SPA이므로 정적 HTML 파일 불필요).

```javascript
window.SNW = window.SNW || {};
(function (SNW) {
    'use strict';

    // escape 유틸 (031.util.dom.js에서 재사용)
    const esc = s => String(s).replace(/[&<>"']/g,
        c => ({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;'}[c]));

    // tagged template literal → HTMLElement
    function tpl(strings, ...vals) {
        const html = strings.reduce((acc, s, i) => {
            const v = vals[i];
            const safe = (v == null) ? '' : (typeof v === 'string' ? esc(v) : v);
            return acc + s + (i < vals.length ? safe : '');
        }, '');
        const div = document.createElement('div');
        div.innerHTML = html.trim();
        return div.firstElementChild;
    }

    SNW.Tpl = {
        tpl,

        // =====================================================
        // Dashboard 템플릿 (data-slot 계약)
        // =====================================================
        dashboard() {
            return tpl`
                <section class="snw-card snw-state-card">
                    <h2 data-i18n="dashboard.realtimeState">실시간 상태</h2>
                    <div data-slot="badge" class="snw-state-badge"></div>
                    <div class="snw-kv">
                        <span data-i18n="dashboard.currentWind">현재 풍속</span>
                        <b data-slot="cur-wind">-</b> <span data-i18n="unit.windSpeed">m/s</span>
                    </div>
                    <div class="snw-kv">
                        <span data-i18n="dashboard.pwmOutput">PWM</span>
                        <span data-slot="gauge"></span>
                    </div>
                </section>
                <section class="snw-card snw-power-card">
                    <h2 data-i18n="dashboard.powerTitle">전원 제어</h2>
                    <div data-slot="power"></div>
                </section>
                <section class="snw-card snw-preset-card">
                    <h2 data-i18n="dashboard.presetTitle">프리셋 선택</h2>
                    <div data-slot="presets"></div>
                </section>
                <section class="snw-card snw-slider-card">
                    <h2 data-i18n="dashboard.intensityTitle">강도 조절</h2>
                    <div data-slot="intensity"></div>
                </section>
                <section class="snw-card snw-sensor-card">
                    <h2 data-i18n="dashboard.sensorTitle">센서</h2>
                    <div data-slot="sensors"></div>
                </section>`;
        },

        // =====================================================
        // Chart 템플릿
        // =====================================================
        chart() {
            return tpl`
                <section class="snw-card">
                    <h2 data-i18n="chart.title">실시간 차트</h2>
                    <div class="snw-chart-toolbar">
                        <select data-slot="range">
                            <option value="5">5s</option>
                            <option value="30">30s</option>
                            <option value="120" selected>120s</option>
                        </select>
                        <button data-action="export" data-i18n="chart.export">CSV</button>
                    </div>
                    <div data-slot="chart"></div>
                </section>`;
        },

        // =====================================================
        // Settings 템플릿 (스키마 기반 폼)
        // =====================================================
        settings() {
            return tpl`
                <section class="snw-card">
                    <h2 data-i18n="system.title">시스템 설정</h2>
                    <div data-slot="form-log"></div>
                    <div data-slot="form-api"></div>
                    <div class="snw-form-actions">
                        <button data-action="save" class="snw-btn snw-btn-primary" data-i18n="system.save">저장</button>
                        <button data-action="reload" class="snw-btn" data-i18n="system.reload">재로드</button>
                    </div>
                </section>`;
        }

        // ... 나머지 페이지 템플릿 (schedule, profiles, network, logs 등)
    };

})(window.SNW);
```

### 7.2 계약

| 규칙 | 예 |
|---|---|

## 10. 부트스트랩 흐름 (`999.app.js`)

```javascript
window.SNW = window.SNW || {};
(function (SNW) {
    'use strict';

    // =====================================================
    // 부트스트랩 (DOMContentLoaded 1회)
    // =====================================================
    document.addEventListener('DOMContentLoaded', async () => {
        try {
            // 1) i18n 적용 (data-i18n 텍스트 채움)
            SNW.I18n.applyTo(document);

            // 2) 사용자 레벨 필터 (data-min-level)
            SNW.LevelUtil.applyTo(document.body);

            // 3) 연결 상태 UI 초기화
            SNW.Store.watch('connection', (c) => {
                const dot = document.getElementById('conn-status');
                if (!dot) return;
                dot.className = 'snw-status-dot snw-status-dot--' + c;
                dot.title = SNW.I18n.t('footer.' + c);
                document.getElementById('footer-status').textContent =
                    SNW.I18n.t('footer.' + c);
            });

            // 4) WS + Store 브리지
            SNW.WsManager.initByLevel();
            SNW.StoreBridge.start();

            // 5) 언어 토글 버튼
            document.getElementById('btn-lang').addEventListener('click', () => {
                const cur = SNW.I18n.getLang();
                SNW.I18n.setLang(cur === 'ko' ? 'en' : 'ko');
            });

            // 6) 라우터 시작 (해시 기반 페이지 마운트)
            SNW.Router.init();

            SNW.LogUtil.info('App bootstrap complete', { level: SNW.LevelUtil.current() });
        } catch (e) {
            SNW.LogUtil.error('bootstrap failed', e);
            document.getElementById('snw-main').innerHTML =
                '<div class="snw-error">' + SNW.I18n.t('msg.unknown') + '</div>';
        }
    });

})(window.SNW);
```
