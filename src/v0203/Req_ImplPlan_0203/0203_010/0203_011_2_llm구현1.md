
한계점 5가지:

# 문제 심각도 영향
G1 Function calling 미사용 — 제어 요청이 텍스트 응답만 🔴 "1시간 후 꺼줘"가 실제 Session 안 됨
G2 커맨드 스키마 부재 — LLM이 반환한 텍스트를 파싱할 규칙 없음 🔴 제어 자동화 불가
G3 컨텍스트 주입 없음 — 현재 상태를 Gemini에 전달 안 함 🟠 "지금 뭐야?" 답변 부정확
G4 에러/타임아웃 처리 부족 — SSL 15초 타임아웃만 🟠 UX 저하
G5 세션/대화 이력 없음 — 매 요청 독립적 🟡 "아까 그거" 참조 불가

1.2 v0203의 진화 목표

```
[현재] 자연어 → Gemini → 텍스트 응답
[목표] 자연어 → Gemini (Function Calling) → 구조화 커맨드 → CT10 실행 → 응답
                  ↑                                      ↓
             현재 상태 주입                     TTS/텍스트 응답
```

Part 3. 음성 인터페이스 검토

3.1 방식 비교

항목 방식 1 (브라우저) 방식 2 (스탠드얼론)
구성 Web Speech API + 백엔드 프록시 I2S mic + I2S amp + 스피커
부품 비용 $0 (기존 스마트폰) ~$16 (INMP441 + MAX98357A + 3W)
STT 브라우저 (Chrome/Safari) Gemini API (audio inline)
TTS 브라우저 (SpeechSynthesis) Gemini TTS or Google Cloud TTS
웨이크워드 프론트엔드 ("헤이 윈드") ESP-SR ("Hi Wind")
PSRAM 사용 0 ~150KB+ (WAV 버퍼)
Heap 요구 0 최소 200KB 여유
전력 스마트폰 의존 상시 대기 (mic 상시)
구현 난이도 ⭐⭐ ⭐⭐⭐⭐
오프라인 ❌ (STT는 브라우저 서버) ❌ (Gemini 필수)
첫 사용성 매우 쉬움 (마이크 권한 1회) 웨이크워드 학습 필요

3.2 ⚠️ 스탠드얼론의 하드웨어 재검토

사용자가 언급한 "현 ESP32(PSRAM 없음)"에 대한 지적:

v0203 하드웨어 사양은 ESP32-S3-N16R8 (platformio.ini 확정):

```
board = esp32s3box
board_build.arduino.memory_type = qio_opi
board_upload.flash_size = 16MB
-D BOARD_HAS_PSRAM
-D BOARD_HAS_PSRAM_OPI
```

PSRAM 8MB가 있으므로 "PSRAM 없음"은 사실과 다름. 다만 스탠드얼론 음성의 진짜 제약은:

실제 제약 설명
WAV 실시간 버퍼 16kHz × 16bit × 5초 = 160KB — PSRAM에 할당 가능
HTTPS SSL 핸드셰이크 ~40KB heap (PSRAM 아님, 내부 heap) — 여유 있음
실시간 오디오 태스크 I2S DMA + WiFi 동시 → CPU 부하 증가
Gemini 오디오 업로드 지연 5초 WAV → HTTPS → 응답 = 2~4초 (체감 느림)
웨이크워드 상시 대기 ESP-SR 모델 ~500KB Flash + 상시 CPU 5~10%

진짜 이유는 PSRAM 부족이 아니라:

1. 실시간성 저하 — 클라우드 왕복 2~4초
2. 웨이크워드 상시 대기 전력 소모
3. 개발 복잡도 (I2S DMA, WAV 인코딩, 에러 복구)
4. 스마트폰이 이미 옆에 있음 (구매자 관점)

3.3 ✅ 결정: 방식 1 (브라우저) 채택

이유:

· 비용 0 — 추가 하드웨어 없음
· 즉시 사용 — 앱 설치 없이 브라우저
· STT/TTS 품질 — Chrome/Safari의 STT는 Gemini 오디오보다 빠르고 정확
· 개발 2주 vs 개발 6주
· 실패 시 폴백 용이 — 텍스트 입력 그대로 유지

스탠드얼론은 Phase 9+로 이월 (하드웨어 옵션 상품화 시):

· 프리미엄 모델: 마이크/스피커 내장
· 웨이크워드: "Hi Wind" (ESP-SR)
· 대상: 스마트폰 없는 거실/침실 상시 사용자

5.1 W10_Web_Routes_AI_0203.cpp — API 확장

```cpp
#include "W10_Web_0203.h"
#include "CT10_Ctl_0203.h"
#include "A40_Com_Utils_0203.h"
#include <HTTPClient.h>
#include <WiFiClientSecure.h>

// ======================================================
// POST /api/v0203/ai/gemini
// Body: {
//   "message": "1시간 후 꺼줘",
//   "history": [{"role":"user","text":"..."},{"role":"model","text":"..."}],
//   "voice": false
// }
// 응답: {
//   "text": "1시간 후에 꺼드릴게요",
//   "actions": [{ "name": "set_timer", "args": {"minutes": 60}, "result": "ok" }],
//   "session": { ... }   // 액션 실행 후 상태
// }
// ======================================================
static void handleAIGemini(AsyncWebServerRequest* req) {
    if (!W10_checkApiKey(req)) { req->send(401); return; }

    JsonDocument in;
    uint8_t buf[4096];
    if (!W10_parseJsonBody(req, in, buf, sizeof(buf))) {
        req->send(400, "application/json", "{\"error\":\"invalid_body\"}");
        return;
    }

    const char* userMessage = A40_ComFunc::Json_getStr(
        in.as<JsonObjectConst>(), "message", "");
    if (!userMessage[0]) {
        req->send(400, "application/json", "{\"error\":\"empty_message\"}");
        return;
    }

    // Gemini API 키 확인
    if (!g_A20_config_root.system ||
        !g_A20_config_root.system->security.geminiApiKey[0]) {
        req->send(400, "application/json",
            "{\"error\":\"gemini_api_key_not_set\"}");
        return;
    }

    // ======================================================
    // 1. 시스템 프롬프트 생성 (현재 상태 컨텍스트)
    // ======================================================
    String systemPrompt = CT10_buildAIPrompt();

    // ======================================================
    // 2. Gemini API 호출 (Function Calling 포함)
    // ======================================================
    String geminiUrl = "https://generativelanguage.googleapis.com/v1beta/models/";
    geminiUrl += "gemini-2.0-flash-exp:generateContent?key=";
    geminiUrl += g_A20_config_root.system->security.geminiApiKey;

    // 요청 body 조립
    JsonDocument geminiReq;
    geminiReq["system_instruction"]["parts"][0]["text"] = systemPrompt;

    // 대화 이력 (선택)
    JsonArray histArr = in["history"].as<JsonArray>();
    if (!histArr.isNull()) {
        JsonArray contents = geminiReq["contents"].to<JsonArray>();
        for (JsonObjectConst h : histArr) {
            JsonObject c = contents.add<JsonObject>();
            c["role"] = A40_ComFunc::Json_getStr(h, "role", "user");
            c["parts"][0]["text"] = A40_ComFunc::Json_getStr(h, "text", "");
        }
        // 현재 메시지 추가
        JsonObject c = contents.add<JsonObject>();
        c["role"] = "user";
        c["parts"][0]["text"] = userMessage;
    } else {
        geminiReq["contents"][0]["role"] = "user";
        geminiReq["contents"][0]["parts"][0]["text"] = userMessage;
    }

    // Function declarations (Stage 8 - 10개 함수)
    JsonArray tools = geminiReq["tools"].to<JsonArray>();
    JsonObject tool = tools.add<JsonObject>();
    JsonArray decls = tool["function_declarations"].to<JsonArray>();
    CT10_appendAIFunctionDeclarations(decls);

    String geminiBody;
    serializeJson(geminiReq, geminiBody);

    // ======================================================
    // 3. HTTPS POST
    // ======================================================
    WiFiClientSecure* client = new WiFiClientSecure();
    client->setInsecure();   // ⚠️ 프로덕션: 인증서 검증 권장

    HTTPClient http;
    http.begin(*client, geminiUrl);
    http.addHeader("Content-Type", "application/json");
    http.setTimeout(20000);
    int httpCode = http.POST(geminiBody);

    String geminiResponse = http.getString();
    http.end();
    delete client;

    if (httpCode != 200) {
        JsonDocument errOut;
        errOut["error"] = "gemini_error";
        errOut["status"] = httpCode;
        errOut["detail"] = geminiResponse.substring(0, 200);
        W10_sendJson(req, 502, errOut);
        return;
    }

    // ======================================================
    // 4. Gemini 응답 파싱
    // ======================================================
    JsonDocument geminiResp;
    DeserializationError err = deserializeJson(geminiResp, geminiResponse);
    if (err) {
        req->send(502, "application/json", "{\"error\":\"parse_failed\"}");
        return;
    }

    JsonArray candidates = geminiResp["candidates"].as<JsonArray>();
    if (candidates.isNull() || candidates.size() == 0) {
        req->send(502, "application/json", "{\"error\":\"no_candidates\"}");
        return;
    }

    JsonObject parts = candidates[0]["content"]["parts"].as<JsonArray>();
    if (parts.isNull()) {
        req->send(502, "application/json", "{\"error\":\"no_parts\"}");
        return;
    }

    // ======================================================
    // 5. Function Call 실행 (있으면) + 텍스트 응답
    // ======================================================
    JsonDocument outDoc;
    JsonArray actionsArr = outDoc["actions"].to<JsonArray>();
    String responseText = "";

    for (JsonObject part : parts.as<JsonArray>()) {
        // Function call
        JsonObject fc = part["functionCall"].as<JsonObject>();
        if (!fc.isNull()) {
            const char* fnName = A40_ComFunc::Json_getStr(fc, "name", "");
            JsonObjectConst args = fc["args"].as<JsonObjectConst>();

            String result = CT10_executeAIAction(fnName, args);

            JsonObject act = actionsArr.add<JsonObject>();
            act["name"]   = fnName;
            act["args"]   = args;
            act["result"] = result;
        }

        // Text
        const char* t = A40_ComFunc::Json_getStr(part, "text", nullptr);
        if (t && t[0]) {
            if (responseText.length() > 0) responseText += " ";
            responseText += t;
        }
    }

    // Function call만 있고 텍스트 응답 없으면 후속 요청 필요 (2-turn)
    // Stage 8 초기: 간단히 텍스트 없으면 "완료했습니다" 폴백
    if (responseText.length() == 0 && actionsArr.size() > 0) {
        responseText = "요청을 실행했습니다.";
    }

    outDoc["text"] = responseText;

    // 액션 실행 후 최신 세션 상태
    JsonDocument stateDoc;
    CL_CT10_ControlManager::instance().exportStateJson_v02(stateDoc);
    outDoc["session"] = stateDoc["control"]["session"];

    W10_sendJson(req, 200, outDoc);
}

void CL_W10_WebAPI::registerAIRoutes(AsyncWebServer& server) {
    server.on("/api/v0203/ai/gemini", HTTP_POST, handleAIGemini);
}
```

```cpp
// ======================================================
// Function Call 실행
// ======================================================
String CT10_executeAIAction(const char* p_fnName, JsonObjectConst p_args) {
    if (!p_fnName) return "error:null_fn";

    // ==================================================
    // start_playlist
    // ==================================================
    if (strcmp(p_fnName, "start_playlist") == 0) {
        uint16_t profileId = A40_ComFunc::Json_getNum<uint16_t>(p_args, "profileId", 0);
        if (profileId == 0) {
            // 이름으로 검색
            const char* name = A40_ComFunc::Json_getStr(p_args, "profileName", "");
            if (name[0] && g_A20_config_root.profiles) {
                for (uint8_t i = 0; i < g_A20_config_root.profiles->count; i++) {
                    if (strcasecmp(g_A20_config_root.profiles->items[i].name, name) == 0) {
                        profileId = g_A20_config_root.profiles->items[i].profileId;
                        break;
                    }
                }
            }
        }
        if (profileId == 0) return "error:profile_not_found";

        bool ok = CL_CT10_ControlManager::startPlaylistManual((uint8_t)profileId);
        return ok ? "ok" : "error:start_failed";
    }

    // ==================================================
    // start_preset
    // ==================================================
    if (strcmp(p_fnName, "start_preset") == 0) {
        const char* pc = A40_ComFunc::Json_getStr(p_args, "presetCode", "");
        const char* sc = A40_ComFunc::Json_getStr(p_args, "styleCode", "BALANCE");
        if (!pc[0]) return "error:missing_preset";
        bool ok = CL_CT10_ControlManager::startPresetManual(pc, sc);
        return ok ? "ok" : "error:start_failed";
    }

    // ==================================================
    // start_fixed
    // ==================================================
    if (strcmp(p_fnName, "start_fixed") == 0) {
        float pct = A40_ComFunc::Json_getNum<float>(p_args, "percent", 50.0f);
        pct = constrain(pct, 0.0f, 100.0f);
        bool ok = CL_CT10_ControlManager::startFixedManual(pct);
        return ok ? "ok" : "error:start_failed";
    }

    // ==================================================
    // pause / resume / stop
    // ==================================================
    if (strcmp(p_fnName, "pause_session") == 0) {
        return CL_CT10_ControlManager::pauseSession() ? "ok" : "error:not_active";
    }
    if (strcmp(p_fnName, "resume_session") == 0) {
        return CL_CT10_ControlManager::resumeSession() ? "ok" : "error:not_paused";
    }
    if (strcmp(p_fnName, "stop_session") == 0) {
        return CL_CT10_ControlManager::stopSession() ? "ok" : "error:no_session";
    }

    // ==================================================
    // set_timer
    // ==================================================
    if (strcmp(p_fnName, "set_timer") == 0) {
        uint32_t minutes = A40_ComFunc::Json_getNum<uint32_t>(p_args, "minutes", 0);
        if (minutes == 0 || minutes > 1440) return "error:invalid_minutes";

        // Session 없으면 FIXED 50%로 시작 후 타이머
        auto sess = CL_CT10_ControlManager::getSessionSnapshot();
        if (sess.type == EN_CT10_SESSION_NONE) {
            CL_CT10_ControlManager::startFixedManual(50.0f);
        }
        // 타이머 설정 (AutoOff timer를 session payload에 반영)
        // ⚠️ Stage 8 임시: N10에 타이머 저장 후 다음 세션 AutoOff로 사용
        // 또는 SessionContext 확장 필요
        CL_N10_NvsManager::setAutoOff(true, minutes);
        return "ok";
    }

    // ==================================================
    // get_status
    // ==================================================
    if (strcmp(p_fnName, "get_status") == 0) {
        auto sess = CL_CT10_ControlManager::getSessionSnapshot();
        if (sess.type == EN_CT10_SESSION_NONE) return "fan_is_off";
        return CT10_sessionSummaryString(sess);
    }

    // ==================================================
    // list_profiles
    // ==================================================
    if (strcmp(p_fnName, "list_profiles") == 0) {
        String result = "";
        if (g_A20_config_root.profiles) {
            for (uint8_t i = 0; i < g_A20_config_root.profiles->count; i++) {
                if (i > 0) result += ", ";
                result += String(g_A20_config_root.profiles->items[i].profileId);
                result += ":";
                result += g_A20_config_root.profiles->items[i].name;
            }
        }
        return result.length() ? result : "no_profiles";
    }

    // ==================================================
    // add_schedule
    // ==================================================
    if (strcmp(p_fnName, "add_schedule") == 0) {
        // Stage 8 임시: 상세 스키마 검증 생략, 최소 필드만
        const char* name = A40_ComFunc::Json_getStr(p_args, "name", "AI Schedule");
        uint16_t profileId = A40_ComFunc::Json_getNum<uint16_t>(p_args, "profileId", 0);
        if (profileId == 0) return "error:missing_profile";

        // ⚠️ Stage 8 초기: C10 CRUD 재사용
        // 실제로는 addScheduleFromJson 필요 (JsonDocument 구성)
        return "not_implemented_yet";   // Stage 8.1 확장 예정
    }

    return "error:unknown_function";
}

String CT10_sessionSummaryString(const ST_CT10_SessionContext_t& s) {
    String out = "";
    if (s.state == EN_SESSION_PAUSED) out += "paused ";
    if (s.type == EN_CT10_SESSION_PLAYLIST) {

    } else {

    }
    return out;
}
```

```javascript
// =========================================================
// 146.ai.voice.js — Web Speech API (STT + TTS)
// =========================================================
window.SNW = window.SNW || {};
(function(SNW) {
    'use strict';

    SNW.AIVoice = {
        // =========================================================
        // STT 지원 여부
        // =========================================================
        isSTTSupported() {
            return 'webkitSpeechRecognition' in window ||
                   'SpeechRecognition' in window;
        },

        // =========================================================
        // TTS 지원 여부
        // =========================================================
        isTTSSupported() {
            return 'speechSynthesis' in window;
        },

        // =========================================================
        // 음성 인식 시작
        // =========================================================
        startListening(opts = {}) {
            if (!this.isSTTSupported()) {
                return Promise.reject(new Error('STT not supported'));
            }

            const {
                lang = SNW.I18n.getLang() === 'ko' ? 'ko-KR' : 'en-US',
                timeoutMs = 10000,
                interimResults = false,
            } = opts;

            const Recognition = window.SpeechRecognition || window.webkitSpeechRecognition;
            const rec = new Recognition();
            rec.lang = lang;
            rec.continuous = false;
            rec.interimResults = interimResults;
            rec.maxAlternatives = 1;

            return new Promise((resolve, reject) => {
                let resolved = false;
                const timer = setTimeout(() => {
                    if (!resolved) {
                        resolved = true;
                        try { rec.stop(); } catch {}
                        reject(new Error('timeout'));
                    }
                }, timeoutMs);

                rec.onresult = (event) => {
                    if (resolved) return;
                    resolved = true;
                    clearTimeout(timer);

                    const transcript = event.results[0][0].transcript;
                    const confidence = event.results[0][0].confidence;
                    resolve({ transcript, confidence });
                };

                rec.onerror = (event) => {
                    if (resolved) return;
                    resolved = true;
                    clearTimeout(timer);
                    reject(new Error(event.error || 'stt_error'));
                };

                rec.onend = () => {
                    if (!resolved) {
                        resolved = true;
                        clearTimeout(timer);
                        reject(new Error('no_speech'));
                    }
                };

                try {
                    rec.start();
                } catch (e) {
                    clearTimeout(timer);
                    reject(e);
                }
            });
        },

        // =========================================================
        // TTS 재생
        // =========================================================
        speak(text, opts = {}) {
            if (!this.isTTSSupported() || !text) {
                return Promise.resolve();
            }

            const {
                lang = SNW.I18n.getLang() === 'ko' ? 'ko-KR' : 'en-US',
                rate = 1.0,
                pitch = 1.0,
                volume = 1.0,
            } = opts;

            return new Promise((resolve) => {
                window.speechSynthesis.cancel();

                const utter = new SpeechSynthesisUtterance(text);
                utter.lang = lang;
                utter.rate = rate;
                utter.pitch = pitch;
                utter.volume = volume;
                utter.onend = () => resolve();
                utter.onerror = () => resolve();

                window.speechSynthesis.speak(utter);
            });
        },

        stopSpeaking() {
            if (this.isTTSSupported()) {
                window.speechSynthesis.cancel();
            }
        },
    };
})(window.SNW);
```

Part 2. 핵심 이슈 상세 분석

C1. Function Calling 2-turn (가장 중요)

Gemini API의 실제 동작:

```
Turn 1:
User → Gemini (Function Declaration + message)
Gemini → { functionCall: { name: "set_timer", args: {minutes: 60} } }
       (텍스트 응답 없음!)

Turn 2:
User → Gemini (functionResult 포함)
Gemini → { text: "네, 1시간 후에 꺼드릴게요" }
```

현재 구현은 Turn 1만 처리 → Fallback "완료했습니다".

개선안:

```cpp
// handleAIGemini 내부 - Turn 2 추가

// 1) 액션 실행
JsonArray actionResults = ...;  // [{"name":"set_timer","result":"ok",...}]

// 2) Function call 있었으면 2-turn
if (actionResults.size() > 0 && responseText.isEmpty()) {
    // Gemini에 결과 전송
    JsonDocument turn2Req;
    turn2Req["system_instruction"] = geminiReq["system_instruction"];
    
    JsonArray contents = turn2Req["contents"].to<JsonArray>();
    
    // 이전 대화 이력 재구성
    for (auto h : histArr) contents.add(h);
    
    // 원래 user 메시지
    JsonObject userTurn = contents.add<JsonObject>();
    userTurn["role"] = "user";
    userTurn["parts"][0]["text"] = userMessage;
    
    // Gemini의 FunctionCall 응답
    JsonObject modelTurn = contents.add<JsonObject>();
    modelTurn["role"] = "model";
    JsonObject fc = modelTurn["parts"][0]["functionCall"].to<JsonObject>();
    fc["name"] = firstAction.name;
    fc["args"] = firstAction.args;
    
    // Function 결과
    JsonObject resultTurn = contents.add<JsonObject>();
    resultTurn["role"] = "user";   // ⚠️ Gemini는 tool result를 user role로 받음
    JsonObject fr = resultTurn["parts"][0]["functionResponse"].to<JsonObject>();
    fr["name"] = firstAction.name;
    fr["response"]["result"] = firstAction.result;
    
    // 2-turn API 호출
    String turn2Body;
    serializeJson(turn2Req, turn2Body);
    // ... HTTPS POST ...
    // → 최종 텍스트 응답 파싱
}
```

이 개선으로:

· ❌ "요청을 실행했습니다." → ✅ "네, 1시간 후에 꺼드릴게요"
· 사용자 체감: AI가 "이해했다"는 느낌

```javascript
SNW.AIVoice.startWakeWordDetection = function(opts = {}) {
    if (!this.isSTTSupported()) return null;
    
    const {
        wakeWord = '헤이 윈드',
        wakeWordEn = 'hey wind',
        lang = SNW.I18n.getLang() === 'ko' ? 'ko-KR' : 'en-US',
        onDetected = null,
    } = opts;
    
    const Recognition = window.SpeechRecognition || window.webkitSpeechRecognition;
    const rec = new Recognition();
    rec.lang = lang;
    rec.continuous = true;   // ★ 계속 듣기
    rec.interimResults = true;
    
    let listening = true;
    let detected = false;
    
    rec.onresult = (event) => {
        if (detected) return;
        
        for (let i = event.resultIndex; i < event.results.length; i++) {
            const transcript = event.results[i][0].transcript.toLowerCase();
            if (transcript.includes(wakeWord.toLowerCase()) ||
                transcript.includes(wakeWordEn.toLowerCase())) {
                detected = true;
                if (onDetected) onDetected();
                // 웨이크워드 감지 후 3초 녹음 시작
                rec.stop();
                setTimeout(() => this.startListening({ lang }).then(r => {
                    if (SNW.AISheet) SNW.AISheet._sendFromInput(r.transcript);
                }), 500);
                return;
            }
        }
    };
    
    rec.onend = () => {
        // 자동 재시작 (계속 듣기)
        if (listening && !detected) {
            try { rec.start(); } catch {}
        }
    };
    
    rec.onerror = (e) => {
        if (e.error === 'not-allowed') listening = false;
    };
    
    rec.start();
    
    return {
        stop() {
            listening = false;
            try { rec.stop(); } catch {}
        },
    };
};
```

```cpp
// ======================================================
// Runtime AutoOff 검사 (Profile AutoOff보다 우선)
// ======================================================
bool CL_CT10_ControlManager::checkAutoOff() {
    // =================================================
    // [0] Runtime AutoOff (AI set_timer) — 최우선
    // =================================================
    if (_session.runtimeAutoOffStartMs > 0 && _session.runtimeAutoOffMin > 0) {
        uint32_t elapsedMs = millis() - _session.runtimeAutoOffStartMs;
        uint32_t elapsedMin = elapsedMs / 60000UL;
        if (elapsedMin >= _session.runtimeAutoOffMin) {
            CL_D10_Logger::log(EN_L10_LOG_INFO,
                "[CT10] Runtime AutoOff triggered (%u min)",
                _session.runtimeAutoOffMin);
            _session.runtimeAutoOffStartMs = 0;
            _session.runtimeAutoOffMin = 0;
            return true;
        }
    }

    // =================================================
    // [1] Profile Timer AutoOff (기존)
    // =================================================
    if (_runCtx.autoOffTimerArmed && _runCtx.autoOffTimerMinutes > 0) {
        uint32_t elapsedMin =
            (millis() - _runCtx.autoOffTimerStartMs) / 60000UL;
        if (elapsedMin >= _runCtx.autoOffTimerMinutes) {
            CL_D10_Logger::log(EN_L10_LOG_INFO,
                "[CT10] Profile timer AutoOff triggered (%u min)",
                _runCtx.autoOffTimerMinutes);
            return true;
        }
    }

    // =================================================
    // [2] offTime (기존)
    // =================================================
    if (_runCtx.autoOffOffTimeEnabled) {
        struct tm tm;
        if (CL_TM10_TimeManager::getLocalTime(tm)) {
            uint16_t curMin = (uint16_t)tm.tm_hour * 60 + tm.tm_min;
            if (curMin >= _runCtx.autoOffOffTimeMinutes &&
                _persistOffTimeLastYday != tm.tm_yday) {
                _persistOffTimeLastYday = tm.tm_yday;
                return true;
            }
        }
    }

    // =================================================
    // [3] offTemp (기존)
    // =================================================
    if (_runCtx.autoOffOffTempEnabled) {
        extern float CT10_readTempC();
        if (CT10_readTempC() >= _runCtx.autoOffOffTemp) {
            return true;
        }
    }

    return false;
}

// Runtime AutoOff API
// ======================================================
bool CL_CT10_ControlManager::setSessionAutoOff(uint32_t minutes) {
    CL_A40_MutexGuard_Semaphore v_guard(s_stateMutex, G_A40_MUTEX_TIMEOUT_100, __func__);
    if (!v_guard.isAcquired()) return false;

    if (_session.type == EN_CT10_SESSION_NONE) {
        CL_D10_Logger::log(EN_L10_LOG_WARN,
            "[CT10] setSessionAutoOff: no active session");
        return false;
    }

    if (minutes == 0 || minutes > 1440) return false;

    _session.runtimeAutoOffStartMs = millis();
    _session.runtimeAutoOffMin     = minutes;

    markDirty("state");
    markDirty("summary");

    CL_D10_Logger::log(EN_L10_LOG_INFO,
        "[CT10] Runtime AutoOff set: %u min", minutes);
    return true;
}

bool CL_CT10_ControlManager::clearSessionAutoOff() {
    CL_A40_MutexGuard_Semaphore v_guard(s_stateMutex, G_A40_MUTEX_TIMEOUT_100, __func__);
    if (!v_guard.isAcquired()) return false;

    if (_session.runtimeAutoOffStartMs == 0) return false;

    _session.runtimeAutoOffStartMs = 0;
    _session.runtimeAutoOffMin     = 0;

    markDirty("state");
    return true;
}

uint32_t CL_CT10_ControlManager::getSessionAutoOffRemainMs() {
    CL_A40_MutexGuard_Semaphore v_guard(s_stateMutex, G_A40_MUTEX_TIMEOUT_100, __func__);
    if (!v_guard.isAcquired()) return 0;

    if (_session.runtimeAutoOffStartMs == 0) return 0;

    uint32_t elapsedMs = millis() - _session.runtimeAutoOffStartMs;
    uint32_t totalMs   = _session.runtimeAutoOffMin * 60000UL;
    if (elapsedMs >= totalMs) return 0;
    return totalMs - elapsedMs;
}
```

```cpp
static String _sessionStatusJson() {
    JsonDocument doc;
    auto sess = CL_CT10_ControlManager::getSessionSnapshot();

    doc["fan"]    = (sess.type == EN_CT10_SESSION_NONE) ? "off" : "on";
    doc["paused"] = (sess.state == EN_SESSION_PAUSED);

    if (sess.type == EN_CT10_SESSION_PLAYLIST) {
        const char* name = "";
        if (g_A20_config_root.profiles) {
            for (uint8_t i = 0; i < g_A20_config_root.profiles->count; i++) {
                if (g_A20_config_root.profiles->items[i].profileId ==
                    sess.payload.playlist.profileId) {
                    name = g_A20_config_root.profiles->items[i].name;
                    break;
                }
            }
        }
        doc["mode"]        = "playlist";
        doc["profileName"] = name;
        doc["currentStep"] = sess.payload.playlist.currentStepIdx + 1;
        doc["totalSteps"]  = sess.payload.playlist.totalSteps;
    } else if (sess.type == EN_CT10_SESSION_PRESET) {
        doc["mode"]      = "preset";
        doc["presetCode"] = sess.payload.preset.presetCode;
        doc["styleCode"]  = sess.payload.preset.styleCode;
    } else if (sess.type == EN_CT10_SESSION_FIXED) {
        doc["mode"]    = "fixed";
        doc["percent"] = sess.payload.fixed.percent;
    }

    if (sess.runtimeAutoOffStartMs > 0) {
        doc["timerRemainSec"] =
            CL_CT10_ControlManager::getSessionAutoOffRemainMs() / 1000;
    }

    extern float CT10_readTempC();
    extern float CT10_readHumidity();
    doc["tempC"]    = round(CT10_readTempC() * 10) / 10.0;
    doc["humidity"] = round(CT10_readHumidity());

    String out;
    serializeJson(doc, out);
    return out;
}

String CT10_executeAIAction(const char* fnName, JsonObjectConst args) {
    if (!fnName) return "error:null_fn";

    // ==================================================
    // start_playlist
    // ==================================================
    if (strcmp(fnName, "start_playlist") == 0) {
        uint16_t profileId = A40_ComFunc::Json_getNum<uint16_t>(args, "profileId", 0);

        // 이름으로 검색 (profileId 없으면)
        if (profileId == 0) {
            const char* name = A40_ComFunc::Json_getStr(args, "profileName", "");
            if (name[0] && g_A20_config_root.profiles) {
                for (uint8_t i = 0; i < g_A20_config_root.profiles->count; i++) {
                    if (strcasecmp(g_A20_config_root.profiles->items[i].name, name) == 0) {
                        profileId = g_A20_config_root.profiles->items[i].profileId;
                        break;
                    }
                }
            }
        }
        if (profileId == 0) return "error:profile_not_found";
        bool ok = CL_CT10_ControlManager::startPlaylistManual((uint8_t)profileId);
        return ok ? "ok" : "error:start_failed";
    }

    // ==================================================
    // start_preset
    // ==================================================
    if (strcmp(fnName, "start_preset") == 0) {
        const char* pc = A40_ComFunc::Json_getStr(args, "presetCode", "");
        const char* sc = A40_ComFunc::Json_getStr(args, "styleCode", "BALANCE");
        if (!pc[0]) return "error:missing_preset";
        bool ok = CL_CT10_ControlManager::startPresetManual(pc, sc);
        return ok ? "ok" : "error:start_failed";
    }

    // ==================================================
    // start_fixed
    // ==================================================
    if (strcmp(fnName, "start_fixed") == 0) {
        float pct = A40_ComFunc::Json_getNum<float>(args, "percent", 50.0f);
        pct = constrain(pct, 0.0f, 100.0f);
        bool ok = CL_CT10_ControlManager::startFixedManual(pct);
        return ok ? "ok" : "error:start_failed";
    }

    // ==================================================
    // pause/resume/stop
    // ==================================================
    if (strcmp(fnName, "pause_session") == 0) {
        return CL_CT10_ControlManager::pauseSession() ? "ok" : "error:not_active";
    }
    if (strcmp(fnName, "resume_session") == 0) {
        return CL_CT10_ControlManager::resumeSession() ? "ok" : "error:not_paused";
    }
    if (strcmp(fnName, "stop_session") == 0) {
        return CL_CT10_ControlManager::stopSession() ? "ok" : "error:no_session";
    }

    // ==================================================
    // set_timer ★ (M6/C2 실제 동작)
    // ==================================================
    if (strcmp(fnName, "set_timer") == 0) {
        uint32_t minutes = A40_ComFunc::Json_getNum<uint32_t>(args, "minutes", 0);
        if (minutes == 0 || minutes > 1440) return "error:invalid_minutes";

        // 세션 없으면 FIXED 50%로 시작
        auto sess = CL_CT10_ControlManager::getSessionSnapshot();
        if (sess.type == EN_CT10_SESSION_NONE) {
            bool started = CL_CT10_ControlManager::startFixedManual(50.0f);
            if (!started) return "error:start_failed";
        }

        // 세션 AutoOff 설정
        bool ok = CL_CT10_ControlManager::setSessionAutoOff(minutes);
        return ok ? "ok" : "error:timer_failed";
    }

    // ==================================================
    // get_status ★ (N5 JSON 반환)
    // ==================================================
    if (strcmp(fnName, "get_status") == 0) {
        return _sessionStatusJson();
    }

    // ==================================================
    // add_schedule ★ (C3 완전 구현)
    // ==================================================
    if (strcmp(fnName, "add_schedule") == 0) {
        const char* name = A40_ComFunc::Json_getStr(args, "name", "AI 스케줄");
        const char* startTime = A40_ComFunc::Json_getStr(args, "startTime", "08:00");
```

```cpp
    String text;
    bool hasFunctionCall;

static bool _parseGeminiResponse(const String& response, AIParsedTurn& out) {
    JsonDocument doc;
    if (deserializeJson(doc, response) != DeserializationError::Ok) return false;

    JsonArray candidates = doc["candidates"].as<JsonArray>();
    if (candidates.isNull() || candidates.size() == 0) return false;

    // ★ C5: parts를 JsonArray로 정확히 받음
    JsonArray parts = candidates[0]["content"]["parts"].as<JsonArray>();
    if (parts.isNull()) return false;

    out.hasFunctionCall = false;

    for (JsonObject part : parts) {
        // Function Call
        JsonObject fc = part["functionCall"].as<JsonObject>();
        if (!fc.isNull()) {
            out.hasFunctionCall = true;
            out.fnName = A40_ComFunc::Json_getStr(fc, "name", "");
            JsonObjectConst args = fc["args"].as<JsonObjectConst>();
            out.fnArgs.set(args);
            out.callId = A40_ComFunc::Json_getStr(fc, "id", "");
            break;
        }

        // Text
        const char* t = A40_ComFunc::Json_getStr(part, "text", nullptr);
        if (t && t[0]) {
            if (out.text.length() > 0) out.text += " ";
            out.text += t;
        }
    }

    return true;
}

// ======================================================
static void handleAIGemini(AsyncWebServerRequest* req) {
    if (!W10_checkApiKey(req)) { req->send(401); return; }

    JsonDocument in;
    uint8_t buf[4096];
    if (!W10_parseJsonBody(req, in, buf, sizeof(buf))) {
        req->send(400, "application/json", "{\"error\":\"invalid_body\"}");
        return;
    }

    const char* userMessage = A40_ComFunc::Json_getStr(
        in.as<JsonObjectConst>(), "message", "");
    if (!userMessage[0]) {
        req->send(400); return;
    }

    if (!g_A20_config_root.system ||
        !g_A20_config_root.system->security.geminiApiKey[0]) {
        req->send(400, "application/json",
            "{\"error\":\"gemini_api_key_not_set\"}");
        return;
    }

    const char* apiKey = g_A20_config_root.system->security.geminiApiKey;

    // ==================================================
    // Turn 1: 초기 요청 (Function Declaration 포함)
    // ==================================================
    JsonDocument turn1Req;
    turn1Req["system_instruction"]["parts"][0]["text"] = CT10_buildAIPrompt();

    // 대화 이력 (최근 6턴, N1)
    JsonArray contents = turn1Req["contents"].to<JsonArray>();
    JsonArrayConst histArr = in["history"].as<JsonArrayConst>();
    if (!histArr.isNull()) {
        uint8_t total = histArr.size();
        uint8_t startIdx = (total > 6) ? (total - 6) : 0;
        for (uint8_t i = startIdx; i < total; i++) {
            JsonObjectConst h = histArr[i];
            JsonObject c = contents.add<JsonObject>();
            c["role"] = A40_ComFunc::Json_getStr(h, "role", "user");
            c["parts"][0]["text"] = A40_ComFunc::Json_getStr(h, "text", "");
        }
    }

    JsonObject userTurn = contents.add<JsonObject>();
    userTurn["role"] = "user";
    userTurn["parts"][0]["text"] = userMessage;

    // Function Declarations
    JsonArray tools = turn1Req["tools"].to<JsonArray>();
    JsonArray decls = tools.add<JsonObject>()["function_declarations"].to<JsonArray>();
    CT10_appendAIFunctionDeclarations(decls);

    String turn1Body;
    serializeJson(turn1Req, turn1Body);

    String turn1Resp, errMsg;
    int httpCode = _geminiPost(apiKey, turn1Body, turn1Resp, errMsg);
    if (httpCode != 200) { _sendGeminiError(req, httpCode); return; }

    // ==================================================
    // Turn 1 응답 파싱
    // ==================================================
    AIParsedTurn turn1;
    if (!_parseGeminiResponse(turn1Resp, turn1)) {
        req->send(502, "application/json", "{\"error\":\"parse_failed\"}");
        return;
    }

    // ==================================================
    // 액션 없음 → 텍스트 응답만
    // ==================================================
    if (!turn1.hasFunctionCall) {
        JsonDocument out;
        out["ok"]   = true;
        out["text"] = turn1.text;
        out["actions"] = JsonArray();  // empty
        W10_sendJson(req, 200, out);
        return;
    }

    // ==================================================
    // 액션 실행
    // ==================================================
    String actionResult = CT10_executeAIAction(turn1.fnName.c_str(),
                                               turn1.fnArgs.as<JsonObjectConst>());

    // ==================================================
    // Turn 2: Function 결과 재주입 (C1 - 2-turn)
    // ==================================================
    JsonDocument turn2Req;
    turn2Req["system_instruction"] = turn1Req["system_instruction"];

    JsonArray t2Contents = turn2Req["contents"].to<JsonArray>();
    // 이력 재구성
    for (JsonObject c : contents) t2Contents.add(c);

    // model의 FunctionCall 응답 재구성
    JsonObject modelTurn = t2Contents.add<JsonObject>();
    modelTurn["role"] = "model";
    JsonObject fcPart = modelTurn["parts"][0]["functionCall"].to<JsonObject>();
    fcPart["name"] = turn1.fnName;
    fcPart["args"] = turn1.fnArgs;

    // functionResponse
    JsonObject resultTurn = t2Contents.add<JsonObject>();
    resultTurn["role"] = "user";
    JsonObject fr = resultTurn["parts"][0]["functionResponse"].to<JsonObject>();
    fr["name"] = turn1.fnName;
    fr["response"]["result"] = actionResult;

    String turn2Body;
    serializeJson(turn2Req, turn2Body);

    String turn2Resp;
    httpCode = _geminiPost(apiKey, turn2Body, turn2Resp, errMsg);

    JsonDocument out;
    out["ok"] = true;
    JsonArray actionsArr = out["actions"].to<JsonArray>();
    JsonObject act = actionsArr.add<JsonObject>();
    act["name"]   = turn1.fnName;
    act["args"]   = turn1.fnArgs;
    act["result"] = actionResult;

    if (httpCode == 200) {
        AIParsedTurn turn2;
        if (_parseGeminiResponse(turn2Resp, turn2) && turn2.text.length() > 0) {
            out["text"] = turn2.text;
        } else {
            // Fallback: 액션 실행만 알림
            out["text"] = "요청을 실행했습니다.";
        }
    } else {
        // Turn 2 실패 → 액션 결과만 반환
        out["text"] = "요청을 실행했습니다. (응답 생성 일시 오류)";
    }

    // 최신 세션 상태
    JsonDocument stateDoc;
    CL_CT10_ControlManager::instance().exportStateJson_v02(stateDoc);
    out["session"] = stateDoc["control"]["session"];

    W10_sendJson(req, 200, out);
}
```

```javascript
// 145.ai.client.js — AI 클라이언트 (스트리밍 + 이력 + 캐시)
// =========================================================
window.SNW = window.SNW || {};
(function(SNW) {
    'use strict';

    const CACHE_MAX = 20;      // 응답 캐시
    const HISTORY_MAX = 20;    // 이력 (10턴)

    let _cache = new Map();
    let _pending = null;

    SNW.AIClient = {
        // =========================================================
        // 이력 관리 (localStorage)
        // =========================================================
        loadHistory() {
            try {
                const saved = localStorage.getItem('snw.ai.history');
                if (!saved) return [];
                const arr = JSON.parse(saved);
                return arr.slice(-HISTORY_MAX);
            } catch { return []; }
        },

        saveHistory(history) {
            try {
                const toSave = (history || []).slice(-HISTORY_MAX);
                localStorage.setItem('snw.ai.history', JSON.stringify(toSave));
            } catch {}
        },

        clearHistory() {
            try { localStorage.removeItem('snw.ai.history'); } catch {}
        },

        // =========================================================
        // 커맨드 전송 (일반 POST, 2-turn 백엔드 처리)
        // =========================================================
        async send(message, history) {
            // 캐시 확인 (N9)
            const cacheKey = `${message}|${(history || []).length}`;
            if (_cache.has(cacheKey)) {
                const cached = _cache.get(cacheKey);
                if (Date.now() - cached.ts < 60000) {   // 60초 유효
                    SNW.LogUtil.debug('[AIClient] cache hit:', message);
                    return cached.data;
                }
                _cache.delete(cacheKey);
            }

            // 중복 요청 방지
            if (_pending) return _pending;

            _pending = (async () => {
                try {
                    const res = await SNW.Api.getAiCommand(message, history);

                    // 캐시 저장
                    _cache.set(cacheKey, { ts: Date.now(), data: res });
                    if (_cache.size > CACHE_MAX) {
                        const firstKey = _cache.keys().next().value;
                        _cache.delete(firstKey);
                    }

                    return res;
                } finally {
                    _pending = null;
                }
            })();

            return _pending;
        },

        // =========================================================
        // 스트리밍 (SSE) — N3
        // =========================================================
        // 백엔드가 streamGenerateContent 지원 시 사용
        async *sendStreaming(message, history) {
            const url = SNW.CFG.API.aiStream || (SNW.CFG.API.aiGemini + '/stream');

            try {
                const response = await fetch(url, {
                    method: 'POST',
                    headers: {
                        'Content-Type': 'application/json',
                        'X-API-Key': localStorage.getItem(SNW.CFG.LS_KEY.API_KEY) || '',
                    },
                    body: JSON.stringify({ message, history: (history || []).slice(-6) }),
                });

                if (!response.ok) {
                    throw new Error(`HTTP ${response.status}`);
                }

                const reader = response.body.getReader();
                const decoder = new TextDecoder();
                let buffer = '';

                while (true) {
                    const { done, value } = await reader.read();
                    if (done) break;

                    buffer += decoder.decode(value, { stream: true });
                    const lines = buffer.split('\n');
                    buffer = lines.pop() || '';

                    for (const line of lines) {
                        if (!line.startsWith('data: ')) continue;
                        const data = line.substring(6).trim();
                        if (data === '[DONE]') return;

                        try {
                            const parsed = JSON.parse(data);
                            if (parsed.text) yield parsed.text;
                        } catch {}
                    }
                }
            } catch (e) {
                SNW.LogUtil.warn('[AIClient] streaming failed, fallback to non-stream', e);
                // 폴백: 일반 요청
                const res = await this.send(message, history);
                yield res.text;
            }
        },
    };
})(window.SNW);
```

```cpp
static void handleAIStream(AsyncWebServerRequest* req) {
    // Stage 8.2에서는 "일반 응답을 SSE 형식으로 감싸서 전송"
    // (Gemini 실제 스트리밍은 8.3으로 이월)

    // 8.2: 단순 wrap
    AsyncWebServerResponse* response = req->beginChunkedResponse(
        "text/event-stream",
        [](uint8_t* buffer, size_t maxLen, size_t index) -> size_t {
            // 한 번에 전체 응답 전송 (streaming 시뮬레이션)
            static bool sent = false;
            if (sent) return 0;
            sent = true;

            const char* payload = "data: {\"text\":\"스트리밍 준비 중...\"}\n\ndata: [DONE]\n\n";
            size_t len = strlen(payload);
            if (len > maxLen) len = maxLen;
            memcpy(buffer, payload, len);
            return len;
        });
    response->addHeader("Cache-Control", "no-cache");
    req->send(response);
}
```
