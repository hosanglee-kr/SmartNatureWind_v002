(C) Gzip / 번들 개선 (G-1~G-4)

C-1. 각 항목의 의미

G-1. Accept-Encoding: gzip 무조건 서빙

현재:

```cpp
if (exists(gz)) {
    addHeader("Content-Encoding", "gzip");  // ← 헤더 검사 없음
    send();
}
```

문제:

· HTTP 표준 위반 (클라이언트가 gzip 미지원임을 명시해도 압축본 전송)
· curl (헤더 없음) → 압축 해제 실패 → "깨진 파일" 수신
· wget, 오래된 IoT 클라이언트 등에서 문제

해결:

```cpp
bool v_acceptsGzip = p_request->hasHeader("Accept-Encoding") 
                  && p_request->getHeader("Accept-Encoding")->value().indexOf("gzip") >= 0;
if (v_acceptsGzip && exists(gz)) {
    // gzip 서빙
} else {
    // raw 원본 서빙 (폴백)
}
```

효과: HTTP 표준 준수, 모든 클라이언트 호환
리스크: 없음 (분기 추가만)

G-2. serveStatic 경로가 Gzip 우회

현재:

```cpp
s_server->serveStatic("/html_v3", LittleFS, "/html_v3");
```

· Short URI(/P010_main_0200.html) → 커스텀 라우트 → Gzip ✅
· Long path(/html_v3/P010_main_0200.html) → 라이브러리 내부 서빙 → raw ⚠️

문제: 브라우저가 상대경로로 접근 시 Gzip 이점 상실 (번들 압축 77% 무효화)
해결 옵션:

· (a) HTML 내부 태그를 모두 절대 short URI로 통일 (/P010_...) — 파이프라인 수정
· (b) serveStatic 사용 안 하고 커스텀 Gzip 라우트로 대체 — 코드 변경

효과: 번들 + Gzip 이점 100% 활용
리스크: 중간 (파이프라인 또는 라우트 구조 변경)

G-3. 번들 소스 누락 시 조용히 skip

현재:

```python
if not js_file.is_file():
    print(f"  [WARN] 번들 소스 파일 누락: {rel_name}", ...)
    continue   # ← 계속 진행
```

문제:

· 8개 중 1개 없으면 번들에서 누락 → 런타임 JS 에러 (ReferenceError)
· 빌드는 성공 → 개발자가 원인 모름

해결:

```python
if not js_file.is_file():
    print(f"  [ERROR] 번들 소스 파일 누락: {rel_name}", ...)
    sys.exit(1)
```

효과: 빌드 시점에 즉시 실패 → 디버깅 시간 절감
리스크: 없음 (실패 시 명확한 메시지)

G-4. serveStatic의 .gz 미지원

현재: ESPAsyncWebServer의 serveStatic은 .gz 파일을 인식하지 못함
문제: G-2와 동일 (long path 접근 시 Gzip 무효)
해결: G-2의 (b)와 동일 (커스텀 라우트로 완전 대체)

항목 내용
효과 HTTP 표준 준수 + 번들/Gzip 이점 100% 활용 + 빌드 실패 조기 감지

```python
#!/usr/bin/env python3
"""
[A-P0] v0200 계약 문서 테이블에 잘못 삽입된 개정이력 행 자동 제거

문제:
  - v017 → v0200 승격 시 개정이력 행이 §1~§7 모든 테이블에 반복 삽입됨
  - 컬럼 수 불일치로 마크다운 렌더링 붕괴
  - §개정이력 섹션의 동일 행은 정상이므로 보존 대상

해결:
  - "## N. 개정 이력" 섹션 이전 본문에서만 정규식 제거
  - 개정이력 테이블 자체는 건드리지 않음

사용:
  python src/v0200/tools_0200/fix_table_bleed.py --dry-run
  python src/v0200/tools_0200/fix_table_bleed.py
"""

from __future__ import annotations

import argparse
import re
import sys
from pathlib import Path

# Windows 콘솔 UTF-8
if sys.platform == "win32":
    try:
        if sys.stdout and hasattr(sys.stdout, "reconfigure"):
            sys.stdout.reconfigure(encoding="utf-8")
        if sys.stderr and hasattr(sys.stderr, "reconfigure"):
            sys.stderr.reconfigure(encoding="utf-8")
    except Exception:
        pass

# 대상 문서 (contract_doc_0200 디렉토리 내)
TARGET_DOCS: tuple[str, ...] = (
    "README_0200.md",
    "SPEC_0200.md",
    "CONTRACT_0200.md",
    "STATE_0200.md",
    "FLOW_0200.md",
    "BUDGET_0200.md",
    "TEST_PLAN_0200.md",
)

# 개정이력 섹션 시작 마커 (이후는 삭제 금지)
REVISION_SECTION_MARKERS = (
    "## 8. 개정 이력",
    "## 개정 이력",
    "## 10. 개정 이력",
    "## 9. 개정 이력",
    "## 7. 개정 이력",
    "## 6. 개정 이력",
)

# 제거 대상 패턴:
#   | 2026-10-19 | v2.0 | v0200 승격: ... | Antigravity AI |
BLEED_PATTERN = re.compile(
    r'^\|\s*2026-10-19\s*\|\s*v2\.0\s*\|.*?Antigravity AI\s*\|\s*$\r?\n',
    re.MULTILINE,
)


def find_revision_section_index(content: str) -> int:
    """개정이력 섹션 시작 위치 반환 (없으면 -1)."""
    for marker in REVISION_SECTION_MARKERS:
        idx = content.find(marker)
        if idx >= 0:
            return idx
    return -1


def fix_document(path: Path, dry_run: bool) -> int:
    """단일 문서 수정. 제거된 행 수 반환."""
    if not path.is_file():
        print(f"  [SKIP] 파일 없음: {path.name}")
        return 0

    original = path.read_text(encoding="utf-8")

    rev_idx = find_revision_section_index(original)
    if rev_idx < 0:
        # 개정이력 섹션 없으면 파일 전체에 적용
        body = original
        tail = ""
    else:
        body = original[:rev_idx]
        tail = original[rev_idx:]

    # 본문에서만 제거
    matches = BLEED_PATTERN.findall(body)
    removed_count = len(matches)

    if removed_count == 0:
        print(f"  [OK] {path.name}: 삽입된 행 없음")
        return 0

    new_body = BLEED_PATTERN.sub("", body)
    new_content = new_body + tail

    if dry_run:
        print(f"  [DRY] {path.name}: {removed_count}행 제거 예정")
        return removed_count

    path.write_text(new_content, encoding="utf-8")
    print(f"  [FIX] {path.name}: {removed_count}행 제거 완료")
    return removed_count


def main() -> int:
    parser = argparse.ArgumentParser(
        description="v0200 계약 문서 테이블 개정이력 행 자동 제거",
    )
    parser.add_argument(
        "-n", "--dry-run",
        action="store_true",
        help="파일 수정 없이 검사만",
    )
    parser.add_argument(
        "--dir",
        default="src/v0200/contract_doc_0200",
        help="문서 디렉토리 (기본: src/v0200/contract_doc_0200)",
    )
    args = parser.parse_args()

    root = Path(args.dir).resolve()
    if not root.is_dir():
        print(f"[ERROR] 디렉토리 없음: {root}", file=sys.stderr)
        return 1

    print("=" * 60)
    print(f" [A-P0] 테이블 개정이력 행 제거: {root}")
    if args.dry_run:
        print(" 모드: DRY-RUN")
    print("=" * 60)

    total_removed = 0
    for name in TARGET_DOCS:
        total_removed += fix_document(root / name, args.dry_run)

    print()
    print(f" 총 제거: {total_removed}행 ({'DRY-RUN' if args.dry_run else '적용 완료'})")
    return 0


if __name__ == "__main__":
    try:
        sys.exit(main())
    except KeyboardInterrupt:
        print("\n[ERROR] 사용자 중단", file=sys.stderr)
        sys.exit(130)
```

if sys.platform == "win32":

TARGETS: tuple[tuple[str, str], ...] = (

# 개정이력 테이블의 v2.0 행 (마지막 셀 Antigravity AI 앞에 병기)
V20_ROW = re.compile(
    r'^(\|\s*2026-10-19\s*\|\s*v2\.0\s*\|\s*)([^|]*?)(\s*\|\s*Antigravity AI\s*\|\s*)$',
    re.MULTILINE,
)


def patch_file(path: Path, suffix: str, dry_run: bool) -> int:
    if not path.is_file():
        print(f"  [SKIP] 파일 없음: {path.name}")
        return 0

    content = path.read_text(encoding="utf-8")
    modified = False

    def _repl(m: re.Match) -> str:
        nonlocal modified
        before, middle, after = m.group(1), m.group(2), m.group(3)
        # 이미 병기됐으면 skip
        if "유지)" in middle:
            return m.group(0)
        modified = True
        return f"{before}{middle.rstrip()}{suffix}{after}"

    new_content = V20_ROW.sub(_repl, content)

    if not modified:
        print(f"  [OK] {path.name}: 이미 반영 또는 대상 없음")
        return 0

    if dry_run:
        print(f"  [DRY] {path.name}: v2.0 행 병기 예정")
        return 1

    path.write_text(new_content, encoding="utf-8")
    print(f"  [FIX] {path.name}: v2.0 행 병기 완료")
    return 1

        total += patch_file(root / name, suffix, args.dry_run)

    print()
    print(f" 총 수정: {total}건 ({'DRY-RUN' if args.dry_run else '적용 완료'})")
    return 0


if __name__ == "__main__":

⚠️ 주의사항

1. ASYNCWEBSERVER_REGEX 플래그 필수
   · platformio.ini에 이미 -D ASYNCWEBSERVER_REGEX 있음 ✅
   · 없으면 regex 라우트 등록 실패 → 정적 서빙 전면 중단
2. W10_registerGzipServe 등록 순서
   · s_server->on()은 먼저 등록한 라우트가 우선
   · routeStaticAssets에서 다른 /html_v3/* 짧은 URI 라우트보다 먼저 등록됨
   · 짧은 URI(/P010_main_0200.html)는 W10_registerStaticRoute가 처리 → 충돌 없음
3. serveStatic 제거의 부작용
   · 기존 serveStatic은 /html_v3/ prefix 자동 처리
   · 대체 regex 라우트는 모든 파일 타입에 Gzip 검사 적용 → 성능 미미
4. Accept-Encoding 없는 클라이언트
   · curl 기본, wget 기본 → raw 원본 받음
   · 브라우저는 항상 gzip 요청 → 사용자 체감 없음
