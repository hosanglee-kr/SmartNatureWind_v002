### 2.2 `010.config.js` — `get()` 경로 검증 및 프로토타입 오염 방어 (`P1-5`)
- 잘못된 경로(`__proto__`, `constructor`, `prototype`) 및 비정상 키 차단, `Object.prototype.hasOwnProperty.call()` 검사 적용.

```js
get(path, fallback) {
    if (typeof path !== 'string' || !path) return fallback;
    if (!/^[a-zA-Z0-9_.]+$/.test(path)) return fallback;
    const parts = path.split('.');
    let cur = this;
    for (const p of parts) {
        if (p === '__proto__' || p === 'constructor' || p === 'prototype') return fallback;
        if (cur == null || !Object.prototype.hasOwnProperty.call(cur, p)) return fallback;
        cur = cur[p];
    }
    return cur === undefined ? fallback : cur;
}
```

## Stage 4. Core 유틸리티 · 상수 · i18n 계층 일괄 패치 (13건)

### 4.1 🔴 P0 — 보안 및 레이아웃 무결성

#### `P0-2` · `031.util.dom.js` — `html()` 비문자열 escape 강화 + `raw()` 헬퍼
- **문제**: 배열/객체가 `String(v)`로 강제 변환되어 `innerHTML`에 무방비 주입됨 (XSS 벡터).
- **해결**: `string`뿐 아니라 배열/객체도 모두 `this.escape(String(v))` 처리하고, 의도된 HTML 문자열만 `SNW.DomUtil.raw(str)`로 명시 opt-in 허용.

```js
html(strings, ...vals) {
    const div = document.createElement('div');
    div.innerHTML = strings.reduce((acc, s, i) => {
        const v = vals[i];
        let safe;
        if (v == null) {
            safe = '';
        } else if (typeof v === 'string') {
            safe = this.escape(v);
        } else if (typeof v === 'number' || typeof v === 'boolean') {
            safe = String(v);
        } else if (v && typeof v === 'object' && typeof v.__raw === 'string') {
            safe = v.__raw;
        } else {
            safe = this.escape(String(v));
        }
        return acc + s + (i < vals.length ? safe : '');
    }, '').trim();
    return div.firstElementChild;
},
raw(str) {
    return { __raw: String(str) };
}
```

#### `P0-3` · `030.util.level.js` + CSS — `applyTo()` 클래스 기반 레벨 필터
- **문제**: `el.style.display = show ? '' : 'none'` 복원 시 기존 `flex`/`grid` 인라인 스타일이 파괴됨.

패치 적용 후 오프라인 모드(`?offline=1`) 브라우저 콘솔에서 아래 검증 항목을 순차 실행해 회귀 여부를 확인합니다:

1. **`[A-1]` XSS 방어**: `SNW.DomUtil.html\`<div>${['<img src=x onerror=alert(1)>']}</div>\`` 결과가 `&lt;img`로 escape되고, `SNW.DomUtil.raw('<b>bold</b>')`만 HTML로 렌더링됨.
2. **`[A-2]` 레벨 필터 보존**: `display: flex` 요소에 `SNW.LevelUtil.set('L2', { reload: false })` → `L4` 복원 시 `style.display === 'flex'` 유지.
3. **`[B-1]` i18n 속성 확장**: `[data-i18n-placeholder]` 요소에 `SNW.I18n.applyTo(document)` 실행 시 placeholder 번역 반영.
4. **`[B-2]` Feedback 클램프 & 다국어**: `getIntensityGuide(200)`이 100으로 클램프되고, `setLang('en')` 전환 시 영문 반환.
5. **`[B-4]` Clock 인터벌 정리**: 동일 요소에 `startClock()` 중복 호출 후 `stopClock(el)` 호출 시 누수 없음 (`_clocks` 비공개 유지).
6. **`[Toast]` 구조분해 호출**: `const { success, error } = SNW.ToastUtil; success('ok');` 시 `TypeError` 없이 정상 동작.

8. **`[Offline]` A-1~A-4 / B-1~B-3**: `getChartHistory()` 120p 반환, `patchProfiles()` 캐시 반영, `setMode()` → `control.profileMode` 동기화, `setTimer(1)` 만료 시 `AUTOOFF_STOPPED(5)` 전이, `SNW.Offline.setActive(false)` 전환 확인.

### 5.2 호출부 영향 주의사항 및 후속 검증 대상
- **호출부 영향 주의사항**:
  1. `DomUtil.html()` 내 pre-escaped HTML 문자열(`tooltip()` 등) 삽입부는 `DomUtil.raw(...)`로 감싸야 함.
  2. `LevelUtil.applyTo()` 정상 동작을 위해 CSS에 `.snw-hidden-by-level { display: none !important; }` 필수 포함.
  3. `LevelUtil.set()` 기본값은 `reload: true` 유지 (SPA 무새로고침 전환은 `{ reload: false }` opt-in).
  4. `TimeUtil.startClock()` 반환 타입은 `number`로 유지되며, 명시적 정리는 `stopClock(el)` 사용 권장.

- **설계 (`040.api.js`)**:
```js
function buildQuery(params) {
    const qs = new URLSearchParams();
    Object.entries(params || {}).forEach(([k, v]) => {
        if (v !== undefined && v !== null) qs.set(k, String(v));
    });
    const s = qs.toString();
    return s ? `?${s}` : '';
}

// getMonitor / overrideFixed 적용 예
getMonitor(type, range) {
    return _fetch(`${SNW.CFG.API.monitor}${buildQuery({ type, range })}`);
}
// reload(): Zero-Reboot RAM 즉시 반영 구조이므로 단발 POST 유지 (Q-4 확정 안 A)
```
