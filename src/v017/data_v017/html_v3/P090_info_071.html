Smart Nature Wind

    도움말 및 시스템 정보

    💡 프로젝트 개요

    Smart Nature Wind는 ESP32 기반의 자연풍 시뮬레이터입니다. 난류, 돌풍, 열기포 등 실제 자연 바람의 복잡한 물리 현상을 정밀하게 재현하여 쾌적한 실내 환경을 제공합니다.

    스케줄 / 사용자 프로파일 / 즉시 실행(Override) 3가지 제어 방식을 지원하며, Wi-Fi 기반 웹 UI로 어디서든 설정·모니터링할 수 있습니다.

    💻 기술 스택
    • 하드웨어ESP32 (Wi-Fi, Web Server)
    • 백엔드Arduino Core, PlatformIO (C++)
    • 프론트엔드HTML5 / CSS3 / Vanilla JS
    • 차트Chart.js 4.x + zoom plugin
    • 통신REST API + WebSocket
    • 저장소LittleFS (JSON) + NVS
    📚 사용 가이드
    1. 초기 설정

    시스템 설정 페이지에서 Wi-Fi 연결을 확인하고, 필요 시 API Key를 설정하세요.

    2. 풍속 즉시 실행

    Main 페이지에서 프리셋·강도·가변성을 조정하고 "🎬 임시 적용" 버튼으로 즉시 실행할 수 있습니다.

    3. 사용자 프로파일

    UserProfile 페이지에서 자주 쓰는 바람 설정을 저장해두고, Main에서 즉시 실행할 수 있습니다.

    4. 스케줄 자동화

    Schedule 페이지에서 요일·시간대별로 프로파일이 자동 적용되도록 예약할 수 있습니다.

    5. 실시간 모니터링

    Chart 페이지에서 풍속·PWM·난류·돌풍·열기포 이벤트를 실시간으로 확인할 수 있습니다.

    ❓ 자주 묻는 질문
    Q. 팬이 전혀 돌지 않습니다.
    시스템 설정에서 팬 PWM 핀·주파수가 실제 하드웨어와 일치하는지 확인하세요. Main 페이지의 "팬 전원" 체크가 On 상태인지, 강도(Intensity)가 0이 아닌지도 확인하세요.
    Q. 스케줄이 실행되지 않습니다.
    시간 동기화(NTP)가 완료되었는지 확인하세요. Main 페이지 상단의 "시간 미동기" 배지가 표시되면 스케줄이 동작하지 않습니다. 시스템 설정에서 NTP 서버와 타임존을 확인하세요.
    Q. 프로파일과 스케줄 중 뭐가 우선인가요?
    제어 우선순위는 Override(임시 적용) > 사용자 프로파일 > 스케줄 순입니다. Main에서 즉시 실행하면 스케줄보다 우선 적용됩니다.
    Q. 설정이 저장되었는데 재부팅 후 초기화됩니다.
    "💾 풍속 설정 저장"을 눌러 LittleFS에 저장했는지 확인하세요. 저장하지 않은 값은 재부팅 시 기본값으로 복원됩니다.
    Q. API Key를 잃어버렸습니다.
    장치를 공장 초기화하거나 시리얼 콘솔에서 재설정해야 합니다. API Key는 보안 자산이므로 안전한 곳에 보관하세요.
