# `W10_Web_WS_0203.cpp` 상세 Spec

## ⚙️ 시스템 스펙 요약: W10_Web_WS_0203.cpp

**5대 AsyncWebSocket 채널(State/Logs/Chart/Metrics/Summary)**의 **핸드셰이크 인증(`_wsHandshakeAuth`)**, **클라이언트 정리(`wsCleanupTick`)**, 및 **JSON 브로드캐스트(`_broadcast`, `broadcastState/Metrics/Chart/Summary`)**를 구현하는 파일입니다.

### 💾 구조체 및 타입 정의 (Structs & Types)

*   **`s_wsServerState` / `s_wsServerLogs` / `s_wsServerChart` / `s_wsServerMetrics` / `s_wsServerSummary`**
    *   **설명:** `CL_W10_WebAPI`가 관리하는 5개 `AsyncWebSocket*` 엔드포인트 인스턴스입니다.
    *   **사용처:** `routeWebSocket()`에서 등록되고 `broadcast*()` 및 `CL_D10_Logger`에서 실시간 푸시에 사용됩니다.

### 🛠️ 함수 정의 및 시그니처 (Functions & Signatures)

| 함수명 | 반환 타입 | 주요 기능 | 핵심 로직/특징 |
| :--- | :--- | :--- | :--- |
| **`_wsHandshakeAuth`** | `static bool` | WebSocket 연결 요청 시 API Key/인증 헤더를 검증합니다. | 1. 보안 설정이 활성화된 경우 미인증 핸드셰이크를 거부합니다. |
| **`wsCleanupTick`** | `void` | 끊기거나 유휴 상태인 WS 클라이언트를 주기적으로 정리(`cleanupClients()`)합니다. | 1. 소켓 리소스 고갈을 방지합니다. |
| **`routeWebSocket`** | `void` | 5대 WS 엔드포인트를 생성하고 이벤트 핸들러(`onEvent`)를 `AsyncWebServer`에 등록합니다. | 1. `CL_D10_Logger::attachWebSocket(s_wsServerLogs)`로 로그 스트리밍을 연결합니다. |
| **`_broadcast` / `broadcastState` / `broadcastMetrics` / `broadcastChart` / `broadcastSummary`** | `void` | 연결된 클라이언트 수(`p_ws->count() > 0`)를 확인한 뒤 `JsonDocument`를 직렬화해 일괄 전송합니다. | 1. 구독 클라이언트가 없으면 직렬화를 건너뛰어 CPU를 절약합니다. |

### 📚 포함 헤더 및 외부 의존성 (Includes & Dependencies)

*   **`"W10_Web_0203.h"` / `"D10_Logger_0203.h"` / `<ESPAsyncWebServer.h>`**:
    *   `AsyncWebSocket` 관리 및 실시간 로그/상태 브로드캐스트에 사용됩니다.
