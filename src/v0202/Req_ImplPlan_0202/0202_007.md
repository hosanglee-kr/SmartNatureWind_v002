
스크린샷을 보니 이전에 제안했던 아코디언 구조와 2열 그리드가 아주 잘 적용되어 모바일에서 훨씬 쾌적해졌습니다.

하지만 실제 사용자 입장에서 조작해 보면 여전히 몇 가지 직관성을 해치는 요소들이 보입니다. "입력 항목 명확화", "기능 개선(순서 변경)", "UI 다듬기" 관점에서 추가 개선안을 제안합니다.

---

1. 입력 및 수정 항목 명확화 (가장 시급)

· 프리셋/스타일 텍스트 입력 → 드롭다운(Select) 변경
  · 현상: 현재 HARBOR_BREEZE, BALANCE처럼 영문 코드를 직접 텍스트로 입력해야 합니다. 오타가 나면 서버에서 거부되거나 작동하지 않습니다.
  · 개선: 백엔드에 정의된 프리셋(10종)과 스타일(5종) 목록을 드롭다운(<select>)으로 제공하여 한글 라벨(예: 항구 바람, 균형)로 선택하게 변경해야 합니다.
· 조건부 입력 필드 비활성화(Disabled)
  · 현상: '예약 종료' 체크박스가 해제되어 있어도 아래 '종료 시간' 인풋은 활성화되어 있어 사용자가 입력할 수 있습니다.
  · 개선: 체크박스 상태에 따라 하위 입력 필드에 disabled 속성을 부여하여 회색으로 비활성화해야 합니다. (온도 종료, PIR 설정도 동일)
· 용어의 명확화
  · On(분) / Off(분)보다는 작동 시간(분) / 정지 시간(분)이 직관적입니다.
  · 모달 상단 제목이 단순히 "편집"인데, "스케줄 수정: Morning Cool Breeze" 등으로 명확히 표시하는 것이 좋습니다.

2. 사용 기능 관점 개선 (실행 순서 변경)

· 세그먼트 실행 순서 변경 기능 추가
  · 현상: 세그먼트 1, 2가 추가된 순서대로 무조건 실행됩니다. 사용자가 순서를 바꾸려면 삭제 후 다시 추가해야 합니다.
  · 개선: 각 세그먼트 카드 헤더 우측(휴지통 옆)에 ▲(위로), ▼(아래로) 버튼을 추가하여 배열의 순서를 직관적으로 변경할 수 있게 해야 합니다.
· 아코디언 닫힘 시 요약 정보 표시
  · 현상: '바람 세그먼트' 아코디언을 접으면 어떤 설정인지 알 수 없습니다.
  · 개선: <summary> 영역에 요약 텍스트를 노출합니다. (예: 바람 세그먼트 (2개) 또는 20분/10분 프리셋 → 15분/5분 고정)

3. UI/UX 시각적 다듬기

· + 세그먼트 추가 버튼 시각적 무게감 조절
  · 현상: 파란색(Primary) 버튼이라 화면에서 너무 눈에 띄어 "확인(저장)" 버튼보다 시선이 먼저 갑니다.
  · 개선: 보조 액션(Secondary)이므로 회색 테두리 버튼이나 점선 테두리 버튼으로 변경하여 저장 버튼과의 위계를 명확히 해야 합니다.
· 세그먼트 삭제 버튼(휴지통)의 오조작 방지
  · 모바일에서 휴지통 아이콘을 터치하려다 실수로 누를 수 있습니다. 삭제 시 확인 절차(confirm 또는 Undo 토스트)를 명확히 하거나, 버튼 크기를 유지하되 색상을 조금 더 차분하게(회색 → 터치 시 빨간색) 변경하는 것을 고려할 수 있습니다.

🛠️ 즉시 적용 가능한 개선 코드 (프리셋 드롭다운 및 순서 변경)

이 개선안을 반영하기 위해 220.page.schedule.js의 _openEditor 내부 renderSegs 함수를 아래와 같이 수정하시면 됩니다. (230.page.profiles.js도 동일하게 적용)

```javascript
// renderSegs 함수 내부 (세그먼트 카드 렌더링 부분)

// 1. 프리셋/스타일 드롭다운 옵션 생성 헬퍼
const presetOptions = Object.keys(SNW.C.PRESET_CODE).map(code => 
    `<option value="${code}" ${seg.presetCode === code ? 'selected' : ''}>${SNW.I18n.t('preset.' + code) || code}</option>`
).join('');

const styleOptions = Object.keys(SNW.C.STYLE_CODE).map(code => 
    `<option value="${code}" ${seg.styleCode === code ? 'selected' : ''}>${SNW.I18n.t('style.' + code) || code}</option>`
).join('');

// 2. 세그먼트 카드 HTML (순서 변경 버튼 및 드롭다운 적용)
segDiv.innerHTML = `
    <div class="snw-seg-header">
        <div style="display:flex; align-items:center; gap:8px;">
            <span class="snw-seg-title">세그먼트 ${idx + 1}</span>
            ${idx > 0 ? `<button type="button" class="snw-btn-icon" data-move="up" data-idx="${idx}" style="font-size:10px;">▲</button>` : ''}
            ${idx < segs.length - 1 ? `<button type="button" class="snw-btn-icon" data-move="down" data-idx="${idx}" style="font-size:10px;">▼</button>` : ''}
        </div>
        <button type="button" class="snw-btn-icon" data-remove-seg="${idx}" style="color:var(--snw-text-dim);">🗑</button>
    </div>
    <div class="snw-seg-grid">
        <label>
            작동 시간(분)
            <input type="number" class="seg-on" min="0" max="1440" value="${seg.onMinutes}">
        </label>
        <label>
            정지 시간(분)
            <input type="number" class="seg-off" min="0" max="1440" value="${seg.offMinutes}">
        </label>
        <label style="grid-column: span 2;">
            모드
            <select class="seg-mode">
                <option value="PRESET" ${seg.mode === 'PRESET' ? 'selected' : ''}>프리셋</option>
                <option value="FIXED"  ${seg.mode === 'FIXED'  ? 'selected' : ''}>고정풍속</option>
            </select>
        </label>
        <div class="snw-seg-preset-area" style="display: ${seg.mode === 'PRESET' ? 'grid' : 'none'};">
            <label>
                프리셋
                <select class="seg-preset">${presetOptions}</select>
            </label>
            <label>
                스타일
                <select class="seg-style">${styleOptions}</select>
            </label>
        </div>
        <div class="snw-seg-fixed-area" style="display: ${seg.mode === 'FIXED' ? 'block' : 'none'};">
            <label>
                고정 풍속(%)
                <input type="number" class="seg-fixed" min="0" max="100" value="${seg.fixedSpeed || 0}">
            </label>
        </div>
    </div>`;

// 3. 순서 변경 이벤트 리스너 추가
segDiv.querySelectorAll('[data-move]').forEach(btn => {
    btn.addEventListener('click', (e) => {
        const dir = e.target.getAttribute('data-move');
        const currentIdx = parseInt(e.target.getAttribute('data-idx'));
        const targetIdx = dir === 'up' ? currentIdx - 1 : currentIdx + 1;
        
        if (targetIdx >= 0 && targetIdx < segs.length) {
            // 배열 순서 교체
            [segs[currentIdx], segs[targetIdx]] = [segs[targetIdx], segs[currentIdx]];
            renderSegs(segs); // 재렌더링
        }
    });
});

// 4. 세그먼트 추가 버튼 스타일 변경 (파란색 -> 회색)
// content.querySelector('#btn-add-seg').className = 'snw-btn'; // primary 제거
```

이 개선안을 적용하면 사용자가 영문 코드를 외울 필요 없이 드롭다운으로 선택하고, 직관적으로 세그먼트 순서를 바꿀 수 있어 앱의 완성도가 크게 올라갈 것입니다.



---

요청하신 대로 구현 코드는 배제하고, 순수하게 기획 및 기획 관점의 UI/UX 개선안만 도출하여 정리했습니다.

특히 사용자님이 지적하신 "프리셋/스타일 외에 풍속 등 필수 설정"을 어떻게 녹여낼지에 대한 구조적 설계안을 중점적으로 다루었습니다.

---

1. 필수 설정 항목 추가 및 구조 개편 (가장 중요)

현재는 '프리셋(예: OCEAN)'을 선택하면 해당 프리셋의 고정된 강도와 변동성으로만 동작합니다. 스케줄/프로필 단위에서 세밀한 제어를 위해 파라미터 오버라이드(Override) 개념을 도입해야 합니다.

· 세그먼트별 '고급 물리 설정(Advanced Physics)' 접이식 영역 추가
  · 위치: 모드(프리셋 선택) 하단에 [고급 설정 (선택 사항)] 아코디언/토글 추가.
  · 세부 입력 항목:
    1. 강도 (Intensity, 0~100%): 프리셋의 기본 세기를 무시하고 이 세그먼트에서만 적용할 풍속 강도. (슬라이더 또는 숫자 인풋)
    2. 변동성 (Variability, 0~100%): 바람의 불규칙한 정도.
    3. 돌풍 빈도 (Gust Freq, 0~100%): 돌풍이 발생하는 빈도.
  · 설계 포인트: 기본적으로 입력창을 비워두거나(Placeholder로 "프리셋 기본값 사용" 표시), 값을 입력할 경우에만 서버로 override 값을 전송하여 프리셋 고유값을 덮어쓰도록 설계.
· 고정풍속(FIXED) 모드와의 통합
  · 현재는 '프리셋'과 '고정풍속'이 모드로 나뉘어 있는데, '프리셋 + 강도 오버라이드'가 가능해지면 사실상 고정풍속(강도 50%, 변동성 0%)과 유사해집니다. UI를 단순화하기 위해 모드 선택을 없애고 [프리셋 선택] + [세부 물리량 오버라이드] 구조로 일원화하는 방안도 검토할 만합니다.

2. 입력 항목 명확화 및 오조작 방지 (UI/UX 직관성)

· 텍스트 인풋을 드롭다운(Select)으로 전면 교체
  · HARBOR_BREEZE, BALANCE 등 사용자가 영문 코드를 직접 타이핑하는 방식을 제거합니다.
  · [프리셋]: 10종의 한글 이름(예: 항구 바람, 숲속 바람)이 담긴 드롭다운.
  · [스타일]: 5종의 한글 이름(예: 균형, 활동적, 수면)이 담긴 드롭다운.
· 조건부 활성화(Disabled) 처리
  · '예약 종료' 체크박스가 해제되어 있으면, 하위의 '종료 시간' 인풋은 회색으로 비활성화되어야 합니다.
  · '온도 종료', 'PIR 센서 활성화'도 마찬가지로 체크 해제 시 하위 인풋(PIR Hold 등)을 비활성화하여 시각적 혼란을 줄입니다.
· 용어 순화
  · On(분) / Off(분) ➔ 작동 시간(분) / 정지 시간(분) (또는 바람 송풍(분) / 휴지(분))

3. 세그먼트 실행 순서 및 편의 기능 강화

· 세그먼트 순서 변경 (Up / Down)
  · 세그먼트 카드 헤더 우측(휴지통 옆)에 ▲ (위로 이동) / ▼ (아래로 이동) 아이콘 버튼을 배치합니다.
  · 이를 통해 삭제 후 재생성 없이 배열 순서를 직관적으로 바꿀 수 있습니다.
· 아코디언 접힘 시 요약(Summary) 정보 노출
  · '바람 세그먼트' 아코디언을 닫았을 때, 빈 칸으로 두지 않고 아래와 같이 요약 텍스트를 노출합니다.
  · 예시: 총 2개 세그먼트 (프리셋 20분 → 고정 55% 15분)
· 버튼 위계(Hierarchy) 재조정
  · + 세그먼트 추가 버튼은 보조 액션이므로 파란색(Primary) 대신 회색 점선 테두리(Secondary)로 변경하여, 하단의 메인 액션인 저장(확인) 버튼이 더 돋보이게 합니다.

💡 요약된 화면 구성 기획안 (세그먼트 카드 기준)

```text
[세그먼트 1]                                     [▲] [▼] [🗑]
------------------------------------------------------------
작동 시간(분)    [ 20 ]     정지 시간(분)  [ 10 ]

프리셋 모드
[ 항구 바람 (HARBOR_BREEZE) ▼ ]

스타일
[ 균형 (BALANCE) ▼ ]

▼ 고급 설정 (풍속 세부 조절)
   강도(%)        [ 70  ] (프리셋 기본값)
   변동성(%)      [ 50  ]
   돌풍 빈도(%)   [ 45  ]
------------------------------------------------------------
```

이 기획안을 바탕으로 개발을 진행하시면, 사용자가 "스케줄에 등록한 바람"을 완벽하게 커스텀 제어할 수 있게 되어 제품의 가치가 크게 상승할 것입니다.
