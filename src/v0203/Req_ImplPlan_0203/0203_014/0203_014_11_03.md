## Part 1. 사용자 정의 요약표

### ① 시작 Trigger (4종)

| # | Trigger | 사용자 표현 | 신규/기존 |
|:---:|---|---|:---:|
| T1 | Manual 일반모드 | "프리셋 눌러서 시작" | 기존 (MANUAL) |
| T2 | Schedule 요일/시작시간 | "예약된 시간에 자동 시작" | 기존 (SCHEDULE) |
| T3 | Manual 완전 Auto (스마트쾌적) | "AI가 알아서 켜줘" | **신규** |
| T4 | Manual 선택 Auto | "이 프로파일로, 풍량은 알아서" | **신규** |

### ② 운전 Mode (5종)

| # | Mode | 정의 | 신규/기존 |
|:---:|---|---|:---:|
| M1 | 고정 속도 | 일반 선풍기 (PWM %) | 기존 (FIXED) |
| M2 | 플레이리스트 | 사용자 Step 시퀀스 (파라미터 고정) | 기존 (PLAYLIST) |
| M3 | 프리셋 | WindDict 프리셋+스타일 (파라미터 고정) | 기존 (PRESET) |
| M4 | 완전 Auto | 시스템이 프리셋+스타일+강도 모두 결정 | **신규** |
| M5 | 선택 Auto | 사용자가 base 선택, 강도/스타일 자동 | **신규** |

### ③ 운전 중 중단/재실행 Trigger (3종)

| # | Trigger | 조건 | 재개 조건 | 사용자 모드 선택 |
|:---:|---|---|---|:---:|
| P1 | PIR | 사람 없음 (`holdSec` 경과) | 재실 감지 | (Pause 고정) |
| P2 | 온도 | `tempC < threshold` | `tempC ≥ threshold + hysteresis` | **⦿Pause / ○Stop** |
| P3 | 불쾌지수 | `DI < threshold` | `DI ≥ threshold + hysteresis` | **⦿Pause / ○Stop** |

### ④ 종료 Trigger (3종)

| # | Trigger | 성격 |
|:---:|---|---|
| S1 | 사용자 중단 | 즉시 완전 종료 |
| S2 | Timer | N분 후 완전 종료 (ACK 필요) |
| S3 | Schedule 종료 | 시간 윈도우 벗어나면 종료 |

> **핵심 원칙**: 온도/DI/PIR 트리거는 **Pause(자동 재개) 또는 Stop(래치)** 중 사용자가 명시 선택. Stop은 사용자 안전 보호를 위한 선택지로 항상 제공.

### 3.3 Pause/Stop 분리 및 `ENV_PAUSED` 단일화

**설계 원칙**:
- **Pause**: 조건 해소 시 자동 재개 (PIR, 온도/DI `mode=PAUSE`)
- **Stop**: ACK 또는 새 세션 시작까지 지속 (사용자, Timer, Schedule, 온도/DI `mode=STOP`)
- **`MOTION_BLOCKED=4` 완전 폐기** → `ENV_PAUSED=7`이 모든 Pause 흡수

```cpp
// 신규: Pause Reason (자동 재개 대상)
typedef enum : uint8_t {
    EN_CT10_PAUSE_NONE      = 0,
    EN_CT10_PAUSE_MOTION    = 1,   // P1: PIR 부재 (구 MOTION_BLOCKED 대체)
    EN_CT10_PAUSE_TEMP_LOW  = 2,   // P2: 온도 이하 (mode=PAUSE일 때)
    EN_CT10_PAUSE_DI_LOW    = 3,   // P3: 불쾌지수 이하 (mode=PAUSE일 때)
} EN_CT10_pause_t;

// Stop Reason (S1/S2/S3 + 온도/DI의 mode=STOP만)
typedef enum : uint8_t {
    EN_CT10_REASON_NONE                = 0,
    // ... 기존 1~8 유지 (State Manager 내부 사유) ...
    EN_CT10_REASON_AUTOOFF_TIMER       = 9,   // S2: Timer 만료 (Stop)
    EN_CT10_REASON_AUTOOFF_TIME        = 10,  // S3: Schedule 종료 (Stop)
    EN_CT10_REASON_USER_STOP           = 11,  // S1: 사용자 명시 중단
    EN_CT10_REASON_TEMP_LOW_STOP       = 12,  // P2 (mode=STOP): 감기 방지 완전 종료
    EN_CT10_REASON_DI_LOW_STOP         = 13,  // P3 (mode=STOP): 쾌적 이탈 완전 종료
} EN_CT10_reason_t;
```

**FSM State 확장 (MOTION_BLOCKED 폐기, ENV_PAUSED 단일화)**:

**State 전이 규칙**:
```
ENV_PAUSED 진입: pauseReason ∈ {MOTION, TEMP_LOW, DI_LOW}
ENV_PAUSED 해제: pauseReason 조건 해소 시 자동
AUTOOFF_STOPPED 진입: reason ∈ {TIMER, TIME, USER_STOP, TEMP_LOW_STOP, DI_LOW_STOP}
```

### 3.4 상태 전이 상세

#### 3.4.1 Pause 전이

```
[RUNNING] ──pause 조건──► [ENV_PAUSED]
  (PIR 없음 / tempC < threshold + mode=PAUSE / DI < threshold + mode=PAUSE)

[ENV_PAUSED] ──resume 조건──► [이전 RUNNING]
  (PIR 감지 / tempC ≥ threshold + hysteresis / DI ≥ threshold + hysteresis)
```

**히스테리시스 강제** (Pause 모드에서만, flapping 방지):
- 온도: `hysteresis ≥ 0.5°C`
- DI: `hysteresis ≥ 3`

**Stop 모드 (mode=STOP)**:
```
[RUNNING] ──stop 조건──► [AUTOOFF_STOPPED]
  (tempC < threshold + mode=STOP / DI < threshold + mode=STOP)
  → reason = TEMP_LOW_STOP / DI_LOW_STOP
  → _autoOffLatched = true
```

**감기 방지 시나리오 (UserManual §6.3 정합)**:
- 사용자가 `mode=STOP` 선택 → `AUTOOFF_STOPPED` 진입
- 새벽 22.9→23.1°C 회복에도 **자동 재개 없음** (래치 유지)
- 사용자 프리셋 선택 또는 `POST /control/ack` 시에만 해제

#### 3.4.2 Stop 전이

```
[RUNNING] ──stop 조건──► [AUTOOFF_STOPPED]
  (S1 사용자 / S2 Timer / S3 Schedule / P2·P3 mode=STOP)
  reason = 개별 코드, _autoOffLatched = true

[AUTOOFF_STOPPED] ──ACK 또는 새 세션──► [IDLE]
```

#### 3.4.3 우선순위

| 우선순위 | 조건 | 결과 |
|:---:|---|---|
| 1 | `overrideState.active` | OVERRIDE |
| 2 | `_autoOffLatched` | AUTOOFF_STOPPED |
| 3 | Pause 조건 만족 | ENV_PAUSED |
| 4 | profile mode + profile 선택 | PROFILE_RUN |
| 5 | 스케줄 활성 | SCHEDULE_RUN |
| 6 | 기본 | IDLE |

### 3.5 통합 TriggerRule 스키마 (온도/DI 이원화)

```cpp
typedef enum : uint8_t {
    EN_A20_RULE_MODE_PAUSE = 0,   // 자동 재개 (편의)
    EN_A20_RULE_MODE_STOP  = 1,   // 완전 종료 (안전)
} EN_A20_ruleMode_t;

typedef struct {
    // ═══════ S2: Timer (Stop) ═══════
    struct { bool enabled; uint32_t minutes; } timer;
    
    // ═══════ S3: OffTime (Stop) ═══════
    struct { bool enabled; char time[6]; } offTime;
    
    // ═══════ 온도 트리거 (Pause/Stop 선택) ═══════
    struct {
        bool              enabled;
        EN_A20_ruleMode_t mode;          // PAUSE or STOP
        float             threshold;     // 정지 임계 (예: 22.0°C)
        float             hysteresis;    // 재개 히스테리시스 (mode=PAUSE일 때만, ≥0.5)
    } tempLow;
    
    // ═══════ 불쾌지수 트리거 (Pause/Stop 선택) ═══════
    struct {
        bool              enabled;
        EN_A20_ruleMode_t mode;
        float             threshold;     // 정지 임계 (예: 65)
        float             hysteresis;    // 재개 히스테리시스 (mode=PAUSE일 때만, ≥3)
    } diLow;
    
    // ═══════ PIR 트리거 (Pause 고정) ═══════
    struct { bool enabled; uint16_t holdSec; } pirPause;
    
    // ═══════ 스마트 쾌적 (M4/M5용) ═══════
    struct {
        bool     enabled;
        uint16_t intervalMin;   // 기본 5
        uint8_t  level;         // 0=off, 1=warn-only, 2=full
    } smartComfort;
} ST_A20_TriggerRule_t;
```

**스키마 검증 규칙 (로더에서 리젝트)**:
- `mode == PAUSE` 이면 `hysteresis` 최소값 강제 (온도 0.5, DI 3)
- `mode == STOP` 이면 `hysteresis` 무시 (0 저장)

### 3.6 저장 위치 매트릭스

| 세션 유형 | 규칙 저장 위치 |
|---|---|
| M1 FIXED 수동 | `overrideState.rule` (휘발성) |

### 3.7 AUTO_FULL (M4) 상세 동작

```
[세션 시작: MANUAL_AUTO_FULL]
  ├─ 초기: 사용자 선택 없음 → 5분 주기 DI/온도 평가 → 프리셋+스타일 자동 세팅
  ├─ 실행 중: 환경 변화 시 프리셋 자동 전환 (부드러운 crossfade)
  ├─ 사용자가 프리셋 수동 선택 시: AUTO_FULL 자동 해제 → MANUAL_PRESET
  └─ Pause/Stop은 공통 규칙 적용
```

### 3.8 AUTO_SELECT (M5) 상세 동작

```
[세션 시작: MANUAL_AUTO_SELECT + payload {baseType, baseValue}]
  ├─ baseType = PRESET: presetCode 고정, styleCode + intensity 자동
  ├─ baseType = PLAYLIST: 각 step의 presetCode 유지, styleCode + intensity 자동
  ├─ 5분 주기 재평가 → style/intensity 부드럽게 조정
  └─ Pause/Stop은 공통 규칙 적용
```

> **사용자 선택 범위**: base(프리셋 or 플레이리스트)만. **스타일·강도는 시스템 자동**.
