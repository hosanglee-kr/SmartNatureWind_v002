## 1. 30초 빠른 시작 (처음 사용자용)

1. **전원 켜기**: 기기에 5V/12V 전원을 연결합니다. (기기 내 NeoPixel 상태 LED가 파란색/녹색으로 점멸하며 부팅됩니다)
2. **와이파이 연결**: 스마트폰이나 PC의 Wi-Fi 검색 목록에서 **`NatureWind`**를 선택합니다.
   - **기본 비밀번호**: `2540`
3. **웹 대시보드 열기**: 인터넷 브라우저(Chrome, Safari 등)를 열고 주소창에 아래 주소를 입력합니다:
   ```text
   http://192.168.4.1
   ```
   *(접속 즉시 고속 압축 전송된 `index.html` 기반 메인 SPA Shell이 0.5초 이내에 열립니다)*
4. **자연풍 가동**: 화면 상단의 **`Ocean(바다)`**, **`Mountains(산바람)`**, **`Forest(숲속)`** 버튼 중 하나를 누르면 대기역학 물리 시뮬레이션 자연풍이 즉시 시작됩니다!
5. **팬 정지**: 대시보드의 **`정지 (STOP)`** 버튼을 누르면 팬이 부드럽게 감속하며 정지합니다.

## 2. 제품 소개 및 핵심 특징

### 2.1 Smart Nature Wind는 어떤 제품인가요?
Smart Nature Wind v0202은 기존 선풍기의 인위적인 1-2-3단 정속 회전 대신, **실제 대기(大氣)의 기류 변화, 돌풍(Gust), 난류(Turbulence), 지표면 열기포(Thermal Bubble)를 실시간 물리 엔진(S10/S20)으로 연산하여 재현하는 차세대 스마트 자연풍 제어기**입니다.

ESP32-S3 고성능 듀얼코어 MCU와 고속 LittleFS 웹서버를 자체 내장하여, 별도의 외부 클라우드나 앱 설치 없이 스마트폰 브라우저만으로 모든 기능을 완벽하게 제어할 수 있습니다.

### 2.2 8대 핵심 기능 요약

| 기능 영역 | 주요 특징 | 사용자 체감 가치 |
|---|---|---|
| **물리 기반 자연풍** | 10종 자연 프리셋 + 5종 바람 스타일 | 획일적이지 않은 부드럽고 상쾌한 자연의 바람 |
| **인체 감지 절전 (PIR)** | 사람의 재실/부재 자동 감지 (7-State FSM) | 자리 비움 시 자동 정지, 복귀 시 부드러운 자동 재개 |
| **온습도 환경 적응 (DHT22)** | 실시간 온도/습도 측정 및 실내 쾌적도 판정 | 과냉 방지 자동 종료 및 실내 온습도 건강 케어 |
| **3대 스마트 자동 종료** | 타이머 / 지정 시각 / 최저 온도 자동 정지 | 잠든 사이 감기나 저체온증 없는 안심 수면 보장 |
| **Gemini AI 비서 연동** | 구글 Gemini 인공지능 기반 자연어 대화 제어 | "더운데 시원하게 해줘" 등 자연어 명령 즉시 반영 |
| **주간 정밀 스케줄러** | 요일별(월~일) 24시간 타임라인 자동 운전 | 아침 기상, 집중 근무, 취침에 맞춘 완벽 자동화 |
| **초고속 SPA 대시보드** | `index.html` 단일 셸 + Gzip Level 9 초고속 로드 | 페이지 이동 지연 시간 0ms, 쾌적한 반응성 |
| **WS2812B RGB LED** | 7-State FSM 풀컬러 NeoPixel 시각화 | 색상과 점멸 리듬으로 기기 연결 및 상태 직관 파악 |

## 3. 기기 연결 및 웹 대시보드 접속 (`index.html`)

Smart Nature Wind는 2가지 Wi-Fi 연결 모드를 지원합니다:

```text
[SoftAP 단독 모드]                     [공유기 STA 연동 모드]
스마트폰 ──(1:1 직접 연결)──► 기기      스마트폰/PC ──► 공유기(AP) ──► 기기
(외부/공유기 없는 환경, 192.168.4.1)      (가정/사무실 전체 기기 접속, NTP 시간 동기화)
```

### 3.1 SoftAP 모드로 직접 접속 (기본 방식)
1. 스마트폰의 Wi-Fi 설정에서 **`NatureWind`**를 선택합니다.
2. 비밀번호 **`2540`**을 입력하고 연결합니다.
3. 브라우저 주소창에 **`http://192.168.4.1`**을 입력하여 접속합니다.
> 💡 **참고**: "인터넷에 연결되지 않음" 알림이 떠도 **"연결 유지"**를 선택해 주세요. 기기와의 1:1 로컬 통신을 위한 정상적인 동작입니다.

### 3.2 가정/사무실 공유기(STA)에 연결하기
1. SoftAP 상태에서 상단 메뉴의 **`Network`** 페이지(`/#/network`)로 이동합니다.
2. Wi-Fi STA 목록에서 연결할 공유기 SSID를 선택하고 비밀번호를 입력한 뒤 **`저장 및 연결`**을 누릅니다.
3. 연결 성공 시 상태 LED가 녹색 점등으로 바뀌며, 공유기에서 부여받은 새 IP(예: `192.168.0.50`)로 가정 내 어디서나 접속할 수 있습니다.

### 3.3 스마트폰 홈 화면에 바로가기 추가 (앱처럼 쓰기)
- **아이폰 (Safari)**: 하단 공유 아이콘 → **`홈 화면에 추가`**
- **안드로이드 (Chrome)**: 우측 상단 더보기(`⋮`) → **`홈 화면에 추가`** 또는 **`앱 설치`**

## 4. 메인 대시보드 조작 가이드 (`#/dashboard`)

대시보드는 제품의 모든 일상 조작을 한눈에 파악하고 1초 만에 제어할 수 있는 메인 화면입니다.

```text
┌────────────────────────────────────────────────────────┐
│  🍃 Smart Nature Wind v0202         [● STA 연결됨]     │
├────────────────────────────────────────────────────────┤
│  [실시간 대시보드 위젯]                                 │
│   • 현재 풍속: 45% (자연풍: OCEAN / NATURAL)            │
│   • 실내 환경: 25.4 ℃  |  54 %  |  재실 감지됨(Active) │
├────────────────────────────────────────────────────────┤
│  [빠른 제어 버튼]                                       │
│   [ ▶ 수동 ON ]   [ ⏹ 정지 (STOP) ]   [ ⏱ 1시간 타이머 ] │
├────────────────────────────────────────────────────────┤
│  [자연풍 프리셋 선택 (10종)]                            │
│   [ Ocean ] [ Country ] [ Medit. ] [ Mountains ] ...   │
├────────────────────────────────────────────────────────┤
│  [바람 스타일 (5종)]                                    │
│   (●) Natural   ( ) Gusty   ( ) Gentle   ( ) Cyclic    │
└────────────────────────────────────────────────────────┘
```

- **실시간 풍속 게이지**: 물리 엔진이 100ms마다 연산하여 전달하는 실제 팬 가동률(0~100%)을 실시간 애니메이션으로 표시합니다.
- **온도 / 습도 / 재실 현황**: 실내 온습도와 PIR 센서 감지 상태를 즉시 확인합니다.
- **수동 풍속 슬라이더**: 원하는 고정 풍속(예: 30%)으로 즉시 수동 운전할 수 있습니다.
- **원클릭 빠른 제어**: 1시간/2시간 취침 타이머 및 즉시 정지(STOP)를 지원합니다.

## 5. 자연풍 물리 시뮬레이션 바람 사전 (`windDict`)

**10대 자연풍 프리셋**과 **5대 바람 스타일**을 조합하여 자연의 감성을 취향에 맞게 즐길 수 있습니다.

### 5.1 자연풍 프리셋 10종

| 프리셋 이름 | 한글 감성 명칭 | 바람의 물리적 특성 및 추천 상황 |
|---|---|---|
| **Ocean** | 바다 바람 | 파도가 밀려오듯 주기적인 큰 파동과 시원한 강풍이 어우러진 대양의 숨결 |
| **Countryside** | 시골 들판 바람 | 완만한 곡선을 그리며 살랑살랑 불어오는 가장 편안하고 고요한 쉼표 바람 |
| **Mediterranean**| 지중해 연안 바람 | 적당한 난류와 부드러운 온도가 조화로운 쾌적하고 산뜻한 휴양지 오후의 바람 |
| **Mountains** | 깊은 산속 계곡풍 | 역동적이고 짜릿한 상쾌함을 전하는 강력한 쿨링 계곡 바람 |
| **Plains** | 대평원 바람 | 막힘없이 넓은 들판을 가로지르는 빠른 실내 환기용 지속풍 |
| **Port** | 항구 바람 | 도시의 열기 속에서 바다의 여운을 전하는 경쾌하고 리듬감 있는 바람 |
| **Forest** | 숲속 쉼표 바람 | 우거진 나뭇잎 사이로 부서져 내리듯 고요하고 은은한 초저소음 휴식/수면 기류 |
| **Sunset** | 도시 일몰 바람 | 하루를 정리하는 저녁 무렵의 차분하고 온화한 노을빛 감성 바람 |
| **Tropical Rain**| 열대 소나기 바람 | 비 내리기 직전의 예측 불가능한 돌풍과 전율을 담은 다이내믹 바람 |
| **Desert Night** | 사막의 밤 바람 | 별빛 아래 고요한 정적, 모터 소음을 극도로 억제한 심야 집중/몰입 바람 |

### 5.2 바람 스타일 5종
1. **Natural (자연풍)**: 기본 물리 모델 파라미터를 그대로 연산하는 균형 잡힌 표준 자연풍.
2. **Gusty (돌풍)**: 활동량이 많거나 무더울 때 돌풍 발생 주기와 강도를 강화한 역동적 바람.
3. **Gentle (산들바람)**: 독서나 취침 시 모터 소음을 최소화하고 변동폭을 억제한 미풍.
4. **Cyclic (주기풍)**: 규칙적인 상승과 하강 파동이 부드럽게 반복되는 리드미컬한 바람.
5. **Off (정지)**: 팬 출력을 0으로 안전하게 차단하는 모드.

## 6. 스마트 센서 연동 및 3대 자동 종료 (AutoOff)

Smart Nature Wind는 실내 환경과 사람의 움직임을 스스로 감지하여 불필요한 전력 낭비를 막고 사용자의 건강을 보호합니다.

### 6.1 인체 감지(PIR) 스마트 절전 운전
- **동작 원리**: 고감도 PIR 인체감지 센서가 실내 움직임을 모니터링합니다.
- **자동 절전 (`MOTION_BLOCKED`)**: 사람이 방을 나가면 설정된 대기 시간(기본 120초) 후 팬을 자동으로 멈춥니다.
- **자동 복귀 (`Soft Start`)**: 사람이 다시 방으로 돌아오면 별도 조작 없이 즉시 이전 바람 모드로 부드럽게 재개됩니다.

### 6.2 3대 스마트 자동 종료 (AutoOff)

```text
┌────────────────────────────────────────────────────────┐
│                   3대 스마트 자동 종료                  │
├───────────────────┬───────────────────┬────────────────┤
│ ⏱ 취침 타이머      │ ⏰ 지정 시각 종료  │ 🌡 과냉 방지 온도 │
│ (Timer AutoOff)   │ (Off-Time)        │ (Off-Temp)     │
├───────────────────┼───────────────────┼────────────────┤
│ 설정한 시간(분) 후 │ 매일 특정 시각     │ 실내 온도가     │
│ 자동으로 정지      │ (예: 새벽 03:30)에 │ 설정치(예 23℃) │
│                   │ 1회 자동 정지     │ 이하로 내려가면 │
│                   │                   │ 감기 예방 정지 │
└───────────────────┴───────────────────┴────────────────┘
```

> 🔒 **자동 종료 후 래치(Latch) 안전 보호**:  
> 자동 종료가 발동되면 기기는 **`AUTOOFF_STOPPED`** 래치 상태로 안전하게 잠깁니다. 이는 잠결에 체온 보호를 위해 꺼진 선풍기가 온도 미세 변화 등으로 갑자기 다시 켜지는 것을 방지하기 위함입니다. 다시 가동하려면 웹 화면에서 바람 모드를 변경하거나 수동 시작 버튼을 누르시면 정상 해제됩니다.

## 7. 주간 스케줄러 설정 (`#/schedule`)

요일별, 시간대별로 선풍기가 알아서 켜지고 원하는 자연풍으로 동작하도록 주간 스케줄을 계획할 수 있습니다.

```text
[월요일 스케줄 예시]
07:00 ~ 08:30 ──► MOUNTAINS (Gusty)   : 활기찬 기상 바람
08:30 ~ 19:00 ──► IDLE (대기)         : 출근 시간대 전원 OFF
19:00 ~ 23:00 ──► OCEAN (Gentle)      : 퇴근 후 편안한 휴식 바람
23:00 ~ 03:00 ──► FOREST (Gentle)     : 조용한 수면 바람 (03:00 자동 종료)
```

1. 상단 메뉴에서 **`Schedule`** (`#/schedule`) 탭으로 이동합니다.
2. 타임라인에서 원하는 요일(월~일)을 선택하고 **`새 스케줄 추가`**를 누릅니다.
3. 시작/종료 시각, 바람 프리셋, 스타일을 지정하고 **`저장`**을 누르면 기기 메모리에 즉시 반영됩니다.
> 🕒 **스케줄 작동 조건**: 주간 스케줄러가 정확한 시간에 켜지려면 기기가 Wi-Fi에 연결되어 인터넷 표준 시간(SNTP)을 받아와야 합니다.

## 8. 맞춤 바람 프로파일 제작 (`#/profiles`)

기본 10종 자연풍 외에, **풍속과 동작 주기를 자유자재로 조합한 나만의 바람 시퀀스**를 직접 제작할 수 있습니다.

- **세그먼트(Segment) 구조**:
  - 구간 1: 풍속 25%로 3분간 가동 (부드러운 시작)
  - 구간 2: 풍속 70%로 1분간 가동 (환기 강화)
  - 구간 3: 풍속 0%로 30초간 모터 휴지 (간헐풍)
  - **반복 설정**: 위 사이클을 지정한 횟수만큼 반복 후 안전 종료.
- `#/profiles` 화면에서 새 프로파일을 추가하고 메인 대시보드에서 클릭 한 번으로 불러올 수 있습니다.

## 9. 실시간 물리 시뮬레이션 차트 (`#/chart`)

Smart Nature Wind가 단순한 기계적 회전이 아닌, **살아있는 대기 물리 시뮬레이션**으로 구동됨을 눈으로 직접 확인할 수 있는 전문 그래픽 뷰어입니다.

- **물리 요소 분해 관측**: 기저 바람선, 난류 변동폭, 돌풍 피크(Gust Peak), 열기포 상승 구간을 시각적으로 구분하여 표시합니다.

## 10. Gemini AI 대화형 비서 연동 (`#/ai`)

Google Gemini 인공지능과 연동하여 사용자의 기분, 날씨, 건강 상태에 맞춘 지능형 대화 제어를 제공합니다.

### 10.1 대화형 명령 예시
- *"지금 방이 조금 더운데 땀 좀 식히게 해줘"* ➔ **Ocean 프리셋 + Gusty 스타일 즉시 적용**
- *"잠잘 건데 감기 안 걸리게 해줘"* ➔ **Forest 프리셋 + Gentle 스타일 + 120분 타이머 + 과냉방지(23.5℃) 자동 세팅**
- *"현재 선풍기 상태랑 실내 온도 알려줘"* ➔ **실시간 센서 측정값 및 현재 풍속 친절 안내**

### 10.2 설정 방법
`#/settings` 또는 `#/ai` 탭에서 발급받은 Google Gemini API Key를 등록하면 기기 자체 프록시를 통해 안전하게 인공지능 비서 기능이 활성화됩니다.

- **PIR 모션 감지 상세 타이머**: 현재 감지 여부, 마지막 움직임 감지 시각, 자동 정지까지 남은 시간 카운트다운을 시각적으로 표시합니다.

## 12. 시스템 및 네트워크 고급 설정 (`#/settings` / `#/network`)

### 12.1 시스템 설정 (`#/settings`)
- **팬 모터 안전 듀티 설정**:
  - `최소 기동 듀티 (Start Percent Min)`: 팬 날개가 멈춤 없이 안정적으로 회전하기 시작하는 최소 전압값 (기본 18%).
  - `안심 상한 듀티 (Comfort Percent Max)`: 일상 자연풍 모드에서 허용할 최대 팬 속도 (기본 65%).
  - `하드웨어 최대 한계치 (Hard Percent Max)`: 수동 풀파워 모드 시 도달할 수 있는 절대 상한선 (기본 90%).
- **보안 API 키 관리**: 비인가자의 제어를 차단하기 위해 관리자 API Key를 설정하거나 제거할 수 있습니다.

### 12.2 설정 저장(`Save`)과 비동기 재적용(`Reload`) (골든 룰)
- **메모리 즉시 반영**: 웹 슬라이더나 모드 조작은 플래시 메모리 수명을 위해 RAM에서 먼저 즉각 반응합니다.
- **`설정 저장 (POST /api/v001/config/save)`**: 수정한 설정을 LittleFS 플래시에 영구 기록합니다.
- **`비동기 재적용 (POST /api/v001/reload)`**: 기기 재부팅 없이 변경된 파라미터를 백엔드 루프에 안전하게 재적용합니다.

## 13. 진단, 시스템 로그 및 OTA 펌웨어 업데이트

- **자가 진단 (`#/diagnostics`)**: Free Heap 메모리, LittleFS 파일시스템 잔여 용량, CPU 부하, 태스크 상태를 한눈에 점검합니다.
- **실시간 시스템 로그 (`#/logs`)**: 내부 링버퍼에 기록되는 시스템 동작 로그를 실시간으로 확인하여 오류나 네트워크 상태를 빠르게 추적합니다.
- **무선 펌웨어 업데이트 (`#/firmware`)**: 케이블 연결 없이 브라우저에서 `firmware.bin` 파일을 선택하여 안전하게 최신 펌웨어로 무선 업데이트(OTA)할 수 있습니다.
- **시스템 정보 (`#/info`)**: 펌웨어 버전, 빌드 일자, 하드웨어 사양, 시스템 라이선스 정보를 확인합니다.

## 14. 자주 묻는 질문 (FAQ) 및 문제 해결

### Q1. 선풍기 날개가 돌지 않아요.
- **원인 1**: 설정 모드가 `IDLE`이거나 타이머 종료 후 `AUTOOFF_STOPPED` 래치 상태일 수 있습니다. 대시보드에서 `수동 시작` 버튼을 눌러보세요.
- **원인 2**: 인체 감지 절전(`MOTION_BLOCKED`)으로 대기 중일 수 있습니다. 센서 앞에서 가볍게 손을 흔들어보세요.
- **원인 3**: 모터 기동 전압 부족일 수 있습니다. `#/settings`에서 `Start Percent Min`을 18%에서 22%로 조금 올려보세요.

### Q2. 스마트폰에서 `192.168.4.1` 페이지가 열리지 않아요.
- **점검**: 스마트폰 Wi-Fi가 **`NatureWind`**에 정상 연결되었는지 확인하세요. LTE/5G 모바일 데이터가 켜져 있으면 로컬 주소 접속을 우회할 수 있으므로, 잠시 모바일 데이터를 끄고 접속해 보세요.

### Q3. 방에 사람이 있는데도 선풍기가 꺼져요.
- **점검**: 의자에 앉아 거의 움직이지 않는 환경이라면 `#/settings`에서 모션 감지 유지 시간(`holdSec`)을 기본 120초에서 300초(5분)로 늘려주세요.

### Q4. 주간 스케줄 시간에 선풍기가 켜지지 않아요.
- **점검**: 기기가 가정 내 Wi-Fi에 연결되어 NTP 표준 시각을 수신했는지 확인하세요. `#/info` 페이지에서 현재 시각이 정상 표시되고 있어야 스케줄이 작동합니다.
