# `W10_Web_0203.h` 상세 Spec

## ⚙️ 시스템 스펙 요약: W10_Web_0203.h

`AsyncWebServer` 기반 **RESTful API 라우트(40여 종)**, **5대 WebSocket 채널(State/Logs/Chart/Metrics/Summary)**, **Gzip 정적 에셋 서빙**, **파일 업로드/OTA 업데이트(2MB 제한)** 및 **Stage 8 Gemini AI / Live 라우트**를 총괄하는 `CL_W10_WebAPI` 헤더입니다.

### 💾 구조체 및 타입 정의 (Structs & Types)

*   **`CL_W10_WebAPI`** (`class`)
    *   **설명:** `AsyncWebServer*`, `CL_CT10_ControlManager*`, 5개 `AsyncWebSocket*` 채널, 업로드 상태(`s_upFile`, `s_uploadTotal`, `G_W10_MAX_UPLOAD_SIZE=2MB`)를 관리하는 정적 웹 API 매니저입니다.
    *   **사용처:** `A00_Main_0203.cpp`에서 `begin(server, control)`로 기동하며 모든 `W10_Web_*.cpp` 파일이 이 클래스의 정적 메서드를 구현합니다.
*   **`ST_W10_PageEntry_t` / `ST_W10_MenuState_t`** (`struct`)
    *   **설명:** 동적 메뉴(`pages.json`)의 페이지 순서(`order`), 메인 여부(`isMain`), 활성 여부(`enable`) 및 메뉴 상태를 보관하는 구조체입니다.
    *   **사용처:** `W10_loadPagesJson()`, `W10_getMenuJson()`에서 프론트엔드 내비게이션 메뉴를 제공할 때 사용됩니다.
