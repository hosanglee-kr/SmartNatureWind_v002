# FLOW_0200.md — 데이터 흐름 및 시퀀스 명세

> **목적**: v0200의 부팅 초기화, 메인 루프 파이프라인, 태스크 간 비동기 위임 시퀀스 및 예외 복구 흐름을 명세.  
> T-loop (`loopTask`), T-async (`async_tcp`), T-wf (`WF10_Reconnect`), T-sys_evt (`esp_event_loop`) 협력 구조.  
> F-01~F-10, I-1~I-6, N-1~N-4, A-1~A-3, B-1~B-6, C-1~C-8, D-1~D-5, E-1~E-10, E-2.1~E-2.7, F-1~F-10 반영.  
> **파일명 정책**: 계약 문서 `_0200.md` 유지, 코드 참조 `_0201` 접미사.

## 1. 부팅 시퀀스 (`A00_init()`)

```text
[1] Serial & Logger
    └── CL_D10_Logger::begin() → setLevel(EN_L10_LOG_INFO)  ← F-4

[2] LittleFS 마운트
    └── LittleFS.begin(true) (실패 시 에러 로깅)

[3] Config & NVS 초기화
    ├── C10::begin() (재귀 뮤텍스 생성)
    ├── C10::loadAll(g_A20_config_root) (8섹션 JSON 역직렬화)
    └── N10::begin() (NVS Preferences 오픈 + 런타임 복구)

[4] 필수 설정 검증 + Status LED
    ├── system/wifi 섹션 null 방어 (E-2: factory reset 블록 제거)
    └── static CL_A30_LED 생성 → g_A00_ledController 할당 → begin()

[5] Wi-Fi + 네트워크
    └── WF10::init(v_wifi, v_sys)
         ├── attachWiFiEvents() (1회)
         ├── TM10::begin() (멱등)
         ├── _ensureWifiTask() (T-wf 생성, F-02 mutex 보호)
         └── startSTA()
              ├── 성공: TM10::onWiFiConnected() 직접 통지 (F-01)
              └── 실패: SoftAP 폴백

[6] PWM + 중앙 제어
    ├── g_P10_pwm.P10_begin(*system) (LEDC 25kHz)
    └── CT10::begin() (s_stateMutex lazy, _pendingMotionSimApply=false 방어)

[7] Motion Logic
    ├── M10::M10_begin() (싱글톤, g_M10_motionLogic 할당)
    └── A00_getControl().setMotion(g_M10_motionLogic)

[8] Web API
    ├── W10::begin(g_A00_server, A00_getControl()) (라우트 등록)
    └── g_A00_server.begin() (포트 80)

[9] WS 브로커 + 스케줄러
    ├── CT10_WS_setBrokers(...) (브로드캐스트 콜백 주입)
    └── CT10_WS_begin()

[10] WDT (마지막)
    ├── esp_task_wdt_init(A20_Const::G_A00_WDT_TIMEOUT_SEC, true)  ← C-5
    └── esp_task_wdt_add(NULL)
```

> **가드**: WDT는 반드시 `A00_init()` 맨 마지막. Wi-Fi 재시도 등 블로킹 회피.

## 2. 메인 루프 파이프라인 (`A00_run()`)

```text
[Step 1] WDT 리셋
         └── esp_task_wdt_reset()

[Step 2] [F-05] Pending Reload 위임 실행
         └── if (consumePendingReload()) {
                 reloadAll();
                 applySystemRuntimeFromConfig(*system);
             }

[Step 3] CT10 메인 제어
         └── CT10::tick() → tickLoop()
                 ├─ [F-06] _pendingMotionSimApply.exchange(false) → applyMotionSimConfigToSim()
                 ├─ 40ms 스로틀
                 ├─ decideRunSource() → applyDecision() (FSM)
                 └─ sim.tick() (물리 + PWM)

[Step 4] WS 스케줄러
         └── CT10_WS_tick()
                 ├─ [D-1] consumeAllDirty() 1회
                 ├─ 우선순위 1채널 브로드캐스트
                 └─ cleanupClients 주기

[Step 5] [F-03] M10 tick
         └── if (g_M10_motionLogic) g_M10_motionLogic->tick()
                 └── PIR holdSec 감쇠 + 상태 전이

[Step 6] TM10 tick
         └── TM10::tick(system)
                 └── SNTP fallback 감시

[Step 7] [E-1] 지연 Free
         └── C10::processPendingFree() (3초 grace 경과분)

[Step 8] [F-04] N10 Flush
         └── N10::tick() (10초 게이트)

[Step 9] LED
         └── g_A00_ledController->run(isStaConnected())  (D-4 atomic)

[Step 10] 스로틀
         └── delay(A20_Const::G_A00_LOOP_DELAY_MS)  ← C-5
```

```text
      │── POST /api/v001/reload ►│                              │
      │                          │── requestReload() (atomic CAS)
      │                          │   ├─ 이미 true: 409 Conflict │
      │                          │   └─ 성공: s_pendingReload=true
      │◄── 202 Accepted ─────────│                              │
      │    (< 1ms)               │                              │
      │                          │                (다음 루프 ≤ 10ms)
      │                          │                consumePendingReload() == true

      │                          │                              │     3. queuePendingFree(v_old)
      │                          │                              │──► applySystemRuntime...
      │                          │                              │
      │── GET /api/v001/state ──►│ (폴링)                       │
      │◄── pendingReload:false ──│                              │
      │    lastReloadOk:true     │ (완료 판별)
```

## 6. 시간 동기화 (SNTP 콜백 + 다중 경로)

```text
[트리거 1] Wi-Fi GOT_IP 이벤트 (T-sys_evt) ──► TM10::onWiFiConnected()
[트리거 2] startSTA 성공 직후 (T-wf) ────────► TM10::onWiFiConnected() (F-01 보조)
[트리거 3] HTTP /api/v001/system/time/set ──► TM10::requestTimeSync(true)

[동작] _startSntpWithServer(s_activeServerIdx)
         ├── esp_sntp_setoperatingmode(SNTP_OPMODE_POLL)
         ├── esp_sntp_setservername(0, serverName)
         └── esp_sntp_init()

[감시] T-loop TM10::tick()
         └── waitingCallback 15초 초과 ──► _switchToNextServer() (Fallback 순환)

[완료] SNTP 콜백 ──► _isTimeSane() ──► s_timeValid=true, s_timeSyncedRecently=true
         (C: G_TIME_EPOCH_SANE_MIN / G_TIME_YEAR_MIN/MAX 사용)
```

## 7. PIR 모션 센서 피드/감쇠 (F-03, A-2)

```text
[1] 외부 피드
    HTTP POST /api/v001/motion/pir/feed (T-async)
    └── CT10::feedPIR(true)  ← A-2 위임 (s_stateMutex 경유)
         └── M10::notifyPIRDetected(): _pir.active=true, _pir.lastDetected_ms=millis()

[2] 주기 감쇠 (T-loop / A00_run)
    └── g_M10_motionLogic->tick() (F-03)
         ├── millis() - _pir.lastDetected_ms >= holdSec*1000
         │    └── _pir.active=false
         └── 상태 변화 시 _state.pirActive, lastChange_ms 갱신

[3] 제어 판정 (T-loop / CT10::tickLoop)
    └── decideRunSource() → isMotionBlocked() → g_M10_motionLogic->isActive()
         └── 부재 시 MOTION_BLOCKED 전환
```

## 8. 배치 A-2 캡슐화 위임 흐름

```text

      │
      ├── /motion/pir/feed ──► s_control->feedPIR(true)
      │                             │
      │                        [CT10::feedPIR] s_stateMutex 획득
      │                             └── motion->feedPIR(true) → M10::s_stateMutex

      ├── /simulation GET ──► s_control->exportSimJson(v_doc)
```

## 10. 예외/폴백 경로

| 장애 유형 | 감지 지점 | 폴백/복구 |
|---|---|---|
| Wi-Fi STA 접속 불가 | startSTA 5회 실패 | SoftAP 폴백 |
| GOT_IP 이벤트 mutex 경합 | `isAcquired()==false` | startSTA 성공 시 명시 통지 (F-01) |
| NTP 타임아웃 | 15초 콜백 미수신 | Google → Cloudflare → pool.ntp.org |
| 설정 JSON 손상 | LittleFS 파싱 실패 | `.bak` 자동 복구 (`A25_Com_Utils_IO_0201.cpp`) |
| 중복 Reload | requestReload CAS 실패 | 409 Conflict |
| 재실자 부재 | PIR holdSec 만료 | MOTION_BLOCKED + 팬 정지 |
| AutoOff 조건 | 타이머/시간/온도 | `_autoOffLatched=true` + 팬 안전 정지 |
| Gzip 파일 부재 | `exists(uri+".gz")==false` | raw 폴백 |
| Factory reset 후 NVS 잔존 | (F-1 이전) | **F-1**: `N10::resetRuntime()` 호출 |
| Logger 초기 DEBUG (양산) | (F-4 이전) | **F-4**: INFO로 변경 |
