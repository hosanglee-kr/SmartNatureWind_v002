# A00_Main_0203.cpp 상세 Spec

## 1. 파일 역할 요약
스마트 네처 윈드 시스템의 부팅 진입점 (Entrypoint) 과 메인 루프를 구현하며, LittleFS/NVS/WiFi 초기화 순서를 정의하고 전역 인스턴스를 생성합니다.

## 2. 주요 클래스/구조체/열거형
*   **전역 인스턴스**: `CL_M10_MotionLogic`, `AsyncWebServer`, `CL_P10_PWM`, `CL_A30_LED`
*   **접근자 (Accessor)**: `CL_CT10_ControlManager& A00_getControl()`
*   **외부 의존성 헤더**: `LittleFS.h`, `WiFi.h`, `esp_task_wdt.h`, `A23_Com_ResetCfg_0203.h` 등

## 3. 주요 함수/메서드 및 동작
*   **`void A00_init()`**: 시스템 부팅 시퀀스 실행 (LittleFS → Config/NVS → WiFi → Time → PWM → Control → Motion → Web → WS → WDT).
    *   **Config 로직**: `CL_C10_ConfigManager::begin()` 실패 시 In-memory 폴백 및 Recovery AP 기동.
    *   **Null 방어**: `g_A20_config_root.system`/`wifi` 가 NULL 이면 `new (std::nothrow)` 를 통한 기본값 할당 후 부팅 계속.
    *   **LED 유효성 검사**: 핀 범위 (0~48) 및 픽셀 수 (1~16) 검증 후 안전 값 적용.
    *   **WDT 초기화**: `esp_task_wdt_init()` 호출 시 마법넘버 상수 (`A20_Const::G_A00_WDT_TIMEOUT_SEC`) 사용.
*   **`void A00_run()`**: 메인 루프 실행 (Watchdog Feed → Pending Reload 처리 → Control/WS/M10/Time Tick).

## 4. 외부 의존성 / 공유 상태 / 락(Mutex 등) 특이사항
*   **공유 상태**: `g_A20_config_root` (System/Wifi), `g_M10_motionLogic`, `g_A00_ledController`.
*   **락/동기화**: `esp_task_wdt_reset()` 호출로 WDT 피드, `CL_CT10_ControlManager::consumePendingReload()` 로 리로드 처리.
*   **특이사항**: `new (std::nothrow)` 를 사용한 메모리 할당으로 OOM 시 부팅 중단 방지 및 Recovery AP 기동 정책 적용.
