## 1. 개요 및 설계 원칙

```
[ 기존 (Before): 복잡한 편차 덧셈 구조 ]
UI (절대값?) ──> [역산: Target - Base = Delta] ──> JSON {"adjust": {"windIntensity": 5}}
──> S20_WindSolver: (Preset * Style) + adjust  (디버깅 난해, 정량값 불투명)

[ 개선 (After): 직관적인 절대값 Override 단일 구조 ]
UI (0~100% 직관적 슬라이더 + 정량 m/s 피드백) ──> JSON {"override": {"enabled": true, "windIntensity": 70.0}}
──> S20_WindSolver: if (override.enabled) v_int = override.windIntensity  (직결, 단순, 명확)
```

### 1.1. 4대 핵심 설계 원칙
1. **Single Source of Truth (개념 일원화)**: UI 표시, JSON 설정 저장, C++ 구조체, 시뮬레이션 물리 연산이 모두 `0~100% 절대값`이라는 단일 멘탈 모델로 통일.
2. **Zero-Inverse Translation (역산 로직 제거)**: 프론트엔드가 편차($\pm$)를 계산할 필요 없이, 사용자가 슬라이더로 맞춘 값을 백엔드로 1:1 직결 전송.
3. **Explicit Fallback (명시적 기본값 유지)**: 세그먼트의 `override.enabled == false`인 경우 기존 프리셋 본래의 정체성(해안풍, 산바람 등 고유 물리값)을 100% 보존.
4. **Consistency across Pages (화면 간 완벽한 일관성)**: 대시보드, 스케줄 모달, 프로필 모달이 동일한 프리셋/스타일 목록, 동일한 슬라이더 동작, 동일한 정량 텍스트 템플릿 공유.

### 2.1. 자료구조 변경 (`A20_Const_Sch_0202.h`)

#### (1) 레거시 편차 구조체 폐기 및 `ST_A20_SegmentOverride_t` 신설
- **파일 경로**: `src/v0202/A20_Const_Sch_0202.h`
- 기존의 복잡한 9개 항목 `ST_A20_AdjustDelta_t`를 폐기하고, 사용자가 직접 제어하는 3대 물리 파라미터 기반의 구조체로 신설.

```cpp
/* ======================================================
 * [신규] Segment Override (세그먼트 개별 물리 파라미터 덮어쓰기)
 *  - enabled == false : 프리셋 기본 물리값 사용
 *  - enabled == true  : 설정된 절대값(0~100%)으로 덮어쓰기
 *  - 음수(-1.0f)     : 해당 항목만 프리셋 값 유지
 * ====================================================== */
typedef struct {
    bool  enabled         = false; // Override 활성화 여부
    float windIntensity   = -1.0f; // 풍속 강도 (0.0f ~ 100.0f)
    float windVariability = -1.0f; // 변동성   (0.0f ~ 100.0f)
    float gustFrequency   = -1.0f; // 돌풍 빈도 (0.0f ~ 100.0f)
} ST_A20_SegmentOverride_t;
```

#### (2) 세그먼트 구조체 내 필드 교체
- 스케줄 세그먼트(`ST_A20_ScheduleSegment_t`) 및 프로필 세그먼트(`ST_A20_UserProfileSegment_t`)의 `adjust` 필드를 `override` 필드로 전면 교체.

    // 2) Style 배수 연산 (v_int *= styleFactor 등)

    const targetIdx = idx + direction;
    if (targetIdx < 0 || targetIdx >= currentSegs.length) return;
    
    // 배열 순서 교체
    const temp = currentSegs[idx];
    currentSegs[idx] = currentSegs[targetIdx];
