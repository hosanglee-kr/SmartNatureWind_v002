# `S10_Simul_0203.h` 상세 Spec

## ⚙️ 시스템 스펙 요약: S10_Simul_0203.h

대기 경계층 미기상학 기반의 **실시간 자연풍 물리 시뮬레이션 엔진(`CL_S10_Simulation`)** 헤더입니다. 난류 스펙트럼(von Kármán), 열기포(Thermal Bubble), 돌풍(Gust), 관성 필터, 60초 풍속 이력 및 120-entry 차트 링버퍼(`s_chartBuffer`)를 관리하며 `CL_P10_PWM`으로 최종 듀티를 출력합니다.

### 💾 구조체 및 타입 정의 (Structs & Types)

*   **`CL_S10_Simulation`** (`class`)
    *   **설명:** 물리 시뮬레이션 상태, `HISTORY_SIZE=60` 1Hz 풍속 이력, `CHART_CAPACITY=120` 차트 링버퍼, `CL_P10_PWM` 출력 참조 및 `ST_A20_FanConfig_t` 스냅샷을 캡슐화한 클래스입니다.
    *   **사용처:** `CT10_Ctl` 제어 매니저가 매 틱마다 `tick()`을 호출하고 `W10_Web_WS`가 `toChartJson()`으로 실시간 차트를 브로드캐스트할 때 사용됩니다.
*   **`ST_ChartEntry`** (`struct`)
    *   **설명:** 차트 링버퍼에 저장되는 단일 샘플(`timestamp`, `wind_speed`, `target_wind`, `pwm_duty`, `intensity`, `variability`, `turbulence_sigma`, `preset_index`, `gust_active`, `thermal_active`) 구조체입니다.
    *   **사용처:** `s_chartBuffer[120]`에 기록되어 `toChartJson()`으로 프론트엔드 Chart.js에 전송됩니다.

### 🛠️ 함수 정의 및 시그니처 (Functions & Signatures)

| 함수명 | 반환 타입 | 주요 기능 | 핵심 로직/특징 |
| :--- | :--- | :--- | :--- |
| **`begin` / `stop` / `resetDefaults`** | `void` | 시뮬레이션 엔진을 초기화(`CL_P10_PWM&` 바인딩)하거나 정지·기본값 리셋합니다. | 1. `_fanCfgSnap` 및 물리 상태 변수를 초기화하고 정지 시 PWM을 0%로 내립니다. |
| **`tick`** | `void` | 매 제어 루프 틱마다 위상·난류·열기포·돌풍·목표 풍속을 갱신하고 팬에 출력합니다. | 1. `updatePhase()`, `calcTurb(dt)`, `updateGust()`, `updateThermal()`을 순차 연산합니다. <br>2. 최종 풍속을 `applyFan()`으로 PWM 출력하고 `_updateWindHistory()`·차트 버퍼를 갱신합니다. |
| **`applyResolvedWind`** | `void` | `S20_WindSolver`가 해석한 `ST_A20_ResolvedWind_t` 파라미터를 엔진에 적용합니다. | 1. 프리셋·스타일·오버라이드 배수가 반영된 목표 풍속/강도/변동성/돌풍 값을 즉시 반영합니다. |
| **`patchFromJson` / `reapplyPresetCore`** | `bool` / `void` | JSON 패치로 물리 파라미터를 직접 수정하거나 현재 프리셋을 재적용합니다. | 1. 수동 튜닝 파라미터를 안전 범위로 보정한 뒤 물리 위상을 재초기화합니다. |
| **`toJson` / `toChartJson`** | `void` | 현재 시뮬레이션 상태 또는 120-entry 차트 버퍼(`p_diffOnly` 지원)를 JSON으로 직렬화합니다. | 1. `p_diffOnly=true` 시 마지막 전송 이후 신규 샘플만 증분 전송해 WS 대역폭을 절약합니다. |
