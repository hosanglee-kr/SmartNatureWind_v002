### 1.2 핵심 원칙
| 원칙 | 이유 |
|---|---|
| ESP32 = 오디오 미경유 | SSL×2 + PCM 중계 = 메모리/CPU 폭발 |
| API Key는 ESP32만 | Ephemeral Token 발급 |
| Function Call만 ESP32 | 8.1 12개 액션 재사용 |
| Live 실패 → REST 폴백 | 사용자 이탈 0 |
| 위험 명령 백엔드 차단 | Prompt injection 방어 |

## 3. API 설계

### 3.1 REST 엔드포인트 (7개)

| Method | Endpoint | 목적 | Body/응답 |
|---|---|---|---|
| POST | /api/v0203/ai/gemini | 자연어 제어 (12도구) | {message, history, lang, voiceMode} |
| GET | /api/v0203/ai/live-config | Live setup | {systemInstruction, tools, voiceName} |
| POST | /api/v0203/ai/live-token | Ephemeral Token | {token, expire, wsUrl} |
| POST | /api/v0203/ai/live-function | Function 위임 | {name, args} → {ok, result} |
| GET | /api/v0203/ai/cost-status | 비용 상태 | {audioSec, level, capSec} |
| POST | /api/v0203/ai/usage | 사용량 보고 | {audioSec, turns, estCostX1000} |
| POST | /api/v0203/ai/cost-reset | 수동 리셋 | - |

### 3.2 Live WS (브라우저 직접 연결)

    Endpoint: wss://generativelanguage.googleapis.com/ws/
              google.ai.generativelanguage.v1beta.GenerativeService.
              BidiGenerateContent?access_token=<ephemeral>

    메시지:
    B→G: setup, realtimeInput(audio), toolResponse, clientContent
    G→B: setupComplete, serverContent(text/audio), toolCall, interrupted

### 3.3 REST 요청/응답 스키마

요청:
    { "message": "1시간 후 꺼줘",
      "history": [{"role":"user","text":"..."}],
      "lang": "ko", "voiceMode": true }

응답:
    { "ok": true,
      "text": "네, 1시간 후에 꺼드릴게요",
      "_speechHint": "60분 후 자동으로 꺼드릴게요",
      "_lang": "ko",
      "actions": [{"name":"set_timer","args":{"minutes":60},"result":"ok"}],
      "session": {"type":"FIXED","runtimeAutoOff":{"active":true,"remainSec":3600}} }

## 6. 구현 순서

### Stage 8.0 (초안, 1주)
PoC: 순수 프록시 + Function Call 미지원 → 20개 이슈 발견

### Stage 8.1 (재작업, 4주)
2-turn Function Calling | SessionContext runtimeAutoOff | set_timer/add_schedule 실제 | 웨이크워드 | TTS 언어 자동 | 음성 실패 폴백 | 에러 복구 | API Key 헤더 | FAB 위치 재설계 | 20개 이슈 해결

### Stage 8.2 (캐시, 8.1 포함)
프롬프트 캐시 | 이력 localStorage | 스트리밍 인프라

### Stage 8.3A-1 (Live 브리지, 1주)
Ephemeral Token | Function Bridge | 모드 토글 UI | 세션 타이머

### Stage 8.3A-2 (오디오, 2주)
AudioWorklet 100ms | AEC 필수 | 24kHz 재생 | Barge-in flush | 리샘플 폴백

### Stage 8.3C (최적화, 1주)
N10 AI 사용량 일일 리셋 | Live 비용 상한 30분/일 | 자동 REST 폴백 | WS exponential backoff | 메모리 모니터링

### Stage 8.4A (참조 보완, 1주)
S1: add_profile(12도구) | S2: _speechHint 폴백 | S3: 위험 명령 화이트리스트 | S4: 시스템 지시 강화 | S5: 캡 12KB/8KB + rate 5s | S6: lang/voiceMode

### Stage 8.4B (S7+검증, 0.5주)
S7: release_manual_to_schedule | E2E 통합 검증
