## I.2 구현 규칙

### 구현 규착 일반
-  객체지향 모듈화 및 모듈별 책임 명확
- 하드코딩 금지
	- 모든 숫자 값은 의미 있는 이름의 상수로 정의
- 매직 넘버 제로
	- 코드 내에 직접 숫자(예: 1024, 1600)가 나타나지 않도록 함
-  컴파일 타임 계산 (Compile-time Derived Values)
	- 종속 파라미터는 하드코딩하지 않고 계산식으로 정의
```cpp
// MFCC 차원 = 계수 * 컴포넌트 * 총 채널 수 (8)
inline constexpr uint32_t MFCC_DIM_MAX = MFCC_COEFFS_MAX * MFCC_COMPONENTS_MAX * CHANNELS_MAX;
```

- 정적 메모리 할당 안전성과 런타임 유연성을 동시에 확보
	- _MAX: 정적 할당 상한선 (OOM 방지) - 배열 크기, 버퍼 크기
	- _DEF: 런타임 기본값 (실제 연산 루프 제어)
   - 헤더 파일 보호 
	- #pragma once 사용 (중복 인클루드 방지)
	- 헤더 선언 시 다중 정의 오류 방지를 위해 함수 선언은 클래스 내부 또는 inline으로 처리

- C++17 표준 준수
	- 프로젝트는 C++17(-std=gnu++17) 표준 준수
	- C++14 이하 기능은 사용 자제
- 워치독 (Watchdog)
	- 메인 루프에서 esp_task_wdt_reset() 주기적 호출
	- 장시간 블로킹 작업 전 워치독 리셋 또는 일시 비활성화 고려

3. 메모리 관리 규칙

3.1 정적 할당 (Static Allocation)

- 모든 배열과 버퍼는 _MAX 상수로 크기 결정
- VLA(Variable Length Array) 금지

```cpp
float band_energy[AXIS_MAX][BAND_MAX];  // OK
float buffer[size];                     // size가 constexpr이 아니면 금지
```

3.2 동적 할당 (Dynamic Allocation)

- PSRAM 사용 시: heap_caps_aligned_alloc(16, size, MALLOC_CAP_SPIRAM)
- SRAM 필요 시: MALLOC_CAP_INTERNAL | MALLOC_CAP_8BIT
- 반드시 할당 실패 검사 후 처리

```cpp
float* buffer = (float*)heap_caps_aligned_alloc(16, size, MALLOC_CAP_SPIRAM);
if (!buffer) { ESP_LOGE(...); return false; }
```

## *3. 시스템  State Machine설계**
### 상태(State) 정의
 * INIT: 부팅 직후 FS 마운트, 변수 초기화 상태.
 * IDLE: 네트워크는 연결되어 있으나 팬 구동이 정지된 대기 상태.
 * RUN_FIXED: 고정 속도 모드. 난류 연산을 중지하고 설정된 고정 PWM 값만 출력.
 * RUN_NATURAL: 자연풍 모드. WindEngine이 활성화되어 동적 풍속 제어.
 * STANDBY_PIR: 작동 중 PIR 움직임 부재로 인한 임시 수면 상태. 물리 연산 일시 정지(Pause) 및 팬 PWM 0 출력.
### 주요 전이(Transition) 조건
 * 작동 명령 수신 시: IDLE -> RUN_FIXED 또는 RUN_NATURAL.
 * 타이머(초) 만료 시: RUN_* -> IDLE (팬 종료 및 변수 초기화).
 * PIR 미감지 타임아웃 시: RUN_* -> STANDBY_PIR.
 * STANDBY_PIR 상태에서 모션 감지 시: STANDBY_PIR -> 이전 동작 상태(RUN_*)로 즉시 복귀. WindEngine의 페이즈(Phase) 및 난류 누적값 이력 유지.
