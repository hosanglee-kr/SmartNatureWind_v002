### 1.2 핵심 원칙
| 원칙 | 내용 및 이유 |
|---|---|
| **ESP32 = 오디오 미경유** | SSL×2 + PCM 실시간 중계 = 메모리/CPU 폭발 방지 (브라우저가 Gemini 직접 연결) |
| **API Key는 ESP32만 보관** | 브라우저에는 10~15분 유효 Ephemeral Token만 노출하여 탈취 방지 |
| **async_tcp 스레드 DoS 방어** | 2-turn REST 수행 시 단일 `async_tcp` 스레드가 30~50초 블로킹되는 현상 원천 차단 (비동기 Worker 또는 프론트 오케스트레이션) |
| **FSM 무중단 스케줄 복귀** | `release_manual_to_schedule`은 `stopSession()` 대신 `clearManual()`을 호출하여 스케줄 활성 시 팬 정지 없이 자연 전환 |
| **세션 종속 AutoOff 라이프사이클** | AI `set_timer`로 설정된 `runtimeAutoOff`는 세션 종료/전환 시 즉시 소멸 (NVS 전역 타이머와 엄격 분리) |
| **동시성 스냅샷 접근 규약** | AI 액션(`add_profile` 등) 실행 시 `g_A20_config_root` 직접 접근 절대 금지, 스냅샷 API 필수 경유 |
| **비용 게이트키핑 (2중 가드)** | 클라이언트 보고 의존 탈피 ➔ 백엔드가 일일 30분 상한 도달 시 토큰 재발급 원천 차단 |

## 3. API 설계

| Method | Endpoint | 목적 | Body/응답 |
|---|---|---|---|
| POST | /api/v001/ai/gemini | 자연어 제어 (12도구 2-turn) | {message, history, lang, voiceMode} |
| POST | /api/v001/ai/execute-action | 단일 도구 실행/검증 (Live/Client 공용) | {name, args} → {ok, result, session} |
| GET | /api/v001/ai/live-config | Live setup 설정 | {systemInstruction, tools, voiceName} |
| POST | /api/v001/ai/live-token | Ephemeral Token 발급 (10~15분 제한) | {token, expire, wsUrl} |
| POST | /api/v001/ai/live-function | Function Call ESP32 위임 | {name, args} → {ok, result} |
| GET | /api/v001/ai/cost-status | 비용 상태 조회 | {audioSec, level, capSec} |
| POST | /api/v001/ai/usage | 사용량 주기적 보고 | {audioSec, turns, estCostX1000} |
| POST | /api/v001/ai/cost-reset | 일일 사용량 수동 리셋 | - |

    Endpoint: wss://generativelanguage.googleapis.com/ws/

              BidiGenerateContent?key=<token>
    기본 음성: Aoede (Google Gemini Live 공식 권장 음성)

    메시지:
    B→G: setup, realtimeInput(audio), toolResponse, clientContent

## 6. 구현 순서

### Stage 8.0 (초안, 1주)
PoC: 순수 프록시 + Function Call 미지원 → 20개 이슈 발견

2-turn Function Calling | SessionContext runtimeAutoOff | set_timer/add_schedule 실제 | 웨이크워드 | TTS 언어 자동 | 음성 실패 폴백 | 에러 복구 | API Key 헤더 | FAB 위치 재설계 | 20개 이슈 해결

### Stage 8.2 (캐시, 8.1 포함)
프롬프트 캐시 | 이력 localStorage | 스트리밍 인프라

### Stage 8.3A-1 (Live 브리지, 1주)
Ephemeral Token | Function Bridge | 모드 토글 UI | 세션 타이머

### Stage 8.3A-2 (오디오, 2주)
AudioWorklet 100ms | AEC 필수 | 24kHz 재생 | Barge-in flush | 리샘플 폴백

### Stage 8.3C (최적화, 1주)
N10 AI 사용량 일일 리셋 | Live 비용 상한 30분/일 | 자동 REST 폴백 | WS exponential backoff | 메모리 모니터링
