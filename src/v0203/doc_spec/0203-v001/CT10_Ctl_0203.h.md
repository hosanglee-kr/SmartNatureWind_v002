# `CT10_Ctl_0203.h` 상세 Spec

## ⚙️ 시스템 스펙 요약: CT10_Ctl_0203.h

Smart Nature Wind v0203의 **중앙 제어 매니저(`CL_CT10_ControlManager`)** 헤더로, **7-State `runCtx` FSM**, **3-State Session FSM (`IDLE`/`ACTIVE`/`PAUSED`)**, **Smart Resume (5분/30분)**, **오버라이드(Fixed/Preset)**, **PIR/온습도/Auto-Comfort(5분 주기) 제어**, **Dirty-Flag WS 브로드캐스트** 및 **Stage 8 AI 도구 선언/안전 가드레일**을 총괄합니다.

### 💾 구조체 및 타입 정의 (Structs & Types)

*   **`CL_CT10_ControlManager`** (`class`)
    *   **설명:** `s_stateMutex`, `s_pendingReload`(atomic), `s_autoComfortEnabled`, `ST_CT10_PausedExec` 및 40ms 틱 루프(`tickLoop`)를 캡슐화한 싱글턴 제어 매니저입니다.
    *   **사용처:** `A00_Main_0203.cpp` 메인 루프 및 모든 `W10_Web_Routes_*` API 핸들러의 제어 진입점으로 사용됩니다.
*   **`ST_CT10_PausedExec`** (`struct`)
    *   **설명:** Session `PAUSED` 진입 시 실행 중이던 프로필/스텝/경과 시간을 보관하는 스냅샷 구조체입니다.
    *   **사용처:** `S_PAUSE_CONTINUE_MS`(5분) / `S_PAUSE_STEP_RESET_MS`(30분) Smart Resume 판정에 사용됩니다.
