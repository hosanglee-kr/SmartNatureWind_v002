📖 시나리오별 "현재 흐름 vs 이상적 흐름"

시나리오 A: "잠들기 전 조용한 바람 30분"

현재 사용자 여정 (5단계):

```
Dashboard 진입 
  → 스타일 탭 "수면" 클릭 
  → 프리셋 "FOREST_CANOPY" 클릭 
  → 🎵 자동화 탭 
  → ⏱️ 타이머 탭 
  → [30분] 버튼 
  → Dashboard 복귀
```

문제:

· 4개 화면 이동 (Dashboard → Automation → Timer → Dashboard)
· 하단 탭 6개 중 3개 경유
· 스타일/프리셋 선택과 타이머가 별개 화면

이상적 흐름 (2단계):

```
Dashboard 진입
  → 스타일·프리셋 선택
  → Now Playing Bar 옆 ⏱️ 퀵 버튼 → 시간 선택 → 완료
```

보완:

· 대시보드 하단 슬라이더 옆 "⏱️ N분 후 종료" 인라인 퀵 액션 추가
· Now Playing Bar의 타이머 배지가 현재 토글만 있음 (설정 불가) → 클릭 시 빠른 시간 선택 팝업

시나리오 B: "매일 아침 7시에 자동으로 켜지게"

현재 사용자 여정 (6단계 + 개념 이해 필요):

```
1. Studio에서 "프로필"이라는 개념 학습
2. Studio → Step 추가 → 프리셋 선택 → 스타일 → 저장
3. Playlist 탭에서 확인
4. Schedule 탭 이동
5. 스케줄 추가 → 프로필 선택 (위에서 만든 것)
6. 시간 설정 → 저장
```

문제:

· "프로필"이라는 개념을 먼저 배워야 스케줄을 만들 수 있음
· SchedulePanel에서 프로필이 없으면 스튜디오로 강제 리다이렉트
· 일반 사용자는 "왜 스케줄에 프리셋을 직접 못 넣지?"라고 느낌

이상적 흐름:

```
Schedule 탭
  → [+ 새 스케줄]
  → [간단 모드]: 프리셋 직접 선택 + 시간
  → [고급 모드]: 프로필 선택 (Studio에서 만든 것)
```

보완:

· SchedulePanel에 "간단 스케줄" 모드 추가 (프리셋 직접 참조)
· 백엔드 스키마 확장 필요 → ⚠️ 백엔드 승인 필요 (schedule.presetCode 직접 지원)
· FE 단독 대응: "간단 스케줄"은 단일 Step 프로필 자동 생성 후 스케줄 연결

시나리오 C: "팬이 안 돌아요" (문제 진단)

현재 사용자 여정 (탐색적 — 어디를 봐야 할지 모름):

```
Dashboard (정지 상태) → "왜?"
  → Sensors? Chart? Monitor? Diagnostics? Logs?
  → 5개 후보 화면 중 어디로?
```

문제:

· 진단 화면이 3곳에 분산: Chart (물리), Monitor (라이프사이클), Diagnostics (시스템)
· 일반 사용자는 "진단"이라는 IT 용어 이해 못함

이상적 흐름:

```
Dashboard 상단 배너:
  ⚠️ "현재 팬이 정지 상태입니다. [이유 보기]"
  → "PIR 감지 없음 (120초 경과)" 모달 + [재개] 버튼
```

보완:

· Dashboard 상단에 상태 배너 표시 (SNW.Banner 재활용, 이미 구현)
· control.stateCode !== 0 && sim.active === false 조건 시 원인 + 해결 버튼
· Diagnostics는 "고급 진단"으로 이름 변경, L4 유지

시나리오 D: "방 온도 맞춰서 알아서 조절"

}

_onQuickTimer() {
    const cur = (SNW.TimerManager && SNW.TimerManager.getStatus)
        ? SNW.TimerManager.getStatus() : null;
    if (cur && cur.active) {
        if (confirm(SNW.I18n.t('timer.cancel') + '?')) {
            SNW.TimerManager.cancel(true);
        }
        return;
    }
    const choice = prompt(SNW.I18n.t('timer.quickPrompt'), '30');
    const min = Number(choice);
    if (min > 0 && SNW.TimerManager) {
        SNW.TimerManager.start(min);
    }
}
