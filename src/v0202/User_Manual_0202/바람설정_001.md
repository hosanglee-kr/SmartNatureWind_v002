# 프리셋 · 스타일 · 강도 · 돌풍 · 변동성 — 기능 차이 완전 정리

이 5개는 **서로 다른 계층**에서 작동합니다. 하나로 합쳐지는 게 아니라 **곱해지고 더해지면서** 최종 PWM을 만듭니다.

---

## 🎯 한눈에 보는 계층 구조

```
[프리셋 = 환경의 성격]  OCEAN, MOUNTAIN, DESERT_NIGHT …
        │  (기본 물리값)
        ▼
[스타일 = 성격의 변주]  BALANCE, ACTIVE, SLEEP …
        │  × 계수 (곱셈)
        ▼
[S20 해석: ST_A20_ResolvedWind_t]  baseMinWind, gustProbBase …
        │
        ▼
[S10 시뮬레이션]
        │  × intensity (전체 볼륨)
        │  × gustFreq  (돌풍 빈도)
        │  × variability (변화율)
        ▼
   최종 PWM → 팬
```

**핵심**: 프리셋·스타일 = "**어떤 바람인가**" (성격), 강도·돌풍·변동성 = "**얼마나 세게/자주/급하게**" (강도 조절)

---

## 1️⃣ 프리셋 (Preset) — "환경의 근본 성격"

**정의**: 바람이 **어디서 부는지**를 흉내 낸 시나리오.
**코드 근거**: `ST_A20_WindPresetFactors_t`

| 프리셋 | 풍속 범위 (baseMin~Max) | 돌풍 발생률 | 돌풍 최대 세기 | 열기포 발생률 |
|---|---|---|---|---|
| **OCEAN** | 1.8 ~ 5.5 m/s | 0.040/s | ×2.10 | 0.022/s |
| **MOUNTAIN** | 2.5 ~ 7.0 m/s | 0.080/s | ×2.80 | 0.015/s |
| **DESERT_NIGHT** | 0.8 ~ 3.2 m/s | 0.020/s | ×1.50 | 0.005/s |

**예시**:
> OCEAN = 부드러운 파도처럼 잔잔하지만 종종 큰 파도(돌풍)가 몰아침
> MOUNTAIN = 기본 풍속이 세고 돌풍이 잦고 강함
> DESERT_NIGHT = 고요하고 차갑고, 강한 돌풍은 거의 없음

**프리셋은 "재료"**. 사용자가 이걸 직접 만지진 않음(설정에서 관리).

---

## 2️⃣ 스타일 (Style) — "같은 환경, 다른 기분"

**정의**: 프리셋의 각 물리값에 **곱셈 계수**를 적용한 변주.
**코드 근거**: `ST_A20_StyleFactors_t` × `S20_resolveWindParams`

| 스타일 | intensityFactor | variabilityFactor | gustFactor | thermalFactor |
|---|---|---|---|---|
| **BALANCE** | ×1.00 | ×1.00 | ×1.00 | ×1.00 |
| **ACTIVE** | ×1.20 | ×1.40 | ×1.30 | ×1.10 |
| **FOCUS** | ×1.10 | ×0.70 | ×0.60 | ×0.80 |
| **RELAX** | ×0.85 | ×0.60 | ×0.50 | ×0.90 |
| **SLEEP** | ×0.65 | ×0.40 | ×0.30 | ×0.60 |

**적용 방식** (코드 그대로):
```cpp
v_int  = preset.windIntensity  * style.intensityFactor;
v_var  = preset.windVariability * style.variabilityFactor;
v_gust = preset.gustFrequency * style.gustFactor;
v_thB  = preset.thermalBubbleStrength * style.thermalFactor;
```

**예시** — 같은 OCEAN, 스타일만 바꿈:

| | OCEAN + BALANCE | OCEAN + ACTIVE | OCEAN + SLEEP |
|---|---|---|---|
| 강도 | 70 × 1.00 = **70** | 70 × 1.20 = **84** | 70 × 0.65 = **45** |
| 변동성 | 55 × 1.00 = **55** | 55 × 1.40 = **77** | 55 × 0.40 = **22** |
| 돌풍 | 50 × 1.00 = **50** | 50 × 1.30 = **65** | 50 × 0.30 = **15** |

**스타일의 정체성**: 같은 바람 환경인데 "기분"만 바뀜. **잔잔한 바다 vs 거친 바다**.

---

## 3️⃣ 강도 (Intensity) — "**볼륨 노브**"

**정의**: 최종 팬 출력을 **전체 스케일링**. 모든 바람·돌풍·열기포가 비례해서 커지고 작아짐.
**코드 근거**: `S10::applyFan()`

```cpp
float v_intPct = clampVal(userIntensity, 0, 100);
// ... 곡선 적용 전에 전체 스케일
v_reqPct = (v_reqPct * v_intPct) / 100.0f;
```

그리고:
```cpp
if (!fanPowerEnabled || v_intPct <= 0.01f) {
    _pwm->P10_setDutyPercent(0.0f);
    return;   // 강도 0% = 팬 정지
}
```

**예시**:
- 계산된 PWM이 80%인데 intensity=50% → 실제 출력 40%
- 계산된 PWM이 80%인데 intensity=100% → 실제 출력 80%
- intensity=0% → **모든 바람이 죽음** (돌풍, 열기포 상관없이)

**강도와 다른 것들과의 관계**:

| 파라미터 | 강도를 바꾸면? |
|---|---|
| 프리셋 (OCEAN 등) | **변화 없음** (성격 유지) |
| 스타일 | **변화 없음** |
| 돌풍 발생률 | **변화 없음** (여전히 자주 옴) |
| 돌풍의 체감 세기 | **비례 감소** (100%→50%는 반으로) |
| 변동성 | **변화 없음** (여전히 급격) |

**비유**: 스테레오 앰프의 **볼륨 노브**. 곡(바람의 성격)은 그대로인데 크기만 조절.

---

## 4️⃣ 돌풍 빈도 (Gust Freq) — "**돌풍이 얼마나 자주 오는가**"

**정의**: 돌풍이 **발생하는 확률**을 조절. 돌풍의 **세기(강도)**가 아님!
**코드 근거**: `S10::updateGust()`

```cpp
const float v_user = clampVal(userGustFreq, 0, 100) / 100.0f;
const float v_ratePerSec = gustProbBase * v_user * v_phaseMul;
const float v_p = 1 - expf(-v_ratePerSec * v_dtSec);
if (getRandom01() < v_p) {
    // 돌풍 발생
    gustIntensity = 1 + (gustStrengthMax - 1) * env;   // ← 세기는 gustStrengthMax가 결정
}
```

여기서 `gustStrengthMax`는 **프리셋 값**입니다. 사용자는 이걸 못 만짐.

**예시**:

| userGustFreq | 돌풍 발생률 (실효) | 체감 |
|---|---|---|
| **100%** | `0.04 × 1.0 = 0.04/s` → **평균 25초에 1회** | 자주 몰아침 |
| **45%** | `0.04 × 0.45 = 0.018/s` → **평균 55초에 1회** | 가끔 몰아침 |
| **0%** | `0` → **돌풍 없음** | 부드럽기만 함 |

**중요한 구분**:

| 항목 | 사용자 조절 | 결정 인자 |
|---|:---:|---|
| 돌풍이 **얼마나 자주** 오나? | ✅ `gustFreq` | userGustFreq |
| 돌풍이 **얼마나 세게** 오나? | ❌ | 프리셋의 `gustStrengthMax` |
| 돌풍이 **얼마나 길게** 지속되나? | ❌ | phase + 프리셋 값 |

**비유**: "아이스크림을 **얼마나 자주 먹는가**"는 조절 가능하지만, "한 번에 **몇 스쿱인가**"는 정해져 있음.

---

## 5️⃣ 변동성 (Variability) — "**얼마나 급하게 바뀌는가**"

**정의**: 목표 풍속으로 **수렴하는 속도** + **목표값의 재생성 빈도**.
**코드 근거**: `S10_Simul_Core_0202.cpp` + `S10_Simul_Physic_0202.cpp`

### (a) 수렴 속도 (windChangeRate)
```cpp
float v_varNorm = userVariability / 100.0f;
windChangeRate = 0.06f + v_varNorm * 0.28f;   // 0.06~0.34 범위
```

풍속이 목표값으로 **얼마나 빨리** 이동하는지. 매 tick마다:
```cpp
v_change = (target - current) * windChangeRate * dt;
```

| variability | windChangeRate | 체감 |
|---|---|---|
| **100%** | 0.34 | 목표값까지 **3초** 수렴 |
| **50%** | 0.20 | 목표값까지 **5초** 수렴 |
| **10%** | 0.09 | 목표값까지 **11초** 수렴 (매우 부드러움) |

### (b) 목표 재생성 (generateTarget)
```cpp
v_base = G_S10_WCR_NORM_BASE + v_var * G_S10_WCR_NORM_RANGE;  // 변동성 ↑ = 목표 자주 바뀜
```

변동성이 높으면 **목표값 자체도 더 자주 바뀜**. 결과적으로:
- **높음**: 목표가 계속 바뀌고 + 빨리 쫓아감 → **들쭉날쭉, 급격**
- **낮음**: 목표가 잘 안 바뀌고 + 천천히 쫓아감 → **부드러움, 일정**

**예시 그래프**:

```
variability=10%  ────────────  (거의 일정)
variability=50%  ∿∿∿∿∿∿∿∿∿∿  (약간 물결)
variability=100% ∿∿∿∿∿∿∿∿∿∿∿∿ (급격한 진동)
```

**비유**: 자동차 **가속 페달의 반응성**. 낮으면 부드럽게 가속, 높으면 급가속/급감속을 반복.

## 🎨 종합 예시 — 5파라미터 조합 시나리오

### 시나리오 A: "잠들기 직전"
```
프리셋  : OCEAN  (잔잔한 바다)
스타일  : SLEEP  (×0.65 강도, ×0.4 변동성, ×0.3 돌풍)
강도    : 40%
돌풍빈도: 20%
변동성  : 25%
```
**결과**: 매우 부드럽고 낮은 바람. 돌풍 드물고 약함. "선풍기 저속 1단" 느낌.

### 시나리오 B: "숲속 산책"
```
프리셋  : FOREST_CANOPY
스타일  : BALANCE
강도    : 70%
돌풍빈도: 50%
변동성  : 50%
```
**결과**: 중간 세기, 가끔 나뭇잎 흔드는 돌풍. 자연스러운 일상 느낌.

### 시나리오 C: "폭풍우 체험"
```
프리셋  : MOUNTAIN   (돌풍 강함 ×2.8)
스타일  : ACTIVE     (×1.4 변동성, ×1.3 돌풍)
강도    : 100%
돌풍빈도: 90%
변동성  : 90%
```
**결과**: 강한 바람이 매우 자주, 매우 세게, 급격히 몰아침. "야외 폭풍" 시뮬.

### 시나리오 D: "같은 조건, 강도만 다르게"
```
프리셋  : OCEAN, 스타일: BALANCE, gustFreq: 45%, variability: 50%
강도    : 100%  →  평균 PWM 60%, 피크 90%
강도    : 50%   →  평균 PWM 30%, 피크 45%   ← 모든 것이 절반
강도    : 0%    →  팬 정지 (돌풍 무관)
```
**관찰**: 프리셋/스타일/돌풍/변동성은 **동일한 상대 패턴**, 크기만 절반.

## ⚠️ 자주 오해되는 부분

### ❌ "돌풍강도 = 사용자가 조절하는 값"
✅ **틀림**. 사용자 "돌풍" 슬라이더는 **발생 빈도**만 조절. 세기는 프리셋이 결정.

### ❌ "강도 낮추면 돌풍도 안 옴"
✅ **틀림**. 돌풍은 여전히 같은 빈도로 옴. 그저 **작게** 옴. (강도=0%면 팬 정지라 무관)

### ❌ "변동성 = 강도"
✅ **틀림**. 변동성은 **변화율**, 강도는 **크기**. 변동성 100% + 강도 20% = "약하지만 급격하게 흔들리는 바람".

### ❌ "스타일 = 프리셋"
✅ **틀림**. 스타일은 프리셋에 **곱셈**. 같은 스타일도 프리셋이 다르면 완전히 다른 바람.

# Smart Nature Wind — 바람 설정 일반 사용자 매뉴얼

바람을 만드는 5가지 설정을 이해하기 쉽게 설명합니다.
모든 프리셋(10종)과 모든 스타일(5종)을 포함합니다.

---

## 한눈에 보는 5가지 역할

| 설정 | 무엇을 조절 | 비유 |
|---|---|---|
| **프리셋** | 어떤 장소의 바람인가 | 바닷가 vs 산 vs 사막 |
| **스타일** | 그 장소에서 어떤 기분인가 | 잔잔한 바다 vs 거친 바다 |
| **강도** | 전체 세기 | 볼륨 노브 |
| **돌풍빈도** | 돌풍이 얼마나 자주 오는가 | 강풍이 오는 간격 |
| **변동성** | 바람이 얼마나 빨리 변하는가 | 급격함 vs 부드러움 |

**원칙**: 프리셋·스타일 = "**어떤 바람**", 강도·돌풍·변동성 = "**얼마나**"

---

## 1. 프리셋 — "장소의 성격" (10종 전체)

실제 장소의 바람 특성을 미리 정해둔 것입니다. 풍속·돌풍·열기포의 기본값이 여기서 결정됩니다.

### 1.1 전체 프리셋 목록

| # | 프리셋 이름 | 한글 | 평소 풍속 | 성격 |
|---|---|---|---|---|
| 1 | **OCEAN** | 해변 바람 | 초속 1.8~5.5 m | 잔잔한 파도처럼 부드럽다가 가끔 큰 파도처럼 몰아침 |
| 2 | **COUNTRY_BREEZE** | 시골 바람 | 초속 0.7~3.4 m | 아주 잔잔하고 규칙적. 들판의 미풍 |
| 3 | **MEDITERRANEAN** | 지중해 바람 | 초속 1.5~4.5 m | 따뜻하고 부드러운 산들바람. 규칙적으로 흔들림 |
| 4 | **MOUNTAIN** | 산 바람 | 초속 2.5~7.0 m | 세고 거칠고 자주 흔들림. 급격한 변화 |
| 5 | **PLAINS** | 대평원 바람 | 초속 2.0~6.0 m | 넓고 일정하게 부는 바람. 중간 세기 |
| 6 | **HARBOR_BREEZE** | 항구 바람 | 초속 1.5~5.0 m | 배 위에서 부는 바람. 습하고 부드러움 |
| 7 | **FOREST_CANOPY** | 숲 그늘 바람 | 초속 1.0~4.0 m | 나뭇잎 사이로 부는 산들바람. 자연스러운 변화 |
| 8 | **URBAN_SUNSET** | 도시 석양 바람 | 초속 1.5~4.5 m | 건물 사이 부는 바람. 중간 세기, 약간 급격 |
| 9 | **TROPICAL_RAIN** | 열대 소나기 바람 | 초속 2.0~6.5 m | 후텁지근하다가 갑자기 강하게 몰아침. 돌풍 잦음 |
| 10 | **DESERT_NIGHT** | 사막의 밤 바람 | 초속 0.8~3.2 m | 고요하고 차갑고 정적. 강한 돌풍은 없음 |

### 1.2 대표 프리셋 상세 (실측값)

설정 파일에서 실측 확인된 대표 프리셋 2종:

| 항목 | OCEAN (해변) | COUNTRY_BREEZE (시골) |
|---|---|---|
| **평소 풍속** | 초속 1.8~5.5 m | 초속 0.7~3.4 m |
| **기본 강도** | 70 | 55 |
| **변동성** | 55 | 40 |
| **돌풍 빈도** | 50 | 30 |
| **팬 최대 출력** | 95% | 90% |
| **팬 최소 출력** | 12% | 10% |
| **돌풍이 오는 간격** | 약 25초에 한 번 | 약 40초에 한 번 |
| **돌풍 최대 세기** | ×2.1배 | ×1.8배 |
| **열기포 주기** | 약 45초에 한 번 | 약 60초에 한 번 |
| **체감** | 잔잔하다가 종종 파도처럼 몰아침 | 규칙적이고 부드러움 |

**나머지 8종**은 성격 설명을 기준으로 동작하며, "바람 프리셋 관리" 페이지에서 세부값을 확인·수정할 수 있습니다.

### 1.3 프리셋 선택 가이드

| 원하는 느낌 | 추천 프리셋 |
|---|---|
| 조용하고 규칙적 | **COUNTRY_BREEZE**, **FOREST_CANOPY** |
| 자연스럽고 잔잔 | **OCEAN**, **MEDITERRANEAN**, **HARBOR_BREEZE** |
| 중간 세기, 일상 | **PLAINS**, **URBAN_SUNSET** |
| 강하고 거친 | **MOUNTAIN**, **TROPICAL_RAIN** |
| 고요하고 차분 | **DESERT_NIGHT** |

## 2. 스타일 — "그날의 기분" (5종 전체)

같은 장소라도 기분에 따라 잔잔할 수도, 거칠 수도 있습니다.
스타일은 프리셋 숫자에 **곱해지는 계수**입니다.

### 2.1 전체 스타일 계수표

| 스타일 | 강도 계수 | 변동성 계수 | 돌풍 계수 | 열기포 계수 | 체감 |
|---|---|---|---|---|---|
| **BALANCE** (균형) | ×1.00 | ×1.00 | ×1.00 | ×1.00 | 프리셋 설계 그대로 |
| **ACTIVE** (활동적) | ×1.20 | ×1.40 | ×1.30 | ×1.10 | 20% 세고, 40% 더 급하고, 돌풍 30% 자주 |
| **FOCUS** (집중) | ×1.10 | ×0.70 | ×0.60 | ×0.80 | 10% 세지만 30% 더 일정하고 돌풍 40% 감소 |
| **RELAX** (휴식) | ×0.85 | ×0.60 | ×0.50 | ×0.90 | 15% 약하고 40% 더 부드럽고 돌풍 절반 |
| **SLEEP** (수면) | ×0.65 | ×0.40 | ×0.30 | ×0.60 | 35% 약하고 아주 부드럽고 돌풍 70% 감소 |

### 2.2 스타일별 체감 상세

| 스타일 | 언제 쓰나 | 체감 |
|---|---|---|
| **BALANCE** | 평상시 | "그 프리셋의 표준 느낌" |
| **ACTIVE** | 운동, 더위 식히기 | "20% 크고, 40% 더 급격하게 흔들림" |
| **FOCUS** | 집중 작업 | "조금 세지만 규칙적, 돌풍 드묾" |
| **RELAX** | 독서, 휴식 | "부드럽고 차분, 돌풍 적음" |
| **SLEEP** | 취침 | "아주 약하고 조용, 거의 일정" |

### 2.3 실제 숫자 예시 — 같은 해변 프리셋, 스타일만 바꿈

| 조건 | 기본 강도 | 변동성 | 돌풍 빈도 |
|---|---|---|---|
| 해변 + **BALANCE** | 70 | 55 | 50 |
| 해변 + **ACTIVE** | 84 (70×1.2) | 77 (55×1.4) | 65 (50×1.3) |
| 해변 + **FOCUS** | 77 (70×1.1) | 39 (55×0.7) | 30 (50×0.6) |
| 해변 + **RELAX** | 60 (70×0.85) | 33 (55×0.6) | 25 (50×0.5) |
| 해변 + **SLEEP** | 46 (70×0.65) | 22 (55×0.4) | 15 (50×0.3) |

**같은 "해변 바람"인데**:
- **BALANCE** → 평범한 바닷가
- **ACTIVE** → 세차게 몰아치는 바다
- **SLEEP** → 고요한 밤바다

## 3. 강도 — "전체 세기 (볼륨 노브)"

가장 단순합니다. **모든 바람이 정확히 비례**해서 커지거나 작아집니다.

### 3.1 강도별 실제 출력

| 강도 | 평균 풍속 변화 | 돌풍 세기 | 체감 |
|---|---|---|---|
| **100%** | 프리셋 설계 그대로 | ×2.1배 유지 | 최대 |
| **75%** | 3/4로 감소 | ×2.1배 유지 (비율 유지) | 강함 |
| **50%** | 정확히 절반 | ×2.1배 유지 | 중간 |
| **25%** | 1/4로 감소 | ×2.1배 유지 | 약함 |
| **10%** | 1/10로 감소 | ×2.1배 유지 | 매우 약함 |
| **0%** | 정지 | 없음 | 팬 멈춤 |

**중요**: 강도를 낮춰도 **돌풍 오는 간격은 그대로**입니다. 크기만 작아집니다.

### 3.2 예시 — 해변 + BALANCE 기준, 강도만 다르게

| 강도 | 평균 풍속 | 돌풍 최대 |
|---|---|---|
| 100% | 3.6 m/s | 7.6 m/s |
| 50% | 1.8 m/s | 3.8 m/s |
| 25% | 0.9 m/s | 1.9 m/s |
| 0% | 0 m/s | 없음 |

## 4. 돌풍빈도 — "돌풍이 오는 간격"

**돌풍이 얼마나 자주 오는지**만 결정합니다. 돌풍의 세기(얼마나 강한지)는 아닙니다.

### 4.1 돌풍빈도별 평균 주기 (해변 프리셋 기준)

| 돌풍빈도 | 평균 주기 | 10분 동안 횟수 |
|---|---|---|
| **100%** | 약 25초에 한 번 | 약 24회 |
| **75%** | 약 33초에 한 번 | 약 18회 |
| **50%** | 약 50초에 한 번 | 약 12회 |
| **25%** | 약 100초에 한 번 | 약 6회 |
| **10%** | 약 250초 (4분)에 한 번 | 약 2회 |
| **0%** | 없음 | 0회 |

### 4.2 주의사항

| 항목 | 사용자 조절 | 결정 인자 |
|---|---|---|
| 돌풍이 **얼마나 자주** 오나? | ✅ 이 설정 | 돌풍빈도 |
| 돌풍이 **얼마나 세게** 오나? | ❌ | 프리셋의 돌풍 최대 세기 |
| 돌풍이 **얼마나 길게** 지속되나? | ❌ | 프리셋 + 현재 풍속 상태 |

**예시** — 해변 + 강도 50% 기준:
- 돌풍빈도 **100%**: 25초마다 한 번씩 절반 세기의 돌풍
- 돌풍빈도 **20%**: 2분마다 한 번씩 절반 세기의 돌풍

## 5. 변동성 — "바람이 변하는 속도"

바람의 세기가 **얼마나 급격하게 변하는가**를 결정합니다.

### 5.1 변동성별 체감

| 변동성 | 풍속이 목표까지 도달하는 시간 | 체감 |
|---|---|---|
| **100%** | 약 3초 | 매우 급격, 들쭉날쭉 |
| **75%** | 약 4초 | 급격함 |
| **50%** | 약 5초 | 자연스러움 |
| **25%** | 약 8초 | 부드러움 |
| **10%** | 약 11초 | 매우 부드러움, 거의 일정 |
| **0%** | 변화 없음 | 일정함 |

### 5.2 실제 숫자 예시 — 해변 + 강도 70% 기준

| 변동성 | 10초 동안 풍속 변화 (m/s) |
|---|---|
| **10%** | 3.6 → 3.7 → 3.6 → 3.8 → 3.7 (거의 일정) |
| **50%** | 3.6 → 4.2 → 3.9 → 4.5 → 4.0 (자연스러운 물결) |
| **100%** | 3.6 → 5.1 → 2.8 → 4.9 → 2.5 (급격한 진동) |

**추가 특징**: 변동성이 높으면 **바람의 목표값 자체도 자주 바뀝니다**. 그래서 들쭉날쭉해집니다.

## 8. 자주 헷갈리는 질문

### Q1. 강도를 낮추면 돌풍도 안 오나요?
→ **아닙니다**. 돌풍은 **같은 간격**으로 오지만 **작게** 옵니다.
   강도 0%일 때만 팬이 완전히 멈춥니다.

### Q2. 변동성이랑 강도 차이가 뭔가요?
→ **강도 = 크기**, **변동성 = 변화 속도**.
   변동성 100% + 강도 20% = "**약하지만 급격하게 흔들리는** 바람".

### Q3. 돌풍빈도와 변동성 차이?
→ **돌풍빈도** = "**갑자기 강해지는 순간**"의 빈도.
   **변동성** = "**평소 세기가 바뀌는 속도**".

### Q4. 스타일을 바꾸면 프리셋도 바뀌나요?
→ **아닙니다**. 스타일은 프리셋 숫자에 **곱해지는 계수**.
   프리셋 자체는 그대로입니다.

### Q5. 프리셋은 왜 직접 못 만지나요?
→ 일상에서는 **스타일·강도·돌풍·변동성**만으로 충분합니다.
   프리셋은 "**바람 프리셋 관리**" 페이지에서 고급 사용자가 추가·편집 가능.

### Q6. 프리셋과 스타일을 다르게 하면 어떻게 되나요?
→ **다르게 곱해집니다**. 예시:

| 조합 | 최종 체감 |
|---|---|
| MOUNTAIN + SLEEP | 산인데 조용한 날 |
| OCEAN + ACTIVE | 해변인데 폭풍우 |
| DESERT_NIGHT + ACTIVE | 사막인데 강풍 |

### Q7. 같은 설정인데 바람이 계속 다른 이유?
→ **변동성**이 높으면 매 순간 목표값이 바뀌기 때문입니다.
   일정하게 유지하고 싶으면 **변동성을 10~25%로 낮추세요**.

# Smart Nature Wind — 전체 파라미터 단위 & 물리 개념 매뉴얼

강도·변동성·돌풍빈도(핵심 3개) + 추가 설정 전체를 단위와 물리 개념으로 정리합니다.

---

## 📌 핵심 3개 슬라이더 (사용자 일상 조절)

**강도 · 변동성 · 돌풍빈도** — 대시보드 슬라이더로 직접 조절. 모두 `%` 단위이지만 **내부 물리량은 완전히 다름**.

---

## 1️⃣ 강도 (Intensity) — "선형 배율"

### 변환 공식
```
실제 PWM = 계산된 PWM × (강도 / 100)
```

**변환 후에도 그대로 "배율(%)"**. 가장 단순한 선형 관계.

### 구체 예시

| 상황 | 계산된 PWM | 강도 | 실제 출력 |
|---|---|---|---|
| A | 80% | **100%** | **80%** |
| B | 80% | **50%** | **40%** |
| C | 80% | **25%** | **20%** |
| D | 80% | **0%** | **0%** (팬 정지) |
| E | 60% | **50%** | **30%** |

**의미**: 모든 바람에 **정확히 비례**. 볼륨 노브와 동일.

---

## 2️⃣ 변동성 (Variability) — "수렴 속도 계수 (1/초 성격)"

### 변환 공식
```
windChangeRate = 0.06 + (변동성 / 100) × 0.28     [1/초]
수렴 시간 상수 τ = 1 / windChangeRate              [초]
매 tick 변화량 = (목표 − 현재) × windChangeRate × dt
```

### 실제 의미
**"매초 현재-목표 갭의 몇 %가 줄어드는가"**

| 변동성 | windChangeRate | **매초 갭 감소율** | **시간 상수 τ** | 체감 |
|---|---|---|---|---|
| **10%** | 0.088 /초 | 매초 **8.8%** 감소 | **11.4초** | 매우 부드러움 |
| **25%** | 0.13 /초 | 매초 **13%** 감소 | **7.7초** | 부드러움 |
| **50%** | 0.20 /초 | 매초 **20%** 감소 | **5.0초** | 자연스러움 |
| **75%** | 0.27 /초 | 매초 **27%** 감소 | **3.7초** | 급격함 |
| **100%** | 0.34 /초 | 매초 **34%** 감소 | **2.9초** | 매우 급격 |

### 구체 예시 — 현재 3.0 m/s, 목표 6.0 m/s일 때

**변동성 50% (rate 0.20/초)**:

| 시간 | 풍속 | 남은 갭 |
|---|---|---|
| t=0 | 3.00 m/s | 3.00 |
| t=1s | 3.60 m/s | 2.40 (20% 감소) |
| t=2s | 4.08 m/s | 1.92 (20% 감소) |
| t=5s | 4.90 m/s | 1.10 (**63% 도달**, τ=5초) |
| t=15s | 5.85 m/s | 0.15 (**95% 도달** = 3τ) |

**변동성 100% (rate 0.34/초)**:

| 시간 | 풍속 | 남은 갭 |
|---|---|---|
| t=0 | 3.00 m/s | 3.00 |
| t=1s | 4.02 m/s | 1.98 (34% 감소) |
| t=3s | 4.90 m/s | 1.10 (**63% 도달**, τ=2.9초) |
| t=9s | 5.85 m/s | 0.15 (**95% 도달** = 3τ) |

**변동성 10% (rate 0.088/초)**:

| 시간 | 풍속 | 남은 갭 |
|---|---|---|
| t=0 | 3.00 m/s | 3.00 |
| t=1s | 3.26 m/s | 2.74 (8.8% 감소) |
| t=11s | 4.90 m/s | 1.10 (**63% 도달**, τ=11.4초) |
| t=34s | 5.85 m/s | 0.15 (**95% 도달** = 3τ) |

**핵심**: 변동성 100%는 3초 만에 거의 도달, 10%는 30초 넘게 걸림.

---

## 3️⃣ 돌풍빈도 (Gust Freq) — "초당 발생률 (1/초)"

### 변환 공식
```
rate (1/초) = 프리셋 기본값 × (돌풍빈도 / 100) × phaseMultiplier
평균 간격 (초) = 1 / rate
```

### 실제 의미
**"초당 몇 번 발생 확률"** — 포아송 과정 (간격 불규칙).

### 구체 예시 — OCEAN 프리셋 기준 (기본 0.04/초)

| 돌풍빈도 | rate (1/초) | **평균 간격** | **10분간 횟수** |
|---|---|---|---|
| **0%** | 0 | **발생 안 함** | 0회 |
| **10%** | 0.004 /초 | **250초** (4분 10초) | 약 2회 |
| **25%** | 0.010 /초 | **100초** (1분 40초) | 약 6회 |
| **50%** | 0.020 /초 | **50초** | 약 12회 |
| **75%** | 0.030 /초 | **33초** | 약 18회 |
| **100%** | 0.040 /초 | **25초** | 약 24회 |

### 시뮬레이션 타임라인 예시

**돌풍빈도 25% (rate = 0.01/초)**:
```
t=0s    : 시작
t=87s   : 첫 돌풍 (평균 100초 이내)
t=210s  : 두 번째 돌풍
t=307s  : 세 번째 돌풍
```

**돌풍빈도 100% (rate = 0.04/초)**:
```
t=0s    : 시작
t=18s   : 첫 돌풍
t=41s   : 두 번째
t=63s   : 세 번째
t=95s   : 네 번째
```

**주의**: rate가 높아도 매초 발생은 아님. **매 tick마다 확률 판정**이므로 **간격이 불규칙**.

## 📊 핵심 3개 요약

| 항목 | 슬라이더 | 내부 단위 | 실제 물리량 | 예시 |
|---|---|---|---|---|
| **강도** | `%` | **선형 배율** | "출력의 몇 %" | 50% = PWM 40% (80×0.5) |
| **변동성** | `%` | **1/초** (수렴 계수) | "매초 갭의 몇 % 감소" | 50% = 매초 20% 감소, τ=5초 |
| **돌풍빈도** | `%` | **1/초** (발생률) | "초당 발생 확률" | 50% = 0.02/초 → 평균 50초 |

### ⚠️ 흔한 오해

- ❌ "돌풍빈도 100% = 항상 돌풍" → ✅ 평균 25초에 1회, 그 사이는 잔잔
- ❌ "변동성 100% = 무한 요동" → ✅ 3초 시간 상수로 수렴
- ❌ "강도 50% = 체감 절반" → ✅ 맞음 (유일한 선형 관계)

# 🔧 추가 설정 항목

강도·변동성·돌풍빈도 외에 조절 가능한 파라미터. 계층별로 정리.

---

## A. 팬 제어 파라미터 (가장 자주 만짐)

### 1. 팬 최대 출력 (fanLimit)

| 항목 | 값 |
|---|---|
| **슬라이더 단위** | `%` (0 ~ 100) |
| **내부 변환** | `_pwm->applyFanConfigCurve(..., v_maxPct/100.0f)` |
| **실제 물리량** | **PWM 상한값 (%)** — 최종 출력의 하드 캡 |

**동작**: 계산된 PWM이 얼마든, **최대 이 값을 넘지 않음**. (강도와 다름 — 강도는 전체 스케일, fanLimit은 상한 클램프)

| 상황 | 계산 PWM | fanLimit | 실제 출력 |
|---|---|---|---|
| A | 90% | **100%** | **90%** (제한 없음) |
| B | 90% | **70%** | **70%** (상한) |
| C | 90% | **50%** | **50%** (상한) |
| D | 30% | **50%** | **30%** (제한 없음) |

**체감**: "이 이상은 세게 안 틀어줘" — 팬 소음/수명/모터 한계 보호.

---

### 2. 팬 최소 출력 (minFan)

| 항목 | 값 |
|---|---|
| **슬라이더 단위** | `%` (0 ~ 100) |
| **내부 변환** | `v_minPct = clampVal(minFanPct, 0, 100)` |
| **실제 물리량** | **PWM 하한값 (%)** — 팬 정지 방지 |

**동작**: 강도가 낮아도 **팬은 최소 이 값으로 유지**. (강도 0%는 예외 → 팬 정지)

| 상황 | 요청 PWM | minFan | 실제 출력 |
|---|---|---|---|
| A | 5% | **10%** | **10%** |
| B | 15% | **10%** | **15%** (제한 없음) |
| C | 0% | **10%** | **0%** (강도 0% 예외) |

**체감**: "너무 약하면 팬이 안 돌아" → 최소 회전 보장.

---

### 3. 팬 전원 (fanPowerEnabled)

| 항목 | 값 |
|---|---|
| **체크박스** | `bool` (true / false) |
| **내부 변환** | `if (!fanPowerEnabled) → PWM=0` |
| **실제 물리량** | **팬 on/off 마스터 스위치** |

**동작**: false면 **강도·프리셋·스타일 모두 무시**, PWM=0 강제.

| fanPowerEnabled | 강도 | 출력 |
|---|---|---|
| **true** | 100% | 프리셋 설계 |
| **true** | 50% | 절반 |
| **false** | 100% | **0%** (무시) |
| **false** | 0% | **0%** |

**체감**: 안전 스위치. `강도=0%`와 유사하지만, **강도 값은 유지한 채** 잠시 끔.

---

## B. 시뮬레이션 물리 파라미터 (고급)

### 4. 난류 강도 (turbSigma, σ)

| 항목 | 값 |
|---|---|
| **슬라이더 단위** | 무차원 (0.0 ~ 3.0 권장) |
| **내부 변환** | `von Kármán 스펙트럼의 진폭 계수` |
| **실제 물리량** | **풍속 잔떨림의 표준편차** (단위 m/s 성격) |

**동작**: 값이 클수록 **풍속이 세밀하게 흔들림** (돌풍·변동성과 별개로, 초고주파 잔물결).

| turbSigma | 체감 |
|---|---|
| **0.1** | 아주 매끄러움 (인공적) |
| **0.5** | 자연스러운 미세 흔들림 (기본) |
| **1.5** | 뚜렷한 잔물결, 파도 느낌 |
| **3.0** | 거친 난류, 실제 폭풍 수준 |

**체감 비유**: "바람의 결(texture)" — 변동성이 큰 파도라면, 난류는 **물결의 미세한 잔물결**.

---

### 5. 난류 길이 스케일 (turbLenScale, L)

| 항목 | 값 |
|---|---|
| **슬라이더 단위** | 무차원 (1.0 ~ 100 권장) |
| **내부 변환** | `von Kármán의 L (적분 길이 스케일)` |
| **실제 물리량** | **난류 소용돌이의 크기 (m)** |

**동작**: 값이 클수록 **느리고 긴 파형**. 값이 작으면 **빠르고 짧은 파형**.

| turbLenScale | 체감 |
|---|---|
| **5** | 빠른 잔물결 (작은 소용돌이) |
| **40** | 자연스러운 중간 크기 (기본) |
| **100** | 느리고 긴 파도 (큰 소용돌이) |

**변동성과 차이**: 변동성 = **목표값으로 수렴 속도**. 난류 L = **잔물결의 공간적 크기**.

---

### 6. 열기포 강도 (thermalStrength)

| 항목 | 값 |
|---|---|
| **슬라이더 단위** | 배율 (1.0 ~ 3.0 권장) |
| **내부 변환** | `thermalContribution = (strength - 1) × envelope` |
| **실제 물리량** | **열기포가 순간 상승시킬 PWM 가산 (%)** |

**동작**: 열기포 발생 시 **순간적으로 +α% 출력 상승**. `strength=1`이면 상승 없음.

| thermalStrength | 열기포 시 PWM 가산 |
|---|---|
| **1.0** | **+0%** (열기포 무효) |
| **2.0** | **+5%** (기본) |
| **3.0** | **+10%** |
| **5.0** | **+20%** (강함) |

**체감**: "갑자기 따뜻한 상승기류가 부는 순간" 느낌.

---

### 7. 열기포 반경 (thermalRadius)

| 항목 | 값 |
|---|---|
| **슬라이더 단위** | 무차원 (0 ~ 100, 단위 m 성격) |
| **내부 변환** | `열기포 발생 시 지속 시간에 영향 (현재 코드는 참조만)` |
| **실제 물리량** | **열기포의 크기** (발생 빈도·지속시간 확장 예약 필드) |

**동작**: 현재 `S10`에서는 참조만 되고 시뮬레이션에 직접 사용되지 않음 (향후 확장 예약).

| thermalRadius | 의미 (설계 의도) |
|---|---|
| **5** | 작고 짧은 열기포 |
| **18** | 표준 (기본) |
| **50** | 크고 긴 열기포 |

**참고**: 프리셋 관리 페이지의 `thermalBubbleRadius`는 실사용, 이 슬라이더는 **S10 런타임 예약값**.

## C. 시뮬레이션 타이밍 (ms)

### 8. 시뮬레이션 주기 (simIntervalMs)

| 항목 | 값 |
|---|---|
| **슬라이더 단위** | **밀리초 (ms)** |
| **내부 변환** | `v_baseMs = simIntervalMs` + 지터(0~60ms) |
| **실제 물리량** | **물리 연산 1회당 실제 시간** |

**동작**: 이 값이 클수록 **연산 빈도 낮음** (CPU 절약, 반응 느림). 작을수록 부드럽지만 부하 증가.

| simIntervalMs | 초당 tick 수 | 체감 |
|---|---|---|
| **100 ms** | 10 Hz | 매우 부드러움, CPU 부하 높음 |
| **500 ms** | 2 Hz | 자연스러움 (기본) |
| **1000 ms** | 1 Hz | 뚝뚝 끊김, CPU 절약 |

**주의**: 너무 작으면 `loopTask` 부하 급증. WDT(10초) 안전 마진 확보 위해 **최소 100ms 권장**.

---

### 9. 돌풍 평가 간격 (gustIntervalMs)

| 항목 | 값 |
|---|---|
| **슬라이더 단위** | **ms** |
| **내부 변환** | `v_minGustEvalMs = gustIntervalMs` |
| **실제 물리량** | **돌풍 발생 확률 판정 주기** |

**동작**: 이 간격마다 확률 판정. 클수록 **판정 빈도 낮음** (돌풍 발생 패턴 거침).

| gustIntervalMs | 판정 빈도 | 체감 |
|---|---|---|
| **500 ms** | 2 Hz | 자연스러운 돌풍 (기본) |
| **2000 ms** | 0.5 Hz | 간헐적 |
| **5000 ms** | 0.2 Hz | 매우 드문 판정 |

**중요**: rate 모델은 `dt`로 자동 보정되므로 **평균 발생률은 유지**. 다만 **판정 세밀도**만 변함.

**동작**: `gustIntervalMs`와 동일 원리. 클수록 판정 거침.

| thermalIntervalMs | 판정 빈도 |

| **1000 ms** | 1 Hz (세밀) |

## D. 프리셋 관리 (고급 — 관리자 페이지)

### 11. 기본 최소/최대 풍속 (baseMinWind / baseMaxWind)

| 항목 | 값 |
|---|---|
| **입력 단위** | **m/s (초속 미터)** — 실제 물리 단위! |
| **내부 변환** | `phase`별 범위 확장의 기준 |
| **실제 물리량** | **Phase 사이에서 오가는 실제 풍속 범위** |

**동작**: 이 범위 안에서 `CALM / NORMAL / STRONG` phase가 결정됨.

| baseMin~Max | 평균 풍속 | 체감 |
|---|---|---|
| **0.7~3.4 m/s** (COUNTRY) | 약 2 m/s | 매우 잔잔 |
| **1.8~5.5 m/s** (OCEAN) | 약 3.6 m/s | 자연스러움 |
| **2.5~7.0 m/s** (MOUNTAIN) | 약 4.7 m/s | 강함 |

**유일하게 실제 물리 단위(m/s)를 쓰는 파라미터**. 나머지는 모두 정규화/배율.

---

### 12. 돌풍 기본 발생률 (gustProbBase)

| 항목 | 값 |
|---|---|
| **입력 단위** | **1/초 (초당 발생률)** |
| **내부 변환** | `rate = gustProbBase × (돌풍빈도/100) × phaseMul` |
| **실제 물리량** | **100% 슬라이더에서의 초당 돌풍 발생 확률** |

| gustProbBase | 슬라이더 100%일 때 평균 간격 |
|---|---|
| **0.02 /초** (사막) | **50초** |
| **0.04 /초** (해변) | **25초** |
| **0.08 /초** (산) | **12.5초** |

**체감**: 프리셋이 "그 장소의 돌풍 기본 빈도"를 결정.

---

### 13. 돌풍 최대 세기 (gustStrengthMax)

| 항목 | 값 |
|---|---|
| **입력 단위** | **배율 (×)** |
| **내부 변환** | `gustIntensity = 1 + (gustStrengthMax - 1) × envelope` |
| **실제 물리량** | **돌풍 시 PWM 몇 배까지 증폭되는가** |

| gustStrengthMax | 돌풍 시 PWM |
|---|---|
| **1.0** | **×1.0** (돌풍 무효) |
| **1.5** | ×1.5배 |
| **2.1** | ×2.1배 (해변 기본) |
| **2.8** | ×2.8배 (산 기본) |
| **3.5** | ×3.5배 (폭풍) |

**주의**: **사용자 슬라이더로 조절 안 됨** — 프리셋이 결정. `돌풍빈도`는 빈도, 이건 세기.

---

### 14. 열기포 기본 발생률 (thermalFreqBase)

| 항목 | 값 |
|---|---|
| **입력 단위** | **1/초** |
| **내부 변환** | `rate = thermalFreqBase × strengthMul × wfac × phaseMul` |
| **실제 물리량** | **초당 열기포 발생률** |

| thermalFreqBase | 평균 간격 |
|---|---|
| **0.005 /초** (사막) | **200초** |
| **0.022 /초** (해변) | **45초** |
| **0.04 /초** (열대) | **25초** |

---

### 15. 난류 길이 스케일 / 난류 강도 (프리셋 기본값)

| 항목 | 단위 |
|---|---|
| **turbulenceLengthScale** | 무차원 (m 성격) |
| **turbulenceIntensitySigma** | 무차원 (σ) |

**시뮬레이션 슬라이더와 차이**: 이건 **프리셋 기본값**. 시뮬 슬라이더는 이 값을 **사용자 조정으로 오버라이드**. 우선순위는 **시뮬 슬라이더 > 프리셋 기본값**.

### 17. PIR 유지 시간 (pir.holdSec)

| 항목 | 값 |
|---|---|
| **슬라이더 단위** | **초 (sec)** |
| **내부 변환** | `if ((now - lastDetected) > holdSec × 1000) → 비활성` |
| **실제 물리량** | **마지막 감지 후 팬 유지 시간** |

| holdSec | 체감 |
|---|---|
| **30초** | 사람이 나가면 30초 후 팬 정지 |
| **120초** | 2분 여유 (기본) |
| **600초** | 10분 유지 (넉넉) |

**체감**: 화장실 다녀오는 정도는 팬이 계속 돌아가도록.

# ⚠️ 통합 오해 정리

### 강도/변동성/돌풍빈도 관련
- ❌ "돌풍빈도 100% = 항상 돌풍" → ✅ 평균 25초에 1회
- ❌ "변동성 100% = 무한 요동" → ✅ 3초 시간 상수로 수렴
- ❌ "강도 50% = 체감 절반" → ✅ 맞음 (유일한 선형)

### 추가 항목 관련
- ❌ "팬 최대 출력 100%면 항상 최대 출력" → ✅ 상한 캡 (계산 PWM 낮으면 그대로 낮음)
- ❌ "돌풍 세기(gustStrengthMax)는 슬라이더로 조절" → ✅ 프리셋 관리에서만
- ❌ "turbSigma는 돌풍과 같은 것" → ✅ turbSigma = 고주파 잔물결, 돌풍 = 저주파 상승
- ❌ "simIntervalMs 작을수록 무조건 좋음" → ✅ WDT 위험, 최소 100ms 권장
- ❌ "PIR holdSec=0이면 즉시 정지" → ✅ 맞지만 사람 있어도 정지 위험, 최소 30초 권장
