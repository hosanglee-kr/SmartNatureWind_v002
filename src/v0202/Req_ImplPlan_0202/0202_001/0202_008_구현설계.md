> 4. 프론트엔드 UI 화면 컴포넌트 영향도 **0건 (Zero Impact)**

## 1. 개요 및 변경 전후 아키텍처 비교

### 1.1 Before vs After 비교

```
[ 기존 (Before): 4중 분산 및 수동 하드코딩 의존 ]
1. 백엔드 C++ 헤더 (A20_Const_*.h)       ──┐ 
2. 설정 JSON (data_v0202_src/json/*.json)──┼──> [수동 복제] ──> 데이터 불일치/휴먼 에러 빈발
3. 프론트 상수 (000.const.js / 010.config.js)│ 
4. 오프라인 모크 (998.offline_0202.js)    ──┘ (500줄 인라인 mock 객체 수동 타이핑)

[ 개선 (After): 실용적 최적안 (Pragmatic Optimum) 파이프라인 ]
[C++ 헤더: A20_Const_*.h] ──(빌드 시 파싱/추출)──> [000.const.js (상수 블록 자동 갱신)]
                                                    └──> UI 메타데이터(아이콘/색상/i18n)와 결합

[정적 JSON: data_v0202_src/json/*.json (SSOT)]
  ├── (빌드 시 자동 주입) ──> [998.offline_0202.js] (file:// 직접 열기 시 CORS 에러 원천 차단)
  └── (LittleFS Flashing) ──> [ESP32 Flash (/json/*.json)] ──> C10 백엔드 로드
```

### 1.2 왜 이 방식이 "최적"인가?
1. **불필요한 제3의 스펙 파일 제거**: 신규 JSON 스펙이나 별도의 복잡한 Codegen 툴체인을 추가하지 않고, 기존 빌드 도구인 [pio_gzip_0202.py](../tools_0202/pio_gzip_0202.py)에 통합됩니다.
2. **백엔드 개발 흐름 100% 보존**: 백엔드 엔지니어는 늘 하던 대로 C++ 헤더(`A20_Const_*.h`)와 `cfg_*.json`만 관리하면 됩니다.
3. **CORS 이슈의 원천적 해결**: 브라우저 보안 정책상 `file:///index.html`로 열면 외부 JSON `fetch()`가 불가능하지만, 빌드 시점에 최신 JSON을 JS 변수로 자동 주입해 두면 **인터넷/로컬 웹서버 없이도 더블클릭만으로 100% 완벽 동작**합니다.

### 3.2 정적 JSON $\rightarrow$ `998.offline_0202.js` 자동 인젝션 설계

#### (1) 주입 대상 JSON 파일 목록
[data_v0202_src/json/](../data_v0202_src/json/) 디렉토리의 파일들을 읽어 단일 객체로 패키징합니다:
1. `cfg_system_0202.json` $\rightarrow$ `cache.system`
2. `cfg_wifi_0202.json` $\rightarrow$ `cache.wifi`
3. `cfg_motion_0202.json` $\rightarrow$ `cache.motion`
4. `cfg_schedules_0202.json` $\rightarrow$ `cache.schedules`
5. `cfg_userProfile_0202.json` $\rightarrow$ `cache.userProfiles`
6. `cfg_windDict_0202.json` $\rightarrow$ `cache.windDict`
7. `cfg_nvsSpec_0202.json` $\rightarrow$ `cache.nvsSpec`
8. `cfg_pages_0202.json` $\rightarrow$ `cache.webPage`

#### (2) `998.offline_0202.js` 리팩토링 구조
기존 500줄의 인라인 mock 코드를 삭제하고, 아래와 같이 **자동 주입 플레이스홀더 + LocalStorage Dirty 캐시 머지** 구조로 간소화합니다.

```javascript
/* ---- 998.offline_0202.js (실용적 최적화 버전) ---- */
window.SNW = window.SNW || {};
(function(SNW) {
    'use strict';
    if (!window.SNW_OFFLINE) return;

    /* __AUTO_INJECT_CACHE_START__ */
    // [주의] 아래 DEFAULT_CACHE는 pio_gzip_0202.py 빌드 시 data_v0202_src/json/*.json에서 자동 주입됩니다.
    const DEFAULT_CACHE = {
        system: {}, wifi: {}, motion: {}, schedules: {}, userProfiles: {}, windDict: {}, nvsSpec: {}, webPage: {}
    };
    /* __AUTO_INJECT_CACHE_END__ */

    // 1. 메모리 캐시 초기화 (LocalStorage에 사용자가 수정한 내용이 있으면 덮어씀)
    const cache = {};
    for (const [key, val] of Object.entries(DEFAULT_CACHE)) {
        const saved = localStorage.getItem('snw.offline.' + key);
        if (saved) {
            try { cache[key] = JSON.parse(saved); continue; } catch(e) {}
        }
        cache[key] = JSON.parse(JSON.stringify(val)); // Deep copy
    }

    // 2. 가상 런타임 상태 (시뮬레이터 Ticker)
    const runtime = {
        control: {
            active: true, profileMode: false, state: 'SCHEDULE_RUN', stateCode: 3,
            reason: 'SCHEDULE_ACTIVE', reasonCode: 4, runSource: 1,
            time: { valid: true, hour: 10, min: 30, wday: 2 },
            sensor: { tempC: 24.5, humidity: 55, motionActive: true },
            system: { uptimeMs: 12000, epochNowMs: Date.now() }
        },
        sim: {
            active: true, phase: 'NORMAL', windSpeed: 4.5, targetWind: 5.0, pwmDuty: 55.0,
            presetCode: 'OCEAN', styleCode: 'BALANCE', intensity: 70, variability: 50, gustFreq: 45
        }
    };

    // 3. SNW.Api 오프라인 메서드 바인딩 (온라인과 100% 동일한 응답)
    const A = SNW.Api = SNW.Api || {};
    A.getState = async () => ({ control: runtime.control, sim: runtime.sim });
    A.getSim = async () => ({ sim: runtime.sim });
    A.getSystem = async () => cache.system;
    A.getMotion = async () => cache.motion;
    A.listSchedules = async () => cache.schedules;
    A.listProfiles = async () => cache.userProfiles;
    A.listWindProfiles = async () => cache.windDict;
    A.getWifiConfig = async () => cache.wifi;
    A.getWifiState = async () => ({ wifi: { state: { mode: 2, status: 'CONNECTED', ip: '192.168.4.1' } } });
    A.diag = async () => ({ heap: 125000, fs_used: 180000, fs_total: 1000000 });
    A.version = async () => ({ fw: 'FW_2.0.2', control: 'CT10_Ctl_0202', mode: 'OFFLINE_MOCK' });

    // 수정(Save) 시 LocalStorage에 반영하여 새로고침 시에도 유지
    A.saveSchedule = async (sch) => {
        // cache.schedules 갱신 및 localStorage.setItem('snw.offline.schedules', ...)
        return { ok: true };
    };

    console.log('[Offline] 빌드 타임 자동 주입 캐시 및 LocalStorage 로드 완료');
})(window.SNW);
```
