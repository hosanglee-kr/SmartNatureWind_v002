# 파트 I. 시작하기 (Getting Started)

## 1. 30초 빠른 시작 (처음 사용자용)

1. **전원 켜기**: 기기에 DC 5V(USB-C) 또는 DC 12V 전원을 연결합니다. 기기 내부의 NeoPixel 상태 LED가 파란색으로 점멸하며 2초 내에 부팅을 완료합니다.
2. **Wi-Fi 연결**: 스마트폰이나 PC의 Wi-Fi 설정에서 **`NatureWind`**를 선택합니다.
   - **초기 비밀번호**: `2540`
3. **웹 대시보드 열기**: 웹 브라우저(Chrome, Safari 등)를 열고 주소창에 아래 주소를 입력합니다:
   ```text
   http://192.168.4.1
   ```
   *(고속 Gzip 압축 전송을 통해 0.5초 이내에 단일 페이지 앱(SPA)이 즉시 로드됩니다)*
4. **4단계 온보딩 진행**: 첫 방문 시 나타나는 친절한 팝업을 따라 **[언어 선택 → Wi-Fi 안내 → 첫 바람 선택 → "지금 시작"]** 4단계를 진행합니다.
5. **자연풍 가동**: 대시보드 상단에서 **바람 스타일(균형/활동/집중/휴식/수면)** 을 고르고, 하단 4x2 그리드에서 **자연풍 프리셋(10종)** 중 하나를 탭하면 자연풍이 즉시 시작됩니다.
6. **팬 정지**: 화면 하단 **Now Playing Bar**의 **`⏹`** 버튼 또는 대시보드의 **[정지]** 버튼을 누르면 팬이 부드럽게 감속하며 안전하게 정지합니다.

## 2. 제품 소개 및 핵심 혁신 기능

### 2.1 Smart Nature Wind는 어떤 제품인가요?
Smart Nature Wind v0203은 기존 선풍기의 인위적인 1-2-3단 단순 정속 회전 대신, **실제 대기(大氣)의 기류 변화, 돌풍(Gust), 난류(Turbulence), 지표면 열기포(Thermal Bubble)를 실시간 물리 엔진(S10/S20)으로 연산하여 재현하는 차세대 스마트 자연풍 제어기**입니다.

고성능 ESP32 MCU(S3/C3)와 고속 LittleFS 웹서버를 자체 내장하여, 별도의 인터넷 클라우드나 전용 앱 설치 없이 스마트폰 브라우저만으로 모든 기능을 완벽하게 제어할 수 있습니다.

## 3. 기기 연결 및 웹 대시보드 접속

Smart Nature Wind는 2가지 Wi-Fi 연결 모드를 완벽하게 지원합니다:

```text
[모드 1: SoftAP 단독 모드]                  [모드 2: 공유기 STA 연동 모드]
스마트폰 ──(1:1 Wi-Fi 직접 연결)──► 기기      스마트폰/PC ──► 가정 내 공유기 ──► 기기
(외부 야외, 공유기 없는 환경, 192.168.4.1)      (가정/사무실 어디서나 접속, 인터넷 시간 자동 동기화)
```

### 3.1 SoftAP 모드로 직접 접속 (기본 방식)
1. 스마트폰의 Wi-Fi 설정 화면으로 이동하여 **`NatureWind`** 무선 네트워크를 선택합니다.
2. 비밀번호 **`2540`**을 입력하고 연결합니다.
3. 스마트폰 웹 브라우저(Safari, Chrome 등)를 실행하고 주소창에 **`http://192.168.4.1`**을 입력합니다.
> 💡 **안내**: 스마트폰 화면에 "인터넷에 연결되어 있지 않음" 또는 "Wi-Fi 연결 유지 여부" 메시지가 뜨더라도 반드시 **"연결 유지"**를 선택해 주세요. 인터넷 회선 없이 기기와 스마트폰이 1:1로 통신하는 정상적인 연결 과정입니다.

### 3.2 가정/사무실 공유기(STA) 연동 모드
1. SoftAP 상태로 접속한 후 상단 메뉴에서 **`네트워크`** (`#/network`) 페이지로 이동합니다.
2. 주변 Wi-Fi 검색 목록에서 연결할 가정용 공유기 SSID를 선택하고 암호를 입력한 후 **[Wi-Fi 설정 저장]**을 클릭합니다.
3. 기기가 공유기와 성공적으로 연결되면 기기 상태 LED가 **초록색 점등**으로 바뀌며, 공유기로부터 할당받은 IP(예: `http://192.168.0.50`)로 동일 네트워크에 연결된 모든 스마트폰과 PC에서 자유롭게 접속할 수 있습니다.

### 3.3 스마트폰 홈 화면에 바로가기 추가 (PWA 앱처럼 쓰기)
- **아이폰 (iOS Safari)**: 브라우저 하단 중앙의 **[공유]** 아이콘 탭 → **`홈 화면에 추가`** 선택
- **안드로이드 (Android Chrome)**: 브라우저 우측 상단 더보기(`⋮`) 탭 → **`홈 화면에 추가`** 또는 **`앱 설치`** 선택
- 이제 스마트폰 바탕화면의 아이콘을 터치하는 것만으로 전용 앱처럼 전체 화면으로 바로 실행됩니다.

### 3.4 하드웨어 배선 및 안전 설치 가이드 (DIY / 제작 가이드)
Smart Nature Wind 제어기를 실제 팬 모터 및 센서와 연결할 때 참고하는 표준 핀맵과 전원 구성도입니다:

```text
┌────────────────────────────────────────────────────────┐
│             Smart Nature Wind 하드웨어 배선도            │
├────────────────────────────────────────────────────────┤
│  [ESP32 보드]                                          │
│   • GPIO 6  ────────► 팬 PWM 제어선 (MOSFET 게이트)    │
│   • GPIO 17 ────────► DHT22 온습도 센서 데이터 (10kΩ 풀업)│
│   • GPIO 13 ────────► PIR 인체감지 센서 OUT (디지털 입력)│
│   • GPIO 48 ────────► 온보드 NeoPixel 풀컬러 LED        │
│   • GND     ────────► 공통 접지선 (Common GND)         │
├────────────────────────────────────────────────────────┤
│  [전원 배선 주의사항]                                   │
│   • ESP32 로직 전원: 5V (USB-C 포트 입력)              │
│   • 팬 구동 모터 전원: 12V 2A~3A 어댑터 권장            │
│   • ⚠️ 중요: 12V 어댑터의 (-)극과 ESP32의 GND는          │
```

|---|:---:|---|
| **Fan PWM 출력** | **GPIO 6** | 25kHz 고주파수 LEDC PWM (10-bit), 로직 레벨 N-Channel MOSFET (예: IRLZ44N, AO3400) 게이트 연결 (100Ω 직렬 저항 권장) |

| **USB CDC 콘솔** | **USB D+/D-** | 네이티브 USB CDC 시리얼 (115200bps, 부팅 로그 및 실시간 디버그) |

### 4.2 실내 쾌적도 (Comfort DI) 실시간 추천 및 5상태 카드
대시보드 상단에는 실시간 센서 온·습도를 기반으로 일본 기상청 표준 불쾌지수를 연산하여 실내 쾌적도와 최적의 바람을 제안하는 지능형 추천 카드가 배치되어 있습니다. 우측 상단의 **[자동 모드]** 토글 스위치를 켜면 사용자가 일일이 조작하지 않아도 실내 환경에 맞춰 자동으로 선풍기를 가동하고 멈춥니다.

#### 4.2.1 추천 카드의 5상태 UI 매트릭스
추천 카드는 현재 기기 가동 상태와 자동 모드 설정 여부에 따라 아래 5가지 상태로 명확하게 시각적 피드백을 제공합니다:

1. **자동 모드 ON · 가동 추천 (`AUTO_ON_RECOMMENDED`)**:
   - 불쾌지수가 높아 가동이 권장되는 상황이며, 기기가 스스로 자연풍을 가동하기 전 5초 카운트다운을 표시합니다.
   - 원클릭 **[지금 시작]** 버튼을 누르면 5초 대기 없이 즉각 가동할 수 있습니다.
2. **자동 모드 OFF · 가동 추천 (`AUTO_OFF_RECOMMENDED`)**:
   - 실내가 다소 덥거나 끈적여 최적의 추천 프리셋이 계산되었으나, 자동 모드가 꺼져 있어 사용자 선택을 대기하는 상태입니다.
   - **[지금 시작]** 버튼을 누르면 추천 바람이 즉시 재생됩니다.
3. **Comfort 자동 가동 중 (`AUTO_RUNNING`)**:
   - 쾌적도 자동 모드에 의해 최적의 자연풍 세션이 실행 중인 상태입니다.
   - 초록색 상태 배지와 함께 **[⏹ 세션 정지]** 버튼이 노출되어 언제든 원클릭으로 종료할 수 있습니다.
4. **수동 운전 중 (`MANUAL_ACTIVE`)**:
   - 사용자가 직접 프리셋이나 슬라이더, Wind Studio 작곡 세션을 재생 중인 상태입니다.
   - 사용자 제어권을 최우선으로 존중하여 자동 제어는 일시 대기하며, 현재 수동 바람 정보가 안내됩니다.
5. **대기 및 주기 평가 중 (`IDLE_AUTO_WAIT`)**:
   - 실내가 쾌적하거나 현재 정지 상태에서 다음 5분 주기 평가를 기다리는 상태입니다.
   - "다음 평가까지 X분 Y초 대기 중" 카운트다운이 표시됩니다.

### 4.3 바람 스타일 5종 탭 (44px 터치 접근성 규격)
모바일 기기에서도 오조작 없이 편안하게 터치할 수 있도록 최소 44px 높이로 규격화된 스타일 탭입니다:
- **`균형 (BALANCE)`**: 프리셋 본연의 표준 물리 값을 100% 그대로 연산합니다 (기본값).
- **`활동 (ACTIVE)`**: 무더운 한낮이나 운동 직후 강한 냉감과 역동적인 돌풍을 선사합니다.
- **`집중 (FOCUS)`**: 기류의 급격한 변동과 모터 소음을 억제하여 공부나 업무에 몰입하도록 돕습니다.
- **`휴식 (RELAX)`**: 은은하고 부드러운 바람으로 피로를 풀어주는 릴랙스 기류입니다.
- **`수면 (SLEEP)`**: 수면 중 체온 저하를 막기 위해 돌풍을 최소화하고 극저소음으로 회전합니다.

### 4.4 10대 자연풍 프리셋 그리드 (4x2 배열)
대양의 숨결부터 사막의 고요한 밤까지, 전 세계 10가지 자연 명소의 바람 특성을 담은 감성 카드입니다. 카드를 탭하면 즉시 해당 바람으로 부드럽게 전환됩니다.

### 4.5 3대 물리 슬라이더 및 수동 조작 (Override 모델)
- **자동 동기화**: 프리셋이나 스타일을 변경하면 내부 물리 공식에 의해 3대 슬라이더(`풍속 세기`, `바람 변동성`, `돌풍 빈도`)의 위치와 정량 수치(m/s, 주기)가 자동으로 맞춰집니다.
- **수동 튜닝 (Override)**: 슬라이더 손잡이를 직접 움직이면 즉시 나만의 맞춤형 물리 값으로 고정되며, 슬라이더 상단에 **`[수동 튜닝됨]`** 뱃지가 표시됩니다.
- **원클릭 복원**: 원래 프리셋 기준값으로 되돌아가고 싶을 때는 **`[↺ 기본값 원복]`** 버튼을 탭하거나 다른 프리셋을 누르면 즉시 기본값으로 원상 복구됩니다.

### 4.6 플로팅 Now Playing Bar 및 세션 상세 확장 모달
- **상시 노출 제어**: 화면을 스크롤하거나 다른 탭으로 이동하더라도 화면 최하단에 항상 떠 있어 현재 바람 정보 확인 및 일시정지(`⏸`), 정지(`⏹`) 조작이 가능합니다.
- **스마트 상태 배지 3종**:
  - `⏰ 스케줄 충돌/대기 배지`: 수동 재생 중 예약 스케줄 시간이 도래했을 때 표시되며, 탭하면 스케줄 전환 모달이 열립니다.
  - `⏱️ 하드웨어 타이머 배지`: 하드웨어 세션 타이머가 활성화되었을 때 남은 시간(예: `28m`, `1h15m`)이 실시간 표출되며, 탭하면 즉시 타이머 설정 패널로 이동합니다.
  - `🌿 Auto Comfort 배지`: 실내 쾌적도 지능형 자동 모드에 의해 기동된 세션임을 안내합니다.
- **바람 세션 상세 확장 모달 (`showNowPlayingDetailsModal`)**:
  Now Playing Bar 좌측의 텍스트 영역이나 이퀄라이저 애니메이션을 탭하면 **바람 세션 상세 확장 모달**이 열립니다:

```text
│                                                        │
```

### 4.7 PC/모바일 오프라인 시연 데모 툴바
실제 하드웨어 기기 없이 PC 브라우저나 모바일 로컬 환경에서 웹을 열었을 때 상단에 슬림한 접이식 데모 툴바가 활성화됩니다. '자연 산들바람', '취침 수면풍', '바닷바람 돌풍', 'PIR 차단', '자동종료 래치' 등 5가지 가상 시나리오를 즉시 시연해 볼 수 있습니다.

### 4.8 데스크톱 1024px 영구 사이드바 2열 그리드 레이아웃 (ADR-10)
Smart Nature Wind v0203 웹 UI는 화면 크기에 따라 최적화된 반응형 레이아웃을 제공합니다:
- **데스크톱 화면 (화면 너비 1024px 이상)**:
  - 좌측 네비게이션 사이드바가 영구적으로 펼쳐지는 **2열 CSS 그리드(`var(--snw-sidebar-w) 1fr`)** 가 적용됩니다.
  - 상단 햄버거 메뉴 버튼(`#btn-menu`)과 어두운 배경 오버레이(Dim)가 자동으로 숨겨지며, 메뉴를 클릭하여 페이지를 이동해도 사이드바가 닫히지 않고 상시 고정되어 넓은 화면에서 쾌적하게 작업할 수 있습니다.
- **모바일/태블릿 세로 화면 (화면 너비 1024px 미만)**:
  - 상단 좌측의 햄버거 메뉴(`☰`)를 탭하면 좌측에서 부드럽게 네비게이션 드로어가 슬라이드 인(Slide-in)됩니다.
  - 메뉴 선택 시 또는 어두운 오버레이 영역을 터치하면 드로어가 자동으로 닫혀 모바일 화면 공간을 최대로 확보합니다.

### 4.9 원클릭 실시간 다국어 전환 (KO / EN)
- 화면 우측 상단의 언어 버튼(**`🌐 한국어`** 또는 **`🌐 English`**)을 탭하면, 웹페이지를 새로고침하지 않고도 전체 475개 UI 단어가 **0.01초 만에 100% 실시간으로 전환**됩니다.
- 선택된 언어는 브라우저 로컬 저장소에 저장되어 다음 접속 시에도 그대로 유지됩니다.

| **`MEDITERRANEAN`** | 지중해 연안 바람 | 적당한 난류와 온화한 기류가 어우러져 이국적인 휴양지의 오후를 연상시키는 산뜻한 바람 |

## 6. 스마트 센서 연동 및 3대 자동 종료 (AutoOff)

### 6.1 인체 감지 센서(PIR) 스마트 절전 운전
기기 전면의 고감도 PIR 센서는 사람의 움직임을 지속적으로 감시합니다:
- **자동 대기 절전 (`MOTION_BLOCKED`)**: 사용자가 방을 비우면 설정된 시간(기본 120초) 동안 대기 후 팬을 부드럽게 정지시켜 불필요한 전력 낭비를 차단합니다.
- **소프트 스타트 자동 재개**: 사용자가 다시 방 안으로 들어서면 센서가 즉각 감지하여, 이전 바람 모드로 모터에 무리 없이 서서히 회전 속도를 올리며 자동 복귀합니다.

### 6.2 3대 스마트 자동 종료 (AutoOff) 메커니즘

```text
┌────────────────────────────────────────────────────────┐
│                   3대 스마트 자동 종료 시스템            │
├───────────────────┬───────────────────┬────────────────┤
│ ⏱ 취침 타이머      │ ⏰ 지정 시각 종료  │ 🌡 과냉 방지 온도 │
│ (Timer AutoOff)   │ (Off-Time)        │ (Off-Temp)     │
├───────────────────┼───────────────────┼────────────────┤
│ 지정한 시간(분)이  │ 매일 특정 시각     │ 실내 온도가     │
│ 경과하면 자동으로   │ (예: 새벽 04:00)에 │ 설정값(예: 23℃) │
│ 팬을 정지         │ 1회 안전 종료     │ 이하로 내려가면 │
│                   │                   │ 감기 예방 정지 │
└───────────────────┴───────────────────┴────────────────┘
```

### 6.3 자동 종료 후 안전 래치 (Latch) 보호 규약
> 🔒 **`AUTOOFF_STOPPED` 래치 보호란?**  
> 자동 종료 조건(타이머 완료, 지정 시각 도래, 과냉 방지 온도 도달)이 발생하면 기기는 안전을 위해 **`AUTOOFF_STOPPED`** 래치 상태로 전환됩니다. 이는 새벽에 실내 온도가 22.9℃에서 다시 23.1℃로 미세하게 올라갔다고 해서 잠든 사용자의 머리맡에서 선풍기가 갑자기 켜지는 위험을 원천 차단하기 위함입니다. 래치 상태를 해제하고 다시 가동하려면 대시보드에서 프리셋을 선택하거나 수동 시작 버튼을 탭하면 정상 해제됩니다.

## 7. Comfort DI 기반 실내 쾌적도 지능형 추천 및 자동 모드

### 7.1 일본 기상청 표준 불쾌지수 (DI) 산출식
Smart Nature Wind는 실시간으로 측정되는 건구온도(T)와 상대습도(H)를 바탕으로 일본 기상청(JMA) 표준 공식을 적용하여 불쾌지수를 연산합니다:
$$\text{DI} = 0.81 \times T + 0.01 \times H \times (0.99 \times T - 14.3) + 46.3$$

### 7.2 4단계 쾌적도 분류 및 맞춤 추천 매트릭스

| 레벨 | DI 수치 범위 | 실내 체감 표시 | 추천 프리셋 | 추천 스타일 | 작동 메커니즘 |
|:---:|:---:|:---:|:---:|:---:|---|
| **0** | DI < 68 | **쾌적함** | `FOREST_CANOPY` | `RELAX` | 은은한 공기 순환 및 초저소음 힐링 |
| **1** | 68 ≤ DI < 75 | **약간 덥네요** | `COUNTRY_BREEZE` | `BALANCE` | 기분 좋은 표준 산들바람으로 체온 조절 |
| **2** | 75 ≤ DI < 80 | **끈적이는 날씨** | `OCEAN` | `ACTIVE` | 습도를 날려버리는 상쾌하고 큰 파도 바람 |
| **3** | DI ≥ 80 | **숨이 막혀요** | `MOUNTAIN` | `ACTIVE` | 강력한 계곡풍과 시원한 냉감 극대화 |

### 7.3 사용자 맞춤 프로필 지능형 매칭 원리
만약 사용자가 Wind Studio에서 작곡해 둔 맞춤 프로파일 중 현재 추천 프리셋과 스타일을 포함하는 스텝이 있다면, 기기는 단순 프리셋 대신 **"사용자 작곡 프로파일 재생"**을 우선적으로 추천 카드에 띄워줍니다.

### 7.4 Comfort 자동 모드 (5분 주기 자동 가동 & 안전 가드)
대시보드 추천 카드의 **[자동 모드]** 스위치를 켜면 기기 펌웨어 내부의 백그라운드 타이머가 매 5분(300초)마다 동작하여 최적의 실내 환경을 유지합니다:
- **자동 기동 판단**: 불쾌지수(DI)가 기준치 이상으로 올라가 추천 바람이 산출되면, 사용자 개입 없이도 세션을 자동으로 시작합니다 (`세션 트리거 = Auto Comfort (3)`).
- **자동 정지 판단**: 온도가 내려가 쾌적 구간(DI < 68)에 도달하면 선풍기를 자동으로 멈추어 불필요한 과냉을 방지합니다.
- **안전 가드레일**:
  1. 사용자가 직접 수동 바람을 틀어둔 경우(`MANUAL_ACTIVE`), 사용자의 조작 권한을 최우선하여 자동 모드가 개입하지 않습니다.
  2. 자동 종료 래치(`AUTOOFF_STOPPED`)가 걸려 있거나 취침 안심 타이머가 만료된 경우, 의도치 않게 다시 켜지지 않도록 기동을 억제합니다.
  3. 사용자가 세션 자동 종료 타이머를 설정하거나 수동으로 선풍기를 끄면, 원치 않는 재가동을 막기 위해 Comfort 자동 모드가 자동으로 안전 해제(OFF)됩니다.

## 8. Session FSM 및 재생 라이프사이클 관리

### 8.1 3-State 세션 엔진 (ACTIVE / PAUSED / COMPLETED)
Smart Nature Wind v0203의 모든 바람 재생은 견고한 세션 수명주기 상태 머신(Session FSM)에 의해 관리됩니다:
- **`ACTIVE` (재생 중)**: 프리셋이나 작곡 스케줄이 실제로 팬을 구동하며 동작 중인 상태.
- **`PAUSED` (일시정지)**: 사용자가 Now Playing Bar에서 `⏸` 버튼을 눌러 팬을 잠시 멈춘 상태 (기존 진행 스텝과 재생 시간은 백엔드 메모리에 보존됨).
- **`COMPLETED` (완료/정지)**: 모든 스텝이 끝나거나 `⏹` 버튼으로 세션이 정상 종료된 상태.

### 8.2 지능형 스마트 재개 정책 (Smart Resume)
일시정지 후 다시 `▶` 버튼을 눌렀을 때, 멈춰있던 경과 시간에 따라 사용자 의도를 파악하여 똑똑하게 재개합니다:
- **5분 이내 재개**: **연속 재개** — 방금 멈췄던 그 자리(초 단위)에서 즉시 이어서 재생합니다.
- **5분 ~ 30분 재개**: **스텝 유지 재개** — 진행 중이던 Step의 처음부터 부드럽게 다시 시작합니다.
- **30분 초과 재개**: **처음부터 리셋** — 장시간 자리를 비웠으므로 전체 세션의 제1스텝부터 신선하게 시작합니다.

## 9. Wind Studio — 8스텝 바람 작곡기 (`#/automation/studio`)

`자동화 → Studio` 메뉴에서는 마치 음악을 작곡하듯 최대 8개의 스텝을 연결하여 나만의 맞춤 바람 시나리오를 만들 수 있습니다.

```text
┌────────────────────────────────────────────────────────┐
│  🎼 Wind Studio (바람 작곡기 — 2열 그리드 폼)          │
├────────────────────────────────────────────────────────┤
│  [Step 1] 🌊 OCEAN · ACTIVE (15분)                     │
│           • 세기: 65% / 변동성: 70% / 돌풍: 50%        │
│           • 80px 기류 스파크라인 파형 렌더링           │
│  [Step 2] 🌲 FOREST_CANOPY · RELAX (30분)              │
│           • 세기: 40% / 변동성: 30% / 돌풍: 10%        │
│  [Step 3] ⏸ 모터 휴지 (REST) (5분)                     │
│  [Step 4] 🌙 DESERT_NIGHT · SLEEP (60분)               │
├────────────────────────────────────────────────────────┤
│  반복 횟수: [ 0 ] 회 (0=무한)                          │
├────────────────────────────────────────────────────────┤
│  [🎬 미리보기]                 [ 취소 ]  [ 저장/업데이트 ]│
└────────────────────────────────────────────────────────┘
```

### 9.1 8스텝 작곡기 개요 및 Step 타입 (PRESET / FIXED / REST)
- **`PRESET`**: 10대 자연풍 프리셋과 5대 스타일을 선택하여 풍부한 물리 기류를 재생합니다.
- **`FIXED`**: 특정 풍속(PWM %)을 지정하여 일정한 속도로 팬을 계속 회전시킵니다.
- **`REST`**: 모터 회전을 완전히 멈추고 자연스러운 바람의 휴지기를 가집니다.
- **반응형 2열 그리드 & 80px 스파크라인**: PC와 태블릿에서는 2열 그리드로 쾌적하게 파라미터를 입력할 수 있으며(모바일 1열), 카드 내 스파크라인 차트가 80px로 확대되어 설정한 바람 곡선의 변화를 더욱 명확하게 볼 수 있습니다.

### 9.2 Step별 물리 파라미터 직접 지정 (Override) 및 원클릭 복원
각 스텝마다 기저 프리셋 값 외에 풍속 세기, 변동성, 돌풍 빈도를 0~100% 절대값으로 미세 조정할 수 있습니다. `⚙ 물리 세부 조정 (Override)` 접기/펼치기 영역을 통해 직관적으로 옵션을 켜고 끌 수 있으며, 튜닝된 스텝에는 `[수동 튜닝됨]` 배지가 붙고 **`[↺ 기본값 원복]`** 버튼으로 언제든 프리셋 고유 값으로 되돌릴 수 있습니다.

### 9.3 시나리오 실시간 미리보기 및 하단 분리 액션바
- **좌우 분리 하단 바**: 하단 바 좌측에 **`[🎬 미리보기]`**, 우측에 **`[취소]`** 및 **`[저장/업데이트]`** 버튼이 명확히 분리 배치되어 실수로 저장을 누르는 오작동을 차단합니다.
- **AI 마이크 FAB 자동 은닉**: 스튜디오 화면으로 들어오면 우하단을 가리던 AI 플로팅 마이크 버튼이 자동으로 숨겨져 스텝 작성 및 편집 시야를 100% 확보해 줍니다. 스튜디오를 벗어나면 원래대로 나타납니다.
- **시나리오 미리보기 (`🎬 미리보기`)**: 실제로 몇 시간을 기다릴 필요 없이, 버튼을 누르면 전체 스텝의 기류 파형이 어떻게 흘러가는지 모달 창에서 시뮬레이션으로 압축 감상할 수 있습니다.

## 10. 맞춤 프로파일 및 주간 스케줄러 (`#/automation`)

### 10.1 재생 목록 (Playlist) 관리 (`#/automation/playlist`)
Wind Studio에서 작곡한 바람은 **Profile(프로파일)** 로 저장되어 Playlist 탭에서 카드 목록으로 열람할 수 있습니다. 언제든 원클릭으로 즉시 재생(`▶`)하거나 편집(`✏️`), 삭제(`🗑`)할 수 있으며, 100px 대형 스파크라인 차트를 통해 프로파일의 기류 흐름을 목록에서 바로 직관적으로 확인할 수 있습니다.

### 10.2 프로파일 구조 (steps[] 단일 표준 스키마)
v0203 펌웨어는 레거시 구조를 배제하고 **`steps[]` 단일 배열 표준 규격**으로 동작합니다. 스텝 순서 변경 시 카드 상단의 `[▲]` / `[▼]` 버튼으로 즉시 재배치할 수 있으며, 스텝 실수 삭제 시 화면 하단에 5초간 **실행 취소(Undo Toast)** 알림이 표시되어 안전하게 되살릴 수 있습니다.

### 10.3 주간 스케줄러 설정 (`#/automation/schedule`)
원하는 요일과 시간대를 지정하여 선풍기가 알아서 켜지고 꺼지도록 생활 맞춤 예약이 가능합니다:
- **기상 스케줄**: 평일 아침 07:00 ~ 08:30 활기찬 바닷바람 재생
- **퇴근 스케줄**: 매일 저녁 19:30 ~ 22:00 시골 들판 바람 재생
- **취침 스케줄**: 매일 밤 23:00 ~ 익일 03:00 숲속 수면 바람 재생

### 10.4 Schedule → Profile 참조 단일 규격 (ADR-3) 및 충돌 방지
스케줄은 미리 만들어둔 Profile을 참조(`profileId`)하여 실행됩니다. 만약 사용자가 수동으로 다른 바람을 틀고 있는 도중에 예약 스케줄 시간이 도래하면, Now Playing Bar에 충돌 경고 배지가 뜨며 "스케줄로 전환할지, 현재 바람을 유지할지" 안전하게 선택할 수 있습니다.

## 11. 세션 자동 종료 타이머 (`#/automation/timer`) — 독립 하드웨어 타이머

`자동화 → 타이머` 탭에서는 현재 재생 중인 바람을 일정 시간 뒤 부드럽게 멈추도록 원클릭 예약할 수 있습니다. v0203_013부터는 브라우저 의존성을 완전히 탈피하여 **기기(ESP32) C++ 백엔드 단독으로 완벽하게 제어되는 독립 하드웨어 타이머 규격**이 적용되었습니다.

### 11.1 원터치 빠른 프리셋 (15분 / 30분 / 1시간 / 2시간)
침대에 눕기 전 복잡한 조작 없이 **`[15분]`, `[30분]`, `[1시간]`, `[2시간]`** 버튼 중 하나를 탭하면 즉시 백엔드 하드웨어 타이머가 기동됩니다.

### 11.2 미세 슬라이더 직접 설정 (1분~480분 상한 가드레일)
원하는 정밀한 시간이 있다면 슬라이더를 움직여 1분부터 최대 480분(8시간)까지 자유롭게 설정한 후 **[타이머 시작]**을 누릅니다. 480분(8시간) 초과 입력은 백엔드 가드레일에 의해 안전하게 차단됩니다.

### 11.3 실시간 카운트다운 및 전역 미니플레이어 배지
타이머가 가동되면 남은 시간(`HH:MM:SS`)과 종료 예정 시각(예: "23:45 종료 예정")이 실시간으로 흐르며, 화면 하단 Now Playing Bar에도 `⏱️ 29m` 배지가 함께 표시되어 어디서나 잔여 시간을 한눈에 볼 수 있습니다.

### 11.4 ESP32 독립 하드웨어 타이머 동작 및 Comfort 모드 연계
- **브라우저 종료 후 단독 만료 보장 (T-155 통과)**:  
  타이머가 설정되면 ESP32 내부의 C++ 제어 엔진이 `millis()` 기반으로 자체 카운트다운을 유지합니다. 따라서 **스마트폰 화면을 끄거나 웹 브라우저를 완전히 닫아도 정해진 시간에 기기가 알아서 100% 완전 정지**합니다.
- **Comfort 자동 모드와의 스마트 안전 연계**:  
  취침 타이머가 만료되어 선풍기가 꺼진 후, 5분 뒤 Comfort 자동 모드에 의해 선풍기가 다시 켜져 잠을 깨우는 현상을 막기 위해, **타이머 만료 시점(및 수동 설정 시점)에 Comfort 자동 모드가 자동으로 안전 해제(`setAutoComfort(false)`)**됩니다.

# 파트 IV. 지능형 AI 및 전문 시각화 (AI & Analytics)

## 12. Gemini AI 대화형 비서 & Live 실시간 음성

Smart Nature Wind v0203은 Google의 최신 생성형 인공지능(Gemini)과 결합하여, 단순한 버튼 터치를 넘어 **자연어 텍스트와 실시간 저지연 음성(Gemini Live)**으로 선풍기를 사람처럼 대화하며 다룰 수 있는 차세대 AI 제어 시스템을 탑재했습니다.

### 12.1 2가지 편리한 진입 경로 (AI Studio & 전역 플로팅 마이크 FAB)
1. **풀스크린 AI Studio (`#/ai`)**: 대형 반응형 오디오 오브(Audio Orb), 음성 설정, 금일 사용 비용 대시보드, 상세 대화 로그를 총망라한 종합 AI 작업 공간입니다.
2. **전역 플로팅 마이크 버튼 (Floating Mic FAB)**: 화면 어느 페이지에서나 우측 하단의 원형 마이크 아이콘을 탭하면 즉시 슬라이드업 바텀시트가 열립니다. Now Playing Bar가 가동되면 메뉴 가림을 방지하기 위해 버튼 위치가 자동으로 상단(`bottom: 124px`)으로 부상합니다.

### 12.2 2가지 대화 모드 (REST 텍스트 vs Gemini Live 실시간 음성)
AI Studio 상단의 모던한 세그먼트 컨트롤 버튼을 통해 언제든 원하는 모드로 즉시 전환할 수 있습니다:
- **REST 텍스트 대화 모드**: 가벼운 데이터 소모로 정확한 2-turn 제어 명령을 실행하고 텍스트 및 TTS 음성 답변을 받습니다.
  * **2x2 퀵 예시 칩**: `[🌊 바다 바람]`, `[⏱ 30분 후 끄기]`, `[📅 스케줄 복귀]`, `[🌤 날씨 추천]` 등 4가지 대표 명령 칩이 2열 그리드로 정렬되어 있어 한 번의 터치로 손쉽게 명령을 내릴 수 있습니다.
  * **스마트 자동 신축 입력창 (Auto-height Textarea)**: 처음에는 1줄 높이로 콤팩트하게 유지되다가, 긴 문장을 타이핑하면 내용량에 맞춰 최대 120px까지 부드럽게 창 높이가 늘어나 긴 지시문도 시원하게 확인하며 입력할 수 있습니다 (`Shift+Enter`로 줄바꿈, `Enter`로 즉시 전송).
- **Gemini Live 실시간 양방향 음성 모드**: 스마트폰 마이크(AudioWorklet 16kHz PCM16 스트림)와 Google Gemini Live 서버 간의 WebSocket을 직결하여, 800ms 이하의 초저지연으로 실제 사람과 통화하듯 자연스럽게 대화하며 기기를 제어합니다.
- **비용 배지 말줄임 보호**: 상단 비용 모니터링 배지가 좁은 모바일 화면에서도 2줄로 깨지지 않고 깔끔하게 한 줄(`...` 말줄임)로 표시되어 UI 레이아웃이 항상 단정하게 유지됩니다.

### 12.3 차세대 실시간 음성 인터랙션 (Aoede 보이스, Audio Orb, 끼어들기)
- **Aoede 공식 보이스**: 가장 자연스럽고 지적인 한국어/영어 발음을 구사하는 Google 공식 프리셋 음성을 기본 지원합니다.
- **역동적인 Audio Orb**: 사용자의 음성 입력 음량과 AI의 음성 출력에 실시간 반응하여 맥동하는 그래픽 구체입니다.
- **사용자 끼어들기 (Barge-in)**: AI가 말하고 있는 도중이라도 사용자가 "잠깐만" 하고 말을 끊으면 AI 음성 출력을 즉시 Flush(소거)하고 사용자의 새 명령을 우선 청취합니다.

3. **일일 비용 한도 ($0.50 USD) 및 NVS 영구 누적**: 하루 사용 금액이 $0.50(약 700원)에 도달하면 신규 음성 접속이 차단(403)되며 안전하게 무료 텍스트 모드로 전환됩니다.

1. **API 키 발급**: Google AI Studio(aistudio.google.com)에서 무료 Gemini API Key를 발급받습니다.

## 13. 실시간 물리 시뮬레이션 차트 (`#/chart`)

기기가 인위적인 회전이 아닌, 실제 지구의 대기 물리 방정식으로 기류를 만들고 있음을 눈으로 검증하는 전문 파형 분석 도구입니다.

```text
  풍속(m/s)
    ▲
7.0 │               ╭─╮           ╭──╮       돌풍(Gust) 피크 구간
5.0 │      ╭─╮     │ │   ╭─╮     │  │
3.0 │  ╭──╯ ╰──╮  │ ╰──╯ ╰─╮   │  ╰──╮   기저 자연풍 곡선
1.0 └──┴────────┴─┴──────────┴───┴───────► 시간(초)
       0s       30s       60s       90s      120s
```

### 13.1 실측 풍속 vs 예상 풍속 파형 오버레이
- **실측 파형**: 고속 WebSocket을 통해 100ms 주기로 팬에 인가되는 실제 물리 풍속 곡선입니다.
- **예상 파형 (점선 오버레이)**: 현재 프리셋과 스타일 공식에 의해 앞으로 전개될 이론적 파형을 점선으로 겹쳐 표시하여 시뮬레이션 정확도를 대조할 수 있습니다.

### 13.2 120포인트 고속 물리 요소 분해 관측
차트 상에서 기저 풍속(Base), 난류 변동폭(Turbulence), 돌풍 피크(Gust Peak), 열기포 상승(Thermal Bubble) 구간을 시각적으로 구분하여 감상할 수 있습니다.

### 13.3 시간 범위 전환 및 CSV 내보내기
5초, 30초, 120초 등 3단계 줌 레벨을 지원하며, **[CSV 내보내기]** 버튼을 통해 연구 및 분석용 원본 데이터를 파일로 저장할 수 있습니다.

## 14. 모니터링 및 세션 히스토리 타임라인 (`#/monitor`)

### 14.1 실시간 탭 (20-bar Canvas EQ & 환경 지표)
- **20-bar Canvas EQ**: 현재 풍속의 생동감을 20개의 수직 바로 렌더링하는 사운드/기류 이퀄라이저입니다.
- **환경 지표**: 실시간 온도, 습도, PIR 인체 감지 여부, 현재 구동 모드를 한눈에 브리핑합니다.

### 14.2 히스토리 탭 (64-event 2단 타임라인 & 반응형 가동 요약)
기존 "회고" 탭이 더욱 직관적인 **`🎬 히스토리`** 탭으로 개편되어 과거의 기기 운전 이력을 한눈에 추적할 수 있습니다:
- **반응형 가동 요약 (Summary Grid)**: 최근 1시간, 24시간 또는 7일간의 총 가동 시간, 평균 풍속, 평균 실내 온도, 재실 감지율을 auto-fit 그리드로 보여주어 모바일 좁은 화면에서도 글자 깨짐 없이 깔끔하게 표시됩니다.
- **2단 지그재그(Zigzag) 타임라인**: 
  * 세션 시작(`▶`), 정지(`⏹`), 수동 조작(`✋`), 자동 종료(`🌙`), 일시정지(`⏸`) 등 주요 라이프사이클 이벤트 64개를 시간순으로 시각화합니다.
  * 이벤트 간격이 5% 이내로 인접하여 마커가 겹칠 경우, 위/아래 2단 레인으로 엇갈려 자동 배치되어 모든 이벤트를 가림 없이 명확히 확인할 수 있습니다.
  * 양 끝(0%, 100%) 마커가 잘리지 않도록 좌우 16px 안전 여백이 적용되었으며, 하단에 시작 및 현재 시간 라벨이 표시됩니다.
  * 마커에 마우스를 올리거나 탭하면 툴팁으로 발생 시각과 라벨이 나타납니다.
- **스마트 시간축 표기 및 이벤트 목록**: 최근 30개의 이벤트 목록에서 1시간/24시간 조회 시에는 `HH:mm`, 7일 조회 시에는 `MM/DD HH:mm` 포맷으로 날짜와 시간이 자동 최적화 표기됩니다.

### 14.3 메모리 2단계 이중화 보관 정책 (Warm PSRAM / Cold LittleFS)
- **Warm 데이터 (PSRAM)**: 최근 1시간 분량의 고해상도 1초 원본 데이터를 메모리에 유지합니다.
- **Cold 데이터 (LittleFS 플래시)**: 1시간 단위로 압축 배치하여 플래시에 안전하게 누적 기록합니다.

# 파트 V. 시스템 관리 및 문제 해결 (System & Support)

## 15. 시스템 및 네트워크 고급 설정 (`#/settings` / `#/network`)

### 15.1 시스템 하드웨어 및 안전 듀티 설정
`설정 → 하드웨어` 탭에서는 팬 모터의 수명 보호와 안전 운전을 위한 전압 경계를 지정합니다:
- **`최소 기동 듀티 (Start Percent Min)`**: 모터 날개가 멈칫거리지 않고 부드럽게 돌기 시작하는 최소 전압값 (기본 18%).
- **`안심 상한 듀티 (Comfort Percent Max)`**: 일상 자연풍 모드에서 허용되는 상한 풍속 (기본 65%).
- **`하드웨어 최대 한계치 (Hard % Max)`**: 초강풍 수동 모드 시 도달할 수 있는 절대적 물리 한계선 (기본 90%).

### 15.2 보안 API 키 및 비밀번호 관리
비인가자의 접근을 차단하기 위해 관리자 보안 API Key를 등록할 수 있습니다. 비밀번호가 설정되면 웹 브라우저나 외부 REST 요청 시 올바른 키를 제출해야만 제어가 허용됩니다.

### 15.3 골든 룰: 설정 저장(Save)과 무중단 재적용(Reload)
- **RAM 즉시 반영**: 슬라이더 조작이나 임시 제어는 플래시 수명(쓰기 횟수) 보호를 위해 기기 RAM에서 먼저 즉각 반응합니다.
- **[설정 저장] 버튼**: 수정한 설정을 플래시 파일시스템에 영구 저장하려면 반드시 상단 **[설정 저장]** 버튼을 눌러야 전원을 껐다 켜도 유지됩니다.
- **무중단 재적용 (Zero-Reboot Reload)**: 타임존이나 NTP 주기를 변경하더라도 기기를 재부팅할 필요 없이 백그라운드에서 즉각 새 설정이 동기화됩니다.

### 15.4 네트워크 및 시간(NTP) 설정
`네트워크` 탭에서는 SoftAP 모드, 공유기(STA) 연결, 주변 Wi-Fi 스캔, 인터넷 표준 시간(SNTP) 동기화 주기 및 한국 표준시(KST, UTC+9) 타임존을 설정합니다.

### 15.5 오프라인 로컬 가상 환경 아키텍처
기기가 없는 환경에서도 개발 및 시연이 가능하도록 설계된 2분할 스크립트 아키텍처입니다:
- `998.offline_data_0203.js`: 10개 환경설정 JSON의 기본 캐시 데이터를 완벽 탑재.
- `998.offline_0203.js`: 웹 브라우저 내에서 가상 센서와 REST/WebSocket을 에뮬레이트.
- 실제 펌웨어 빌드 시에는 플래시 용량 절약을 위해 이 오프라인 모듈 2종이 100% 자동 제외됩니다.

### Q1. 선풍기 날개가 회전하지 않아요.
- **원인 1 (세션 정지 상태)**: 대시보드에서 자연풍 프리셋 카드를 탭하거나 Comfort 추천 카드의 **[▶ 지금 재생]** 버튼을 눌러보세요.
- **원인 2 (자동 종료 래치 상태)**: 새벽 시간 타이머나 과냉 방지로 종료된 경우 `AUTOOFF_STOPPED` 래치 상태일 수 있습니다. 대시보드의 바람 프리셋 카드를 선택하면 즉시 래치가 풀리고 가동됩니다.
- **원인 3 (인체 미감지 절전 대기)**: 사람이 자리를 비워 절전 모드(`MOTION_BLOCKED`)에 들어갔을 수 있습니다. 센서 앞에서 손을 흔들면 즉시 부드럽게 재개됩니다.
- **원인 4 (모터 최저 기동 전압 부족)**: `#/settings` (하드웨어 탭)에서 `최소 기동 듀티(Start Percent Min)`를 18%에서 22% 정도로 올려보세요.

### Q2. 스마트폰에서 `192.168.4.1` 웹 화면이 뜨지 않아요.
- **점검**: 스마트폰 Wi-Fi 설정에서 **`NatureWind`**에 정상 연결되어 있는지 확인하세요. LTE/5G 모바일 데이터가 켜져 있으면 로컬 접속을 방해할 수 있으므로, 잠시 **모바일 데이터를 끄고** 접속해 보세요.

### Q3. 방에 사람이 가만히 누워있는데 선풍기가 꺼져요.
- **점검**: 침대에 누워 미세한 움직임이 없는 환경이라면 `#/settings`에서 모션 감지 유지 시간(`holdSec`)을 기본 120초에서 300초(5분) 이상으로 늘려주세요.

### Q4. 예약한 스케줄 시각에 선풍기가 켜지지 않아요.
- **점검 1**: 기기가 가정용 Wi-Fi에 연결되어 인터넷 표준 시각(NTP)을 받아왔는지 `#/info` 페이지에서 확인하세요. 기기 내부 시계가 맞춰져 있어야 스케줄이 작동합니다.
- **점검 2**: 해당 스케줄이 참조하고 있는 바람 Profile이 Playlist에서 삭제되지 않았는지 확인하세요.

### Q5. 세션을 일시정지했다가 켰는데 처음부터 다시 시작해요.
- **정상 동작입니다**: Smart Resume 정책에 따라 일시정지 시간이 30분을 초과하면 안전을 위해 제1스텝부터 신규 세션으로 리셋됩니다. 5분 이내 재개는 1초의 오차도 없이 연속 재생됩니다.
