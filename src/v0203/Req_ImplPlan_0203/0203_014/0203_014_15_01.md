### 0.2 핵심 아키텍처 전략

1. **즉시 Clean Break**: 하위 호환(`[[deprecated]]`, 레거시 `autoOff`/`motion`, `MOTION_BLOCKED=4`, `LEGACY_ALIAS`)을 남기지 않고 Stage 1~5에서 즉시 제거·치환한다.
2. **백엔드 선행 원칙**: 백엔드(Stage 1~3)를 먼저 구현·빌드·실기 부팅 확인한 뒤 프론트엔드(Stage 4~5)를 진행하여 Mock 의존성을 제거한다. *(단, Stage 3과 Stage 4는 상호 의존성이 없으므로 필요 시 병렬 진행 가능)*
3. **스테이지 게이트(Stage Gate) 방식**: 각 Stage는 **진입 조건(Entry Gate) → 구현 → 이탈 조건(Exit Gate) → 스테이지 커밋** 순으로 진행하며, 게이트 미통과 시 다음 Stage로 넘어가지 않는다.

### 0.5 실행 환경 주의사항 (Windows / PlatformIO)

- **`pio` 실행**: PlatformIO CLI(`%USERPROFILE%\.platformio\penv\Scripts\pio.exe`)는 워크스페이스 외부 경로에 설치되어 있으므로, `pio run` / `--target upload` / `--target uploadfs` 명령은 반드시 **샌드박스 밖(`BypassSandbox: true`)**에서 실행합니다.
- **PowerShell `InitializeDefaultDrives` 경고**: 샌드박스 세션 시작 시 출력되는 `'FileSystem' 공급자에서 InitializeDefaultDrives 작업을 수행하지 못했습니다.` 메시지는 접근 제한 드라이브 열거로 인한 무해한 경고이며 명령 실행 결과에는 영향을 주지 않습니다.
