# 🎯 오프라인 AI 어시스턴트 원인 분석 및 구현 설계

> **대상 버전:** v0203 (`0203_014`)  
> **핵심 요약:** 오프라인 모드에서 `A.gemini`가 API 키 미설정 시 즉시 early-return하여 키워드 폴백이 실행되지 않는 문제와 `set_timer` 액션 미작동 문제를 해결하기 위한 구현 설계 문서입니다.

## 1. 문제 요약 및 실행 흐름

```text
사용자 입력 ("바다 바람 켜줘")

```

## 2. 원인 분석 (실제 코드 기준)

| 구분 | 위치 | 현상 및 원인 |
|---|---|---|
| **원인 A (주원인)** | `998.offline_0203.js` L609~ | `A.gemini`가 `apiKey`가 비어 있을 때 즉시 경고(`actions: []`)를 반환하여, 하단의 키워드 폴백에 도달하지 못함 |
| **원인 B** | `998.offline_0203.js` L704~717 | `A.executeAiAction`의 `set_timer` 분기가 존재하지 않는 `SNW.TimerManager.start()`를 호출하여 타이머 액션이 동작하지 않음 |
| **원인 C (방어)** | `040.api.js` L61~ | `OFFLINE_ROUTES`에 `/ai/gemini`, `/ai/execute-action`이 없어, `ensureApi()` 실패 시 거짓 성공(`{result:'ok', offline:true}`)을 반환함 |

> 참고: `998.offline_0203.js` L722~ 이후의 `A.gemini`는 `/* ... */` 주석 블록 내부에 비활성화되어 있습니다.

## 3. 구현 설계 (옵션 2 + 옵션 3)

### 3.1 설계 원칙 및 영향도

- **온라인(실기기) 무영향:** `998.offline_0203.js`는 `pio_gzip_0203.py` 빌드 시 배포에서 자동 제외됩니다. `040.api.js`의 `OFFLINE_ROUTES`는 오프라인/폴백 경로에서만 동작합니다.
- **UI 자동 동기화:** `A.startSession` / `A.stopSession` / `A.overrideFixed`를 통해 `runtime.control.session`이 갱신되므로 대시보드 Now Playing 카드와 `#now-playing-bar`가 즉시 반영됩니다.
- **타이머 호출 보정:** `998.offline_0203.js`에는 `A.setControlTimer`가 없으므로, `040.api.js` L267의 `SNW.Api.setControlTimer(minutes)`를 호출하도록 설계합니다.

### 3.2 수정 대상 1 — `998.offline_0203.js`

#### ① `_offlineKeywordFallback(msg)` 신설

API 키가 없거나 Gemini REST 호출이 실패했을 때 공통으로 사용하는 키워드 기반 제어 폴백입니다.

```js
async function _offlineKeywordFallback(msg) {
    const actions = [];
    let replyText = '';

    if (msg.includes('바다') || msg.includes('오션')) {
        await A.startSession({ type: 'PRESET', payload: { presetCode: 'OCEAN', styleCode: 'BALANCE' } });
        actions.push({ name: 'start_preset', args: { presetCode: 'OCEAN' }, result: 'ok' });
        replyText = '바다 바람을 틀어드렸습니다.';
    } else if (msg.includes('숲') || msg.includes('산들')) {
        await A.startSession({ type: 'PRESET', payload: { presetCode: 'FOREST_CANOPY', styleCode: 'BALANCE' } });
        actions.push({ name: 'start_preset', args: { presetCode: 'FOREST_CANOPY' }, result: 'ok' });
        replyText = '숲속 바람을 틀어드렸습니다.';
    } else if (msg.includes('산') || msg.includes('계곡')) {
        await A.startSession({ type: 'PRESET', payload: { presetCode: 'MOUNTAIN', styleCode: 'BALANCE' } });
        actions.push({ name: 'start_preset', args: { presetCode: 'MOUNTAIN' }, result: 'ok' });
        replyText = '산바람을 틀어드렸습니다.';
    } else if (msg.includes('꺼') || msg.includes('정지') || msg.includes('중지') || msg.includes('off')) {
        await A.stopSession();
        actions.push({ name: 'stop_session', args: {}, result: 'ok' });
        replyText = '바람을 껐습니다.';
    } else if (msg.includes('분') || msg.includes('타이머') || msg.includes('시간')) {
        const m = parseInt((msg.match(/(\d+)\s*분/) || [])[1] || 30, 10);
        if (SNW.Api && typeof SNW.Api.setControlTimer === 'function') {
            await SNW.Api.setControlTimer(m);
        }
        actions.push({ name: 'set_timer', args: { minutes: m }, result: 'ok' });
        replyText = `${m}분 후 자동으로 꺼드릴게요.`;
    } else if (msg.includes('스케줄') || msg.includes('자동')) {
        runtime.control.manualOverrideSchedule = false;
        actions.push({ name: 'release_manual_to_schedule', args: {}, result: 'ok' });
        replyText = '스케줄 자동 실행 모드로 전환했습니다.';
    } else {
        replyText = `"${msg}" 요청을 이해했습니다. (오프라인 사용 가능: 바다/숲/산/끄기/N분 타이머/스케줄)`;
    }

    return {
        ok: true,
        text: replyText,
        _speechHint: replyText,
        actions,
        session: runtime.control.session
    };
}
```

#### ② `A.gemini(body)` 재구조화 (L609~)

```js
A.gemini = async (body) => {
    const msg = (body && body.message || '').trim();
    const systemCache = cache.system || {};
    const apiKey = systemCache.security?.geminiApiKey || localStorage.getItem('snw.geminiKey') || '';

    // API 키 없음 → 즉시 키워드 폴백
    if (!apiKey) {
        return _offlineKeywordFallback(msg);
    }

    // API 키 있음 → Gemini REST 호출 + 실패/미매칭 시 폴백
    try {
        // 기존 fetch + [ACTION:...] 파싱 로직 유지
        // [ACTION:...] 미포함 시 _offlineKeywordFallback(msg)로 보완
    } catch (e) {
        console.error('[AI] Gemini 호출 실패 → 폴백:', e);
        return _offlineKeywordFallback(msg);
    }
};
```

#### ③ `A.executeAiAction(name, args)` 보완 (L704~717)

- `start_playlist`, `release_manual_to_schedule` 분기 추가
- `set_timer` 분기를 `SNW.TimerManager.start` → `SNW.Api.setControlTimer(args?.minutes || 30)`로 교체

### 3.3 수정 대상 2 — `040.api.js` (`OFFLINE_ROUTES` 방어)

`ensureApi()` 미적용 시 거짓 성공 대신 명시적 오류를 반환하도록 `OFFLINE_ROUTES`(L61~)에 아래 라우트를 추가합니다.

```js
{ re: /\/ai\/gemini$/i, method: 'POST',
  handle: () => ({
      ok: false,
      error: 'offline',
      text: '⚠️ AI 오프라인 핸들러가 초기화되지 않았습니다. 페이지를 새로고침하세요.',
      actions: []
  }) },
{ re: /\/ai\/execute-action$/i, method: 'POST',
  handle: () => ({ ok: false, error: 'offline', actions: [] }) },
```

## 4. 검증 계획

### 4.1 기능 테스트 매트릭스

| 시나리오 | 기대 결과 |
|---|---|
| API 키 없음 + `"바다 바람 켜줘"` | `OCEAN` 프리셋 실행 + `"바다 바람을 틀어드렸습니다."` 응답 + Now Playing Bar 표시 |
| API 키 없음 + `"30분 후 꺼줘"` | `SNW.Api.setControlTimer(30)` 호출 + `"30분 후 자동으로 꺼드릴게요."` 응답 |
| API 키 있음 + 정상 응답 | Gemini REST 응답 및 `[ACTION:...]` 정상 실행 |
| API 키 있음 + 네트워크/API 오류 | `_offlineKeywordFallback`으로 자동 폴백 |
| `ensureApi()` 미적용 상태 호출 | `{ ok: false, error: 'offline' }` 명시적 오류 반환 |
