# `A00_Main_0203.h` 상세 Spec

## ⚙️ 시스템 스펙 요약: A00_Main_0203.h



스마트 네이처 윈드 시스템의 메인 엔트리포인트 인터페이스로, 초기화 및 루프 실행 함수와 전역 인스턴스 접근을 위한 선언 전용 헤더입니다.

### 💾 구조체 및 타입 정의 (Structs & Types)
*   **`AsyncWebServer`**: ESP32 웹 서버 객체 (전역 인스턴스)
*   **`CL_P10_PWM`**: PWM 제어 관리자 클래스 (전역 인스턴스)
*   **`CL_A30_LED`**: LED 제어 관리자 클래스 (전역 인스턴스 포인터)
*   **`CL_CT10_ControlManager`**: CT10 컨트롤러 접근자 반환형


### 🛠️ 함수 정의 및 시그니처 (Functions & Signatures)

*   **`A00_getControl()`**: `CL_CT10_ControlManager&` 참조를 반환하여 CT10 컨트롤러에 접근합니다. (Reference 타입 사용으로 정적 초기화 순서 문제 회피)
*   **`A00_init()`**: 시스템 초기화를 수행합니다. (구현은 A00_Main_0203.cpp)
*   **`A00_run()`**: 메인 루프 로직을 실행합니다. (구현은 A00_Main_0203.cpp)


### 📚 포함 헤더 및 외부 의존성 (Includes & Dependencies)

*   **외부 의존성**: `Arduino.h`, `ESPAsyncWebServer.h` 및 모듈 내 다른 헤더 (`A20_Const_0203.h`, `CT10_Ctl_0203.h`, `P10_PWM_ctrl_0203.h`, `A30_LED_0203.h`) 를 포함합니다.
*   **공유 상태 (Extern)**: 웹 서버, PWM 컨트롤러, LED 컨트롤러 전역 인스턴스가 `.cpp` 파일에서 단 한 번 정의되도록 extern 선언되어 있습니다.
*   **설계 원칙**: 다중 TU 안전을 위해 구현은 분리하고, 정적 초기화 순서 문제(static init order fiasco)를 방지하기 위해 참조 타입 접근자를 사용합니다.
