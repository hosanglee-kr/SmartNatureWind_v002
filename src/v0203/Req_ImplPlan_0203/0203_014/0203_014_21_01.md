## 2. 세부 보완 설계

### 2.1 [FE] base 선택 모달 노출 정책 개선 (`200.page.dashboard.js`)

- **대상:** [200.page.dashboard.js](file:///d:/95.2540_PJT/SmartNatureWind_v002/src/v0203/data_v0203_src/html_v0203/js/app/200.page.dashboard.js#L424-L434), `_showAutoSelectDialog` ([L575-L670](file:///d:/95.2540_PJT/SmartNatureWind_v002/src/v0203/data_v0203_src/html_v0203/js/app/200.page.dashboard.js#L575-L670))
- **설계:**
  1. `key === 'autoSelect'` 클릭 시 `snw.lastAutoSelectBase`가 있더라도 모달을 건너뛰지 않고 `_showAutoSelectDialog(false, savedBase)`를 호출합니다.
  2. 모달 내부에서 `savedBase`의 `baseType` (`PRESET` / `PLAYLIST`), `presetCode` 또는 `profileId`를 초기 선택(pre-select)해 두어, 기존 선택을 유지할 때는 바로 `시작` 버튼 1회 클릭으로 실행할 수 있게 합니다.
  3. 선택 완료 시 `localStorage.setItem('snw.lastAutoSelectBase', JSON.stringify(base))` 갱신은 유지합니다.

### 2.2 [FE] Now Playing 제목 표기 통일 (`999a.nowplaying.js`, `200.page.dashboard.js`)

- **대상:** [999a.nowplaying.js](file:///d:/95.2540_PJT/SmartNatureWind_v002/src/v0203/data_v0203_src/html_v0203/js/app/999a.nowplaying.js#L211-L218), [200.page.dashboard.js](file:///d:/95.2540_PJT/SmartNatureWind_v002/src/v0203/data_v0203_src/html_v0203/js/app/200.page.dashboard.js#L844-L850)
- **설계:**
  - 두 컴포넌트 모두 동일한 접미사(모바일 바 폭을 고려한 `(맞춤Auto)` 또는 원문 기준 `(취향 맞춤 Auto)`)를 i18n 키(`session.autoSelectTag` 등)로 통일해 언어 전환(`ko`/`en`) 시에도 일관되게 표시합니다.
  - `ko`/`en` 키 추가 시 `check_i18n.py --strict` 100% 대칭을 유지합니다.

### 2.3 [BE] `PLAYLIST` base 실행 시 프로필 기본 규칙 보존 (`CT10_Ctl_Ctl_0203.cpp`)

> [!IMPORTANT]
> C++ 백엔드 수정은 `AGENTS.md` 원칙 1에 따라 **사용자 승인 후** 반영합니다.

- **대상:** [CT10_Ctl_Ctl_0203.cpp](file:///d:/95.2540_PJT/SmartNatureWind_v002/src/v0203/CT10_Ctl_Ctl_0203.cpp#L548-L568)
- **현상:** `baseType == "PLAYLIST"`일 때 `startUserProfileByNo(pid)` 직후 무조건 `self.initRuleFromPayload(v_rule)`을 호출하므로, `payload.rule`이 없는 경우 기본 초기화된 `v_rule`이 프로필 규칙을 덮어쓸 수 있습니다.
- **설계:**
  - `const bool hasExplicitRule = p_payloadDoc["rule"].is<JsonObjectConst>();` 플래그를 두고, `PLAYLIST` 분기에서는 `if (hasExplicitRule) { self.initRuleFromPayload(v_rule); }`로 조건부 적용합니다.
  - `PRESET` 분기에서는 기존처럼 `hasExplicitRule` 여부와 무관하게 `v_rule`(명시 규칙 또는 전역 기본 규칙)을 적용합니다.

### 2.4 [Offline] 오프라인 어댑터 `AUTO_SELECT` 스타일 시뮬레이션 보완 (`998.offline_0203.js`)

- **대상:** [998.offline_0203.js](file:///d:/95.2540_PJT/SmartNatureWind_v002/src/v0203/data_v0203_src/html_v0203/js/998.offline_0203.js#L393-L413)
- **설계:**
  - `payload.styleCode`가 전달된 경우(예: 수면 모드 `SLEEP`) 이를 우선 반영합니다.
  - 미전달 시 현재 가상 센서값(`runtime.sensor.tempC`, `di`)에 따라 스타일(`SLEEP` / `BALANCE` / `VITAL`)을 선택해 `runtime.sim.styleCode` 및 `resolvePreset(pc, sc)` 결과를 반영합니다.
