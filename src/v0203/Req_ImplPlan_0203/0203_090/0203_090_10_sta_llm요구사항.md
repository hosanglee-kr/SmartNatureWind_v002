## 1. 개요

### 1.1 목적
v0203 표준 = **브라우저 음성** (Stage 8.3A 완료). Stage 9는 **프리미엄 모델**을 위한 **스탠드얼론 음성 PoC**로, 하드웨어 추가 후 진정한 음성 제어 기기를 검증한다.

### 1.2 배경
- **Stage 8.3A**: 브라우저 Live API (음성 대화, Barge-in) 완료
- **한계**: 스마트폰 필요 (거실/침실 상시 사용 불편)
- **Stage 9 목표**: 스마트폰 없이 "헤이 윈드"만으로 제어

### 1.3 범위

| 포함 | 제외 |
|---|---|
| I2S 마이크/스피커 하드웨어 | v0203 펌웨어 통합 (PoC 분리) |
| ESP-SR 웨이크워드 감지 | Gemini Live 오디오 중계 |
| 5초 WAV 녹음 + 인코딩 | 스트리밍 오디오 (Phase 2+) |
| Gemini API audio inline_data | 멀티모달 (이미지/비디오) |
| TTS 재생 (Google Cloud or Gemini TTS) | 오프라인 STT |
| GO/NO-GO 판정 | 양산 최적화 |

**Stage 9는 PoC — 상품화는 Stage 10+ (프리미엄 모델)**

## 2. 제약사항 ★필수 검토

### 2.1 하드웨어 제약

| # | 제약 | 영향 | 완화 |
|---|---|---|---|
| H1 | **PSRAM 8MB 필수** | WAV 버퍼 160KB + 모델 로드 200KB | N16R8 확정 (있음) |
| H2 | **ESP32-S3 전용** | ESP32-D0WD 불가 (PSRAM 없음) | 하드웨어 확정 |
| H3 | **I2S 핀 할당** | GPIO 4/5/6 마이크, GPIO 15/16/17 앰프 | 다른 핀 재배치 필요 시 회로 수정 |
| H4 | **3W 스피커 부하** | 5V 500mA 순간 피크 | 별도 5V 전원 분리 |
| H5 | **ESP-SR 모델 500KB** | Flash 파티션 축소 (LittleFS -500KB) | Gzip 번들 재조정 필요 |
| H6 | **INMP441 3.3V 전용** | 5V 직결 시 파손 | LDO 필수 |

### 2.2 소프트웨어 제약

| # | 제약 | 영향 | 완화 |
|---|---|---|---|
| S1 | **Heap 150KB+ 필요** | I2S DMA + WAV + Base64 + HTTPS | PSRAM 강제 할당 |
| S2 | **CPU 대기 시 5~10%** | 웨이크워드 상시 감지 | 딥슬립 옵션 (배터리) |
| S3 | **웨이크워드 지연 < 500ms** | ESP-SR 실시간 처리 | 전용 코어 할당 |
| S4 | **Gemini audio API 지원 불확실** | Gemini 2.0 Flash inline_data | Google Cloud STT 대안 |
| S5 | **TLS 핸드셰이크 2~3초** | 매 요청마다 재연결 | 세션 재사용 (지연 -1.5s) |
| S6 | **ESP-SR 한국어 미지원** | "Hi Wind" 영어만 | 커스텀 모델 학습 (Phase 9B) |

### 2.3 UX 제약

| # | 제약 | 영향 | 완화 |
|---|---|---|---|
| U1 | **왕복 지연 4초 한계** | 사용자 체감 느림 | 로컬 피드백 (LED + 비프) |
| U2 | **AEC 미지원 (ESP32)** | 스피커 출력 → 마이크 재유입 | 스피커 재생 중 마이크 mute |
| U3 | **웨이크워드 오탐** | 일상 대화 중 감지 | 커스텀 모델 + 2단어 |
| U4 | **재생 중 말 자르기 불가** | 스탠드얼론은 반이중 | 버튼 트리거 옵션 |

### 2.4 정책 제약

| # | 제약 | 영향 |

## 3. 기능 요구사항

### 3.1 [F-S9-WAKE] 웨이크워드 감지

#### F-S9-WAKE-01: 웨이크워드 인식
- **설명**: "Hi Wind" 또는 커스텀 워드 감지
- **엔진**: ESP-SR (WakeNet9)
- **모델**: `wn9_hilexin` (프리셋) 또는 커스텀
- **우선순위**: 🔴 필수
- **수용 기준**:
  - 감지율 > 90% (조용한 실내, 1m 거리)
  - 오탐 < 5% (일상 대화 1시간)
  - 감지 지연 < 500ms

#### F-S9-WAKE-02: 감지 후 피드백
- **설명**: LED + 비프로 "듣고 있어요" 신호
- **LED**: NeoPixel 녹색 점등 (300ms)
- **비프**: 1kHz 100ms (스피커)
- **우선순위**: 🔴 필수
- **수용 기준**: 사용자가 감지 여부 인지 가능

#### F-S9-WAKE-03: 옵션 (커스텀 워드)
- **설명**: "헤이 윈드" 한국어 워드 (Phase 9B)
- **엔진**: ESP-SR 커스텀 모델 (ESP-SR Studio)
- **우선순위**: 🟡 선택
- **수용 기준**: 한국어 > 85%

---

### 3.2 [F-S9-REC] 녹음

#### F-S9-REC-01: 5초 WAV 녹음
- **설명**: I2S 마이크로 5초 PCM 캡처
- **포맷**: 16kHz, 16-bit LE, Mono
- **버퍼**: PSRAM 160KB (5초 × 32000 B/s)
- **우선순위**: 🔴 필수
- **수용 기준**: 녹음 손실 0%, 클리핑 < 1%

#### F-S9-REC-02: WAV 인코딩
- **설명**: PCM → WAV (44-byte header + data)
- **우선순위**: 🔴 필수
- **수용 기준**: 표준 WAV 플레이어 재생 가능

#### F-S9-REC-03: 무음 감지 (VAD)
- **설명**: 500ms 무음 시 조기 종료
- **우선순위**: 🟡 선택
- **수용 기준**: 지연 -2초

---

### 3.3 [F-S9-AI] Gemini audio 처리

#### F-S9-AI-01: WAV → Gemini API
- **설명**: Base64 인코딩 후 `inline_data`로 전송
- **엔드포인트**: `POST /v1beta/models/gemini-2.0-flash-exp:generateContent`
- **Body**: `inline_data: {mime_type: "audio/wav", data: "<base64>"}`
- **우선순위**: 🔴 필수
- **수용 기준**: 응답 수신 < 5초

#### F-S9-AI-02: Function Call 실행
- **설명**: Stage 8.1의 12개 도구 재사용
- **우선순위**: 🔴 필수
- **수용 기준**: Function Call 실행 성공률 > 95%

#### F-S9-AI-03: 2-turn 자연어 응답
- **설명**: Function 결과 → Gemini → 자연어
- **우선순위**: 🔴 필수
- **수용 기준**: 응답 문장 획득

---

### 3.4 [F-S9-TTS] 음성 응답

#### F-S9-TTS-01: TTS 생성
- **설명**: Gemini 응답 텍스트 → 오디오
- **엔드포인트**: Google Cloud TTS 또는 Gemini TTS
- **포맷**: PCM 24kHz (재생용)
- **우선순위**: 🔴 필수
- **수용 기준**: 재생 지연 < 1초

#### F-S9-TTS-02: I2S 재생
- **설명**: MAX98357A 앰프 → 3W 스피커
- **우선순위**: 🔴 필수
- **수용 기준**: 명료도 > 90%

#### F-S9-TTS-03: 재생 중 마이크 mute
- **설명**: AEC 없으므로 mute 필수
- **우선순위**: 🔴 필수
- **수용 기준**: 에코 루프 0건

### 3.5 [F-S9-POWER] 전력 관리

#### F-S9-POWER-01: 상시 대기 전력

- **우선순위**: 🟡 선택
