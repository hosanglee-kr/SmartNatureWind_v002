# [제 1부] Phase 2 백엔드 및 FSM 확장 설계

## 0. 설계 개요

### 0.1 범위

| 구분 | 대상 | 방식 |
|---|---|---|
| **데이터 구조** | enum/struct 정의 | 헤더 확장 및 신규 |
| **C10 로더/저장** | profile/schedule `rule` 파싱·직렬화 | 단일 규격 (마이그레이션 배제) |
| **CT10 FSM** | `checkTriggers()` 리팩토링, `decideRunSource()` 우선순위 | Pause/Stop 이원화 |
| **AUTO 모드** | `AUTO_FULL` / `AUTO_SELECT` 세션 | 신규 위임 로직 |
| **API** | `/session/start` payload 확장 | 하위 호환 배제 |
| **계약 문서** | 6문서 동시 갱신 | 원칙 4 준수 |

### 0.2 설계 원칙

1. **하위 호환 배제 (Clean Break)**: `autoOff` → `rule` 단일 스키마, 레거시 분기 없음
2. **`ENV_PAUSED` 단일화**: `MOTION_BLOCKED` 완전 폐기
3. **온도/DI 이원화**: `mode = PAUSE | STOP` 사용자 선택
4. **세션 시작 시 규칙 스냅샷**: `_session.rule`에 복사 후 참조 (일관성 및 돌발 정지 방지)
5. **사용자 조작 절대 우선**: AUTO 세션 중 수동 조작 개입 시 즉시 MANUAL 자동 전환 (Zero-latency)
6. **계약 문서 동시 갱신**: 코드 변경 = 6문서 원자 커밋

```cpp
/* ======================================================
 * [Phase 2] TriggerRule 공통 스키마
 *  - profile.rule / schedule.rule / overrideState.rule 공통 사용
 *  - 하위 호환 배제: 기존 autoOff 완전 폐기

// 온도/DI 트리거의 동작 모드 (Pause/Stop 이원화)
typedef enum : uint8_t {
    EN_A20_RULE_MODE_PAUSE = 0,   // 자동 재개 (편의)
    EN_A20_RULE_MODE_STOP  = 1,   // 완전 종료 (안전, ACK 필요)
} EN_A20_ruleMode_t;

// 온도/DI 공통 임계 트리거 (DRY 통합 구조체)
typedef struct {
    bool              enabled    = false;
    EN_A20_ruleMode_t mode       = EN_A20_RULE_MODE_PAUSE;
    float             threshold  = 22.0f;   // 정지 임계 (°C 또는 DI)
    float             hysteresis = 0.5f;    // 재개 히스테리시스 (mode=PAUSE 시 유효, STOP 시 0.0 허용)
} ST_A20_ThresholdRule_t;

// 재실 트리거 (Pause 고정)
typedef struct {
    bool     enabled = false;
    uint16_t holdSec = 120;
} ST_A20_TriggerPir_t;

// 스마트 쾌적 (M4/M5용)
typedef struct {
    bool     enabled     = false;
    uint16_t intervalMin = 5;
    uint8_t  level       = 2;   // 0=off, 1=warn-only, 2=full
} ST_A20_TriggerSmartComfort_t;

// 통합 TriggerRule
typedef struct {
    // S2/S3 (Stop)
    struct { bool enabled = false; uint32_t minutes = 0; } timer;
    struct { bool enabled = false; char time[6] = {0}; } offTime;
    
    // P1/P2/P3 (Pause or Stop 이원화)
    ST_A20_ThresholdRule_t         tempLow;       // 기본: threshold=22.0f, hysteresis=0.5f
    ST_A20_ThresholdRule_t         diLow;         // 기본: threshold=65.0f, hysteresis=3.0f
    ST_A20_TriggerPir_t            pirPause;      // Pause 고정
    
    // M4/M5
    ST_A20_TriggerSmartComfort_t   smartComfort;
} ST_A20_TriggerRule_t;
```

```cpp
// ═══════════════════════════════════════════════════════════
// 통합 트리거 검사 (Pause / Stop 이원화 & 다중 Pause 래치)
//  - 호출: tickLoop → checkTriggers(&pauseOut, &stopOut)
//  - 반환: pauseOut != NONE → ENV_PAUSED 진입
//          stopOut  != NONE → AUTOOFF_STOPPED 진입
//  - 우선순위: Stop > Pause (Stop이 우선)
// ═══════════════════════════════════════════════════════════
bool CL_CT10_ControlManager::checkTriggers(EN_CT10_pause_t* p_pauseOut,
                                            EN_CT10_reason_t* p_stopOut) {
    if (p_pauseOut) *p_pauseOut = EN_CT10_PAUSE_NONE;
    if (p_stopOut)  *p_stopOut  = EN_CT10_REASON_NONE;
    
    const ST_A20_TriggerRule_t& r = _session.rule;
    uint32_t now = millis();
    
    // ═══════════════ 1) STOP 검사 (우선순위 최상) ═══════════════
    
    // 1-A. Timer
    if (triggerRt.timerArmed && triggerRt.timerMinutes > 0) {
        uint32_t elapsedMin = (now - triggerRt.timerStartMs) / 60000UL;
        if (elapsedMin >= triggerRt.timerMinutes) {
            if (p_stopOut) *p_stopOut = EN_CT10_REASON_AUTOOFF_TIMER;
            CL_D10_Logger::log(EN_L10_LOG_INFO,
                "[CT10] STOP: Timer %u min expired", triggerRt.timerMinutes);
            return true;
        }
    }
    
    // 1-B. OffTime
    if (triggerRt.offTimeEnabled) {
        struct tm tmv;
        if (CL_TM10_TimeManager::getLocalTime(tmv)) {
            int16_t yday = tmv.tm_yday;
            uint16_t curMin = tmv.tm_hour * 60 + tmv.tm_min;
            if (curMin >= triggerRt.offTimeMinutes && _persistOffTimeLastYday != yday) {
                _persistOffTimeLastYday = yday;
                if (p_stopOut) *p_stopOut = EN_CT10_REASON_AUTOOFF_TIME;
                return true;
            }
        }
    }
    
    // 환경 센서 1초 주기 평가 가드 (WCET 예산 25ms 준수)
    bool doEnvCheck = (now - triggerRt.lastEnvCheckMs >= 1000UL) || (triggerRt.lastEnvCheckMs == 0);
    if (doEnvCheck) {
        triggerRt.lastEnvCheckMs = now;
        
        // 1-C. TempLow (mode=STOP)
        if (r.tempLow.enabled && r.tempLow.mode == EN_A20_RULE_MODE_STOP) {
            float t = getCurrentTemperatureMock();
            if (t < r.tempLow.threshold) {
                if (p_stopOut) *p_stopOut = EN_CT10_REASON_TEMP_LOW_STOP;
                CL_D10_Logger::log(EN_L10_LOG_INFO,
                    "[CT10] STOP: tempLow %.2f < %.2f", t, r.tempLow.threshold);
                return true;
            }
        }
        
        // 1-D. DiLow (mode=STOP)
        if (r.diLow.enabled && r.diLow.mode == EN_A20_RULE_MODE_STOP) {
            float di = getDiscomfortIndex();
            if (di < r.diLow.threshold) {
                if (p_stopOut) *p_stopOut = EN_CT10_REASON_DI_LOW_STOP;
                return true;
            }
        }
    }
    
    // ═══════════════ 2) PAUSE 검사 (다중 래치 pauseMask 관리) ═══════════════
    
    // 2-A. PIR
    if (r.pirPause.enabled && motion) {
        if (!motion->isActive()) {
            triggerRt.pauseMask |= CT10_PAUSE_MASK_MOTION;
        } else {
            triggerRt.pauseMask &= ~CT10_PAUSE_MASK_MOTION;
        }
    }
    
    if (doEnvCheck) {
        // 2-B. TempLow (mode=PAUSE) — 히스테리시스
        if (r.tempLow.enabled && r.tempLow.mode == EN_A20_RULE_MODE_PAUSE) {
            float t = getCurrentTemperatureMock();
            float stopTh = r.tempLow.threshold;
            float resumeTh = stopTh + r.tempLow.hysteresis;
            
            if (t < stopTh) {
                triggerRt.tempPaused = true;
                triggerRt.pauseMask |= CT10_PAUSE_MASK_TEMP;
            } else if (t >= resumeTh) {
                triggerRt.tempPaused = false;
                triggerRt.pauseMask &= ~CT10_PAUSE_MASK_TEMP;
            }
        }
        
        // 2-C. DiLow (mode=PAUSE) — 히스테리시스
        if (r.diLow.enabled && r.diLow.mode == EN_A20_RULE_MODE_PAUSE) {
            float di = getDiscomfortIndex();
            float stopTh = r.diLow.threshold;
            float resumeTh = stopTh + r.diLow.hysteresis;
            
            if (di < stopTh) {
                triggerRt.diPaused = true;
                triggerRt.pauseMask |= CT10_PAUSE_MASK_DI;
            } else if (di >= resumeTh) {
                triggerRt.diPaused = false;
                triggerRt.pauseMask &= ~CT10_PAUSE_MASK_DI;
            }
        }
    }
    
    // 다중 Pause 조건 중 하나라도 활성이면 ENV_PAUSED 진입
    if (triggerRt.pauseMask != 0) {
        if (p_pauseOut) {
            // 대표 사유 설정 (우선순위: PIR > Temp > DI)
            if (triggerRt.pauseMask & CT10_PAUSE_MASK_MOTION) *p_pauseOut = EN_CT10_PAUSE_MOTION;
            else if (triggerRt.pauseMask & CT10_PAUSE_MASK_TEMP) *p_pauseOut = EN_CT10_PAUSE_TEMP_LOW;
            else if (triggerRt.pauseMask & CT10_PAUSE_MASK_DI) *p_pauseOut = EN_CT10_PAUSE_DI_LOW;
        }
        return true;
    }
    
    return false;
}

// ═══════════════════════════════════════════════════════════
// Pause 재개 조건 검사 (decideRunSource에서 호출)
//  - 모든 활성 Pause 조건이 해소(pauseMask == 0)되어야만 재개!
// ═══════════════════════════════════════════════════════════
static bool isPauseResumed(const ST_A20_TriggerRule_t& r,
                            ST_CT10_TriggerRuntime_t& rt,
                            EN_CT10_pause_t& pauseReasonInOut,
                            CL_CT10_ControlManager& ctrl) {
    uint32_t now = millis();
    
    // 1) PIR 감지 상태 갱신
    if (r.pirPause.enabled && ctrl.motion) {
        if (ctrl.motion->isActive()) {
            rt.pauseMask &= ~CT10_PAUSE_MASK_MOTION;
        } else {
            rt.pauseMask |= CT10_PAUSE_MASK_MOTION;
        }
    }
    
    // 2) 환경 센서 1초 주기 갱신
    if ((now - rt.lastEnvCheckMs >= 1000UL) || (rt.lastEnvCheckMs == 0)) {
        rt.lastEnvCheckMs = now;
        
        if (r.tempLow.enabled && r.tempLow.mode == EN_A20_RULE_MODE_PAUSE) {
            float t = ctrl.getCurrentTemperatureMock();
            float resumeTh = r.tempLow.threshold + r.tempLow.hysteresis;
            if (t >= resumeTh) {
                rt.tempPaused = false;
                rt.pauseMask &= ~CT10_PAUSE_MASK_TEMP;
            } else if (t < r.tempLow.threshold) {
                rt.tempPaused = true;
                rt.pauseMask |= CT10_PAUSE_MASK_TEMP;
            }
        }
        
        if (r.diLow.enabled && r.diLow.mode == EN_A20_RULE_MODE_PAUSE) {
            float di = ctrl.getDiscomfortIndex();
            float resumeTh = r.diLow.threshold + r.diLow.hysteresis;
            if (di >= resumeTh) {
                rt.diPaused = false;
                rt.pauseMask &= ~CT10_PAUSE_MASK_DI;
            } else if (di < r.diLow.threshold) {
                rt.diPaused = true;
                rt.pauseMask |= CT10_PAUSE_MASK_DI;
            }
        }
    }
    
    // 3) 모든 조건 해소 시에만 완전 재개
    if (rt.pauseMask == 0) {
        return true;
    }
    
    // 아직 Pause 중인 경우 대표 사유 갱신
    if (rt.pauseMask & CT10_PAUSE_MASK_MOTION) pauseReasonInOut = EN_CT10_PAUSE_MOTION;
    else if (rt.pauseMask & CT10_PAUSE_MASK_TEMP) pauseReasonInOut = EN_CT10_PAUSE_TEMP_LOW;
    else if (rt.pauseMask & CT10_PAUSE_MASK_DI) pauseReasonInOut = EN_CT10_PAUSE_DI_LOW;
    return false;
}
```

```cpp
ST_CT10_Decision_t CL_CT10_ControlManager::decideRunSource() {
    ST_CT10_Decision_t d;
    memset(&d, 0, sizeof(d));
    
    // [1] AutoOff 래치 (최우선)
    if (_autoOffLatched) {
        d.nextState = EN_CT10_STATE_AUTOOFF_STOPPED;
        d.reason = runCtx.reason;
        d.wantSimStop = true;
        return d;
    }
    
    // [2] ENV_PAUSED 재개 판정 (OVERRIDE 포함 모든 활성 세션 대상)
    if (runCtx.state == EN_CT10_STATE_ENV_PAUSED) {
        if (!isPauseResumed(_session.rule, triggerRt,
                            runCtx.pauseReason, *this)) {
            d.nextState = EN_CT10_STATE_ENV_PAUSED;
            d.reason = runCtx.reason;
            d.wantSimStop = true;
            return d;
        }
        // 재개: 아래 로직으로 진행 (overrideState.active 유지 시 [4]에서 자동 복귀)
        CL_D10_Logger::log(EN_L10_LOG_INFO,
            "[CT10] PAUSE resumed (was reason=%u)", runCtx.pauseReason);
    }
    
    // [3] 새 Pause/Stop 조건 검사 (OVERRIDE 포함 — 타이머/저온/DI/PIR 일관 적용)
    EN_CT10_pause_t pauseOut = EN_CT10_PAUSE_NONE;
    EN_CT10_reason_t stopOut = EN_CT10_REASON_NONE;
    if (checkTriggers(&pauseOut, &stopOut)) {
        if (stopOut != EN_CT10_REASON_NONE) {
            d.nextState = EN_CT10_STATE_AUTOOFF_STOPPED;
            d.reason = stopOut;
            d.wantSimStop = true;
            return d;
        }
        if (pauseOut != EN_CT10_PAUSE_NONE) {
            d.nextState = EN_CT10_STATE_ENV_PAUSED;
            d.nextPauseReason = pauseOut;
            d.wantSimStop = true;
            return d;
        }
    }
    
    // [4] Override 활성 (Pause 해소 시 자동 복귀)
    if (overrideState.active) {
        d.nextState = EN_CT10_STATE_OVERRIDE;
        d.reason = EN_CT10_REASON_OVERRIDE_ACTIVE;
        return d;
    }
    
    // [5] ProfileMode (기존과 동일, MOTION_BLOCKED 제거)
    if (useProfileMode && runSource == EN_CT10_RUN_USER_PROFILE && curProfileIndex >= 0) {
        d.nextState = EN_CT10_STATE_PROFILE_RUN;
        d.reason = EN_CT10_REASON_PROFILE_MODE;
        d.nextRunSource = EN_CT10_RUN_USER_PROFILE;
        d.nextProfileIndex = curProfileIndex;
        return d;
    }
    
    // [6] TimeInvalid
    if (!CL_TM10_TimeManager::isTimeValid()) {
        d.nextState = EN_CT10_STATE_TIME_INVALID;
        d.reason = EN_CT10_REASON_TIME_NOT_VALID;
        d.wantSimStop = true;
        return d;
    }
    
    // [7] Schedule
    if (g_A20_config_root.schedules) {
        int idx = findActiveScheduleIndex(*g_A20_config_root.schedules, true);
        if (idx >= 0) {
            d.nextState = EN_CT10_STATE_SCHEDULE_RUN;
            d.reason = EN_CT10_REASON_SCHEDULE_ACTIVE;
            d.nextRunSource = EN_CT10_RUN_SCHEDULE;
            d.nextScheduleIndex = idx;
            return d;
        }
    }
    
    // [8] IDLE
    d.nextState = EN_CT10_STATE_IDLE;
    d.reason = EN_CT10_REASON_NONE;
    d.wantSimStop = true;
    return d;
}
```

```cpp
void CL_CT10_ControlManager::tickAutoComfort() {
    if (millis() - s_autoComfortLastEvalMs < AUTO_COMFORT_INTERVAL_MS) return;
    s_autoComfortLastEvalMs = millis();
    auto& self = instance();

    // AUTO_FULL 세션 재평가 (전역 s_autoComfortEnabled와 무관하게 항상 실행)
    if (self._session.type == EN_CT10_SESSION_AUTO_FULL &&
        self._session.state == EN_SESSION_ACTIVE) {
        const char* recPreset = getRecommendedPresetCode();
        const char* recStyle  = getRecommendedStyleCode();
        
        if (strcasecmp(self._session.payload.preset.presetCode, recPreset) != 0) {
            CL_D10_Logger::log(EN_L10_LOG_INFO,
                "[CT10] AUTO_FULL switch: %s → %s", 
                self._session.payload.preset.presetCode, recPreset);
            self.applyPresetToSession(recPreset, recStyle); // override + payload.preset 동시 갱신
        }
        return;
    }
    
    // AUTO_SELECT 세션 재평가 (전역 s_autoComfortEnabled와 무관하게 항상 실행)
    if (self._session.type == EN_CT10_SESSION_AUTO_SELECT &&
        self._session.state == EN_SESSION_ACTIVE) {
        const char* newStyle = getRecommendedStyleCode();
        
        if (self._session.autoSelect.baseType == EN_CT10_SESSION_PRESET) {
            if (strcasecmp(self._session.payload.preset.styleCode, newStyle) != 0) {
                CL_D10_Logger::log(EN_L10_LOG_INFO,
                    "[CT10] AUTO_SELECT style: %s → %s",
                    self._session.payload.preset.styleCode, newStyle);
                self.applyPresetToSession(self._session.autoSelect.basePresetCode, newStyle);
            }
        }
        // PLAYLIST base는 step별 presetCode 유지 + styleCode만 자동 갱신
        return;
    }
    
    // 기존 Auto Comfort (IDLE 자동 시작) — 전역 스위치 게이트 적용
    if (!s_autoComfortEnabled) return;
    if (self.isSessionActive()) return;
    if (self.runCtx.state == EN_CT10_STATE_AUTOOFF_STOPPED || self._autoOffLatched) return;
    
    const char* recPreset = getRecommendedPresetCode();
    if (recPreset && strlen(recPreset) > 0) {
        self.startPresetManual(recPreset, getRecommendedStyleCode());
        self._session.trigger = EN_CT10_TRIGGER_AUTO_COMFORT;
    }
}
```

## Part I. 정책 최종 확정 사항 (설계 확정 완료)

사용자 검토 및 확정에 따라 아래 2대 운영 정책을 **권장안 A**로 최종 확정하고 구현에 적용합니다:

### 1. Session 중 rule 변경 정책: **A안 확정 (세션 시작 시 스냅샷 고정)**
* **동작 원칙**:
  - 세션 시작 시 프로필/스케줄의 rule이 `_session.rule`로 스냅샷 복사되어 독립적으로 실행됨.
  - 실행 중에 사용자가 프로필 원본 rule을 수정하더라도, **현재 돌고 있는 세션에는 영향을 주지 않고 다음 세션 시작부터 적용**됨.
  - 실시간 타이머 조절이나 조건 변경이 필요한 경우, Now Playing Bar의 빠른 설정(Quick Action)을 통해 현재 세션만 직접 제어.
* **확정 사유**:
  - 실행 중 런타임 값 덮어쓰기로 인한 돌발 정지(예: 타이머 축소 시 갑작스러운 전원 OFF) 및 FSM 래치 꼬임 원천 방지.
  - Core 0/1 간 Lock 경합 제로로 WCET(25ms) 및 시스템 안정성 보장.

### 2. AUTO 중 사용자 개입 시 처리: **A안 확정 (개입 즉시 AUTO → MANUAL 자동 전환)**
* **동작 원칙**:
  - `AUTO_FULL` 또는 `AUTO_SELECT` 세션 실행 중, 사용자가 홈 화면 슬라이더로 풍속을 변경하거나 다른 프리셋을 직접 선택하면:
    1) **개입 즉시** 사용자가 명령한 풍속/프리셋으로 모터 출력 반영 (Zero-latency).
    2) 세션 트리거가 `AUTO_xxx` → `MANUAL`로 즉시 변경되며, 시스템의 5분 주기 자동 개입(`tickAutoComfort`)은 정지됨.
    3) 상태 배지가 `[✨ AI 자동 운전]` → `[✋ 수동 제어]`로 즉각 전환되며 사용자 제어 우선권 확보.
* **확정 사유**:
  - *"사용자의 물리적 직접 조작은 항상 시스템 자동 개입보다 우선한다"*는 가전 UX 대원칙 준수.
  - 조작 지연을 유발하는 불필요한 확인 모달을 배제하고 즉각적인 반응성 확보.

> **착수 선언**: 2대 핵심 정책 확정 완료에 따라 **G1(데이터 구조 정의)부터 순차 구현에 착수**합니다.

#### 7.5.2 Y축 고정 스케일 및 렌더링 3대 불변 원칙
1. **절대 비교 보장 (No Jittering Auto-scale)**:
   - 미풍 상태에서 풍속 변화가 미세하더라도 차트가 상하로 크게 출렁이는 오토스케일링을 영구 금지한다.
   - 사용자가 한눈에 "현재 바람이 수면 미풍(2 m/s 이하)이구나" 또는 "강한 자연풍이구나"를 직관적으로 판별할 수 있어야 한다.
2. **이중 축 분리 (Decoupled Dual-Axis)**:
   - 물리 풍속(`m/s`, 0~8)과 모터 제어 신호(`PWM %`, 0~100)는 반드시 좌측/우측으로 Y축을 분리한다. 풍속 곡선이 PWM 곡선에 가려지거나 왜곡되는 현상을 원천 방지한다.
3. **목적 기반 렌더링 이원화 (SVG vs Canvas 2D)**:
   - 정적/저주기 트렌드(홈 환경 스파크라인, 24시간 타임라인)는 CSS 스타일링과 반응형 확장이 용이한 **경량 SVG**로 렌더링한다.
   - 고주기 실시간 스트리밍(모니터 물리 차트, 체험실 시뮬레이터, 감성 레이더)은 메모리 가비지 컬렉션(GC) 부하가 없는 **Canvas 2D 버퍼 렌더링**을 적용하여 60fps 부드러운 애니메이션을 보장한다.

### 6. 2대 Auto 체계 통폐합 확정 (AI 스마트 쾌적 & 취향 맞춤 Auto)
1. **스마트 쾌적 + AI 알아서 → `✨ AI 스마트 쾌적` 통폐합**:

2. **선택 Auto → `🎯 취향 맞춤 Auto` 명확화**:
   - 사용자가 원하는 바람(프리셋/프로필)은 고정하고, 실시간 날씨에 따라 바람 세기(스타일/PWM)만 시스템이 자동 조절하는 반자율 모드로 분리.
3. **사용자 경험(UX) 효과**: 3개 혼재로 인한 인지 부하 해소, 2대 Auto 체계로 직관적 선택 보장.
