## 2. 공통 HTTP 통신 및 보안 정책 (`W10_Web_Util_0203.cpp`)
- **인증 정책 (`requireApiKey`)**:
  - 컴파일 플래그 `W10_USE_API_KEY == 0`이면 개방 모드로 통과[span_22](start_span)[span_22](end_span)[span_23](start_span)[span_23](end_span)
  - 활성화 시 `system.security.apiKey`가 설정된 경우 HTTP 헤더 `X-API-Key` 일치 여부 검증 (불일치 시 `401 Unauthorized` + `{"error":"unauthorized","hint":"X-API-Key header required"}` 즉시 반환)[span_24](start_span)[span_24](end_span)
- **공통 응답 헤더 (`_applyHeaders`)**:
  - `Access-Control-Allow-Origin: *`, `Access-Control-Allow-Methods: GET, POST, PUT, PATCH, DELETE, OPTIONS`, `Access-Control-Allow-Headers: Content-Type, X-API-Key`[span_25](start_span)[span_25](end_span)
  - `X-Content-Type-Options: nosniff`[span_26](start_span)[span_26](end_span)
  - API JSON 응답은 `Cache-Control: no-store`, `Pragma: no-cache` 강제 적용[span_27](start_span)[span_27](end_span)
- **페이로드 크기 한도**:
  - 일반 JSON Body 누적 버퍼(`W10_MAX_ACCUM_BODY`): 최대 `1MB` (`1,048,576 bytes`), 초과 시 `413 Payload Too Large`[span_28](start_span)[span_28](end_span)[span_29](start_span)[span_29](end_span)
  - AI 프록시/액션 요청 본문(`W10_AI_Limits::G_MAX_REQUEST_BODY`): 최대 `12KB` (`12,288 bytes`)[span_30](start_span)[span_30](end_span)
  - 파일 업로드 및 OTA 펌웨어(`G_W10_MAX_UPLOAD_SIZE`): 최대 `2MB` (`2,097,152 bytes`), 동시 업로드 시 `429 Too Many Requests`[span_31](start_span)[span_31](end_span)[span_32](start_span)[span_32](end_span)
