## 1. 30초 빠른 시작 (처음 사용자용)

1. **전원 연결**: 기기에 5V/12V 전원을 연결합니다. (기기 내 상태 표시 LED가 빨간색으로 점멸하며 부팅됩니다)
2. **와이파이 연결**: 스마트폰이나 노트북의 Wi-Fi 목록에서 **`NatureWind`**를 찾아 연결합니다.
   - **기본 비밀번호**: `2540`
3. **웹 대시보드 열기**: 인터넷 브라우저(Chrome, Safari 등)를 열고 주소창에 아래 주소를 입력합니다:
   ```text
   http://192.168.4.1
   ```
4. **자연풍 즐기기**: 화면에 표시되는 **`Ocean(바다)`**, **`Mountain(산바람)`**, **`Forest(숲속)`** 버튼 중 하나를 누르면 자연풍 물리 시뮬레이션 바람이 즉시 시작됩니다!
5. **선풍기 정지**: 대시보드 상단의 **`정지 (STOP)`** 버튼을 누르면 언제든지 팬이 부드럽게 멈춥니다.

## 2. 제품 소개 및 핵심 특징

### 2.1 Smart Nature Wind는 어떤 제품인가요?
Smart Nature Wind v0200은 기존 선풍기의 단순하고 인위적인 1-2-3단 바람 대신, **실제 대기(大氣)의 기류 변화, 돌풍(Gust), 난류(Turbulence), 지표면 열기포(Thermal Bubble)를 실시간 물리 엔진(S10/S20)으로 계산하여 재현하는 차세대 스마트 자연풍 제어기**입니다.

기기 자체에 고성능 듀얼코어 MCU(ESP32-S3)와 고속 LittleFS 웹서버가 내장되어 있어, 별도의 외부 클라우드나 앱 설치 없이 웹 브라우저만으로 모든 기능을 완벽하게 제어할 수 있습니다.

### 2.2 핵심 기능 요약

| 기능 영역 | 주요 특징 | 사용자 체감 가치 |
|---|---|---|
| **물리 기반 자연풍** | 10종 자연 프리셋 + 5종 바람 스타일 | 획일적이지 않은 부드럽고 상쾌한 자연의 바람 |
| **인체 감지 절전 (PIR)** | 사람의 재실/부재 자동 감지 | 자리 비움 시 자동 정지, 복귀 시 부드러운 자동 재개 |
| **온습도 환경 적응 (DHT22)** | 실시간 온도/습도 모니터링 | 과냉 방지 자동 종료 및 실내 온습도 쾌적도 관리 |
| **3대 자동 종료 (AutoOff)** | 타이머 / 취침 시각 / 목표 온도 정지 | 잠든 사이 감기나 저체온증 없는 안심 수면 보장 |
| **주간 정밀 스케줄러** | 요일별(월~일) 24시간 타임라인 자동 운전 | 아침 기상, 집중 근무, 취침에 맞춘 자동화 |
| **맞춤 프로파일 (Profile)** | 다단계 바람 세그먼트 커스텀 제작 | 사용자 취향에 맞춘 최적의 나만의 풍속 사이클 설계 |
| **초고속 웹 대시보드** | 번들링 및 Gzip 사전 압축 탑재 | 모바일/PC 브라우저에서 0.5초 이내 즉각 반응 |
| **다채로운 상태 LED** | WS2812B RGB NeoPixel 상태 표시 | 색상과 점멸 속도로 기기 연결 및 운전 상태 직관 파악 |

## 3. 기기 연결 및 웹 대시보드 접속

Smart Nature Wind는 2가지 Wi-Fi 모드를 지원합니다:
- **단독 모드 (SoftAP)**: 공유기가 없는 장소에서도 스마트폰과 기기가 1:1로 직접 연결됩니다.
- **공유기 연동 모드 (STA)**: 집이나 사무실의 Wi-Fi 공유기에 등록하여 같은 네트워크의 모든 기기에서 접속할 수 있습니다.

### 3.1 SoftAP 모드로 직접 접속 (기본 방식)
기기를 처음 구매했거나 외부에서 사용할 때 사용하는 가장 간편한 방식입니다.

1. 스마트폰의 Wi-Fi 설정을 켭니다.
2. 주변 네트워크 검색 목록에서 **`NatureWind`**를 선택합니다.
3. 비밀번호 입력 창에 **`2540`**을 입력하고 연결합니다.
4. 브라우저를 켜고 주소창에 **`http://192.168.4.1`**을 입력하여 접속합니다.

> 💡 **안내**: "인터넷이 연결되지 않은 네트워크"라는 스마트폰 알림이 떠도 **"연결 유지"**를 선택해 주세요. 기기와 직접 통신하는 로컬 제어망이기 때문에 정상 동작입니다.

### 3.2 가정/사무실 Wi-Fi 공유기(STA)에 연결하기
집 안 어디서나 접속하고, 정확한 인터넷 시간(NTP)을 동기화하려면 공유기에 등록하는 것을 권장합니다.

1. SoftAP 상태(`http://192.168.4.1`)에서 상단 메뉴의 **`System (설정)`** 페이지로 이동합니다.
2. **Wi-Fi 설정** 카드에서 사용 중인 공유기(SSID)와 비밀번호를 입력하고 **`저장 및 재연결`**을 누릅니다.
3. 기기가 공유기에 연결되면, 상태 LED가 녹색 점멸로 바뀌며 공유기에서 할당받은 새로운 IP 주소(예: `192.168.0.50`)로 접속할 수 있습니다.

### 3.3 스마트폰 홈 화면에 바로가기 아이콘 만들기 (앱처럼 사용하기)
스마트폰 브라우저에서 매번 주소를 입력하지 않고 일반 앱처럼 사용하실 수 있습니다:
- **아이폰 (Safari)**: 하단 공유 버튼(`공유 아이콘`) → **`홈 화면에 추가`** 선택
- **안드로이드 (Chrome)**: 우측 상단 메뉴(`점 3개`) → **`홈 화면에 추가`** 또는 **`앱 설치`** 선택

## 4. 메인 대시보드 조작 가이드 (`/main`, P010)

대시보드는 제품의 모든 일상 조작을 한눈에 파악하고 1초 만에 제어할 수 있는 메인 화면입니다.

```text
┌────────────────────────────────────────────────────────┐
│  🍃 Smart Nature Wind v0200         [● STA 연결됨]     │
├────────────────────────────────────────────────────────┤
│  [실시간 상태 카드]                                     │
│   • 현재 풍속: 45% (자연풍: OCEAN / BALANCE)            │
│   • 실내 환경: 25.4 ℃  |  54 %  |  재실 감지됨(Active) │
├────────────────────────────────────────────────────────┤
│  [빠른 제어 버튼]                                       │
│   [ ▶ 수동 ON ]   [ ⏹ 정지 (STOP) ]   [ ⏱ 1시간 타이머 ] │
├────────────────────────────────────────────────────────┤
│  [자연풍 프리셋 선택 (10종)]                            │
│   [ Ocean ] [ Country ] [ Medit. ] [ Mountain ] ...    │
├────────────────────────────────────────────────────────┤
│  [바람 스타일 (5종)]                                    │
│   (●) Balance   ( ) Active   ( ) Focus   ( ) Sleep     │
└────────────────────────────────────────────────────────┘
```

### 4.1 실시간 모니터링 카드
- **현재 풍속 게이지**: 물리 엔진이 10ms 단위로 계산하는 실제 팬 가동률(0~100%)을 부드러운 애니메이션으로 표시합니다.
- **온도 / 습도**: 내장된 고정밀 DHT22 센서가 측정한 실시간 실내 온도(℃)와 상대습도(%)를 보여줍니다.
- **재실(모션) 상태**: 인체감지 센서가 사람을 감지하고 있는지, 부재 중 카운트다운 상태인지 실시간 표시합니다.

### 4.2 빠른 제어 버튼
- **수동 시작 (Manual Run)**: 슬라이더로 지정한 고정 풍속(예: 35%)으로 팬을 즉시 가동합니다.
- **정지 (STOP)**: 즉시 모터를 정지하고 대기(IDLE) 상태로 전환합니다.
- **1시간 타이머**: 원클릭으로 60분 취침 타이머를 가동합니다.

## 5. 자연풍 물리 시뮬레이션 바람 사전 (`windDict`)

Smart Nature Wind의 핵심인 **10대 자연풍 프리셋**과 **5대 바람 스타일**을 조합하여 총 50가지의 독창적인 바람 감성을 경험할 수 있습니다.

### 5.1 자연풍 프리셋 10종

| 프리셋 이름 | 한글 감성 명칭 | 바람의 물리적 특성 및 추천 상황 |
|---|---|---|
| **Ocean** | 바다 바람 | 파도가 밀려오듯 주기적인 큰 파동과 시원한 강풍이 어우러진 해변의 바람 |
| **Country Breeze** | 시골 들판 바람 | 완만한 곡선을 그리며 살랑살랑 불어오는 가장 편안하고 포근한 미풍 |
| **Mediterranean** | 지중해 연안 바람 | 적당한 난류와 부드러운 온도가 조화로운 쾌적하고 산뜻한 휴양지 바람 |
| **Mountain** | 깊은 산속 계곡풍 | 계곡 사이를 스치듯 역동적이고 굵은 돌풍이 시원하게 불어오는 활력 바람 |
| **Plains** | 대평원 바람 | 막힘없이 넓은 들판을 가로지르는 연속적이고 시원한 지속형 강풍 |
| **Harbor Breeze** | 항구의 활기찬 바람 | 바다 내음과 함께 빠르고 리듬감 있게 불어오는 경쾌한 바람 |
| **Forest Canopy** | 숲속 쉼표 바람 | 우거진 나뭇잎 사이로 부서져 내리듯 고요하고 은은한 초저소음 휴식 바람 |
| **Urban Sunset** | 도시 일몰 바람 | 하루를 마무리하는 저녁 무렵의 차분하고 온화한 감성 바람 |
| **Tropical Rain** | 열대우림 소나기 바람 | 소나기 직전의 강한 기류 변화와 돌풍을 느낄 수 있는 다이내믹한 바람 |
| **Soft Breeze** | 초미풍 수면 바람 | 모터 소음과 바람 소리를 극한으로 억제한 무자극 수면 전용 바람 |

### 5.2 바람 스타일 5종

동일한 프리셋(예: Ocean)을 선택하더라도, 현재 기분이나 활동에 따라 스타일 배율을 적용할 수 있습니다:

1. **Balance (표준)**: 원본 자연풍의 물리 계수를 100% 그대로 유지하는 가장 자연스러운 상태.
2. **Active (활력)**: 운동 후나 무더운 낮 시간용. 돌풍 주기와 강도를 25~30% 상향하여 시원함을 극대화.
3. **Focus (집중)**: 독서나 업무용. 변동폭을 20% 줄이고 잔잔하게 유지하여 주의를 분산시키지 않음.
4. **Relax (휴식)**: 소파에서 휴식할 때 적합한 부드러운 바람. 강풍 요소를 낮추고 열기포 주기를 완화.
5. **Sleep (수면)**: 수면 전용. 전체 풍속을 35% 낮추고 돌풍을 60% 억제하여 체온 저하를 방지.

## 6. 스마트 센서 연동 및 3대 자동 종료 (AutoOff)

Smart Nature Wind는 실내 환경과 사람의 움직임을 스스로 감지하여 불필요한 전력 낭비를 막고 사용자의 건강을 보호합니다.

### 6.1 인체 감지(PIR) 스마트 절전 운전
- **동작 원리**: 고감도 PIR 인체감지 센서가 실내 움직임을 모니터링합니다.
- **자동 절전 (MOTION_BLOCKED)**: 사람이 방을 나가면 설정된 시간(기본 120초) 동안 대기 후 팬을 자동으로 멈춥니다.
- **자동 복귀 (Soft Start)**: 사람이 다시 방으로 돌아오면 별도 조작 없이 즉시 이전 바람 모드로 부드럽게 재개됩니다.
- **옵션 끄기**: 센서 연동을 원치 않으시면 메인 화면이나 설정에서 언제든 기능을 비활성화할 수 있습니다.

### 6.2 3대 스마트 자동 종료 (AutoOff)

```text
┌────────────────────────────────────────────────────────┐
│                   3대 스마트 자동 종료                  │
├───────────────────┬───────────────────┬────────────────┤
│ ⏱ 취침 타이머      │ ⏰ 지정 시각 종료  │ 🌡 과냉 방지 온도 │
│ (Timer AutoOff)   │ (Off-Time)        │ (Off-Temp)     │
├───────────────────┼───────────────────┼────────────────┤
│ 설정한 시간(분) 후 │ 매일 특정 시각     │ 실내 온도가     │
│ 자동으로 정지      │ (예: 새벽 03:30)에 │ 설정치(예 23℃) │
│                   │ 1회 자동 정지     │ 이하로 내려가면 │
│                   │                   │ 감기 예방 정지 │
└───────────────────┴───────────────────┴────────────────┘
```

1. **취침 타이머 (Timer AutoOff)**:
   - 10분, 30분, 1시간, 2시간 등 원하는 시간 후 자동 정지하도록 설정합니다.
2. **지정 시각 자동 종료 (Off-Time)**:
   - 깊은 밤 특정 시각(예: 오전 03:00)에 선풍기가 자동으로 꺼지길 원할 때 사용합니다.
   - **중복 방지 안심 설계**: 동일한 날(yday)에는 단 1회만 트리거되므로 의도치 않게 다시 꺼지는 일이 없습니다.
3. **과냉 방지 자동 종료 (Off-Temp)**:
   - 밤새 기온이 급격히 떨어져 실내 온도가 지정한 안전 온도(예: 23.0℃) 밑으로 내려가면 선풍기가 저절로 멈춥니다. 감기나 수면 중 저체온증을 원천 예방합니다.

> 🔒 **자동 종료 후 래치(Latch) 안전 보호**:
> 자동 종료가 발동되면 기기는 **`AUTOOFF_STOPPED`** 래치 상태로 안전하게 잠깁니다. 이는 사용자가 잠결에 추워서 꺼진 선풍기가 온도 변화 등으로 갑자기 다시 켜지는 것을 방지하기 위함입니다. 다시 가동하려면 웹 화면에서 모드를 변경하거나 수동 시작 버튼을 누르시면 정상 해제됩니다.

## 7. 주간 스케줄러 설정 (`/schedules_t2`)

요일별, 시간대별로 선풍기가 알아서 켜지고 원하는 자연풍으로 동작하도록 주간 스케줄을 계획할 수 있습니다.

```text
[월요일 스케줄 예시]
07:00 ~ 08:30 ──► MOUNTAIN (Active) : 활기찬 기상 바람
08:30 ~ 19:00 ──► IDLE (대기)        : 출근 시간대 전원 OFF
19:00 ~ 23:00 ──► OCEAN (Relax)     : 퇴근 후 편안한 휴식 바람
23:00 ~ 03:00 ──► FOREST (Sleep)    : 조용한 수면 바람 (03:00 자동 종료)
```

### 7.1 스케줄 등록 방법
1. 상단 메뉴에서 **`Schedule T2`** 페이지를 클릭합니다.
2. 타임라인에서 원하는 요일(월~일)을 선택합니다.
3. **`새 스케줄 추가`** 버튼을 누릅니다:
   - **시작 / 종료 시간**: (예: 22:00 ~ 06:00)
   - **바람 프리셋**: (예: Forest Canopy)
   - **바람 스타일**: (예: Sleep)
4. **`저장`**을 누르면 기기의 LittleFS 메모리에 즉시 반영되어 설정한 시간이 되면 자동으로 동작합니다.

> 🕒 **스케줄 작동 필수 조건**:
> 주간 스케줄러가 정확한 시간에 켜지려면 기기가 가정 내 Wi-Fi에 연결되어 인터넷 표준 시간(NTP)을 받아와야 합니다. 인터넷 미동기화 시에는 안전을 위해 스케줄 작동이 대기(`TIME_INVALID`) 상태로 유지됩니다.

## 8. 맞춤 바람 프로파일 제작 (`/userProfile_t2`)

기본 제공되는 10종 자연풍 외에, **풍속과 동작 주기를 자유자재로 조합한 나만의 바람 시퀀스**를 직접 제작할 수 있습니다.

### 8.1 세그먼트(Segment) 구조
하나의 프로파일은 여러 개의 연속된 구간(Segment)으로 이루어집니다:
- **구간 1 (부드러운 시작)**: 풍속 25%로 3분간 가동
- **구간 2 (강한 환기 바람)**: 풍속 75%로 1분간 가동
- **구간 3 (휴지기)**: 풍속 0%로 30초간 모터 쉼
- **반복 횟수**: 위 1~3 구간을 5회 반복 후 자동 종료

### 8.2 프로파일 생성 및 적용
1. 상단 메뉴에서 **`UserProfile T2`** 페이지를 선택합니다.
2. 새 프로파일의 이름을 입력합니다 (예: `요가 집중 모드`, `아기 낮잠 모드`).
3. 각 스텝별 **목표 풍속(%)**과 **유지 시간(초/분)**을 추가합니다.
4. 저장을 완료한 후 메인 대시보드에서 해당 프로파일을 선택하면 나만의 맞춤 바람이 시작됩니다.

## 9. 실시간 물리 시뮬레이션 차트 (`/chart_t3`)

Smart Nature Wind가 단순한 기계적 모터 회전이 아닌, **살아있는 대기 물리 시뮬레이션**으로 동작하고 있음을 눈으로 직접 확인할 수 있는 전문 그래픽 뷰어입니다.

```text
  풍속(m/s)
    ▲
7.0 │               ╭─╮           ╭──╮       돌풍(Gust) 발생 구간
5.0 │      ╭─╮     │ │   ╭─╮     │  │
3.0 │  ╭──╯ ╰──╮  │ ╰──╯ ╰─╮   │  ╰──╮   기저 자연풍
1.0 └──┴────────┴─┴──────────┴───┴───────► 시간(초)
       0s       30s       60s       90s      120s
```

- **120포인트 실시간 파형**: 120초간의 풍속 변화 곡선이 1.2초마다 매끄럽게 갱신됩니다.
- **물리 요소 분해 관측**: 기저 바람선, 난류 변동폭(Sigma), 돌풍 피크(Gust Peak), 열기포 상승 구간이 색상별로 구분되어 표시됩니다.
- **미니맵 & 크로스헤어**: 그래프 아래 미니맵을 드래그하여 특정 시간 구간을 확대(Zoom)하거나, 마우스를 올려 정확한 순간 풍속과 파라미터를 점검할 수 있습니다.

## 10. 기기 환경설정 및 관리 (`/settings`)

기기의 시스템 파라미터, Wi-Fi 네트워크, 모터 안전 한계치, 센서 감도 등을 통합 관리하는 페이지입니다.

### 10.1 팬 모터 안전 듀티 설정
연결된 팬 모터의 하드웨어 특성에 맞추어 모터 수명을 보호하고 최적의 회전을 보장합니다:
- **최소 기동 듀티 (Start Percent Min)**: 팬 날개가 멈춤 없이 안정적으로 회전하기 시작하는 최소 전압값 (기본 18%).
- **안심 상한 듀티 (Comfort Percent Max)**: 일상 자연풍 모드에서 허용할 최대 팬 속도 (기본 65%).
- **하드웨어 최대 한계치 (Hard Percent Max)**: 수동 풀파워 모드 시 도달할 수 있는 절대 상한선 (기본 90%).

### 10.2 설정 저장(`Save`)과 재적용(`Reload`)의 차이점 (중요)
Smart Nature Wind는 플래시 메모리(LittleFS)의 무결성과 수명을 극대화하기 위해 **메모리(RAM) 즉시 반영**과 **디스크(Flash) 영구 저장**을 체계적으로 분리하여 관리합니다.

- **메모리 패치**: 웹 화면에서 슬라이더나 모드를 바꿀 때는 플래시 수명을 아끼기 위해 **메모리에만 즉시 반영**됩니다.
- **`설정 저장 (POST /config/save)`**: 수정한 설정을 전원이 꺼져도 유지되도록 LittleFS 파일시스템에 영구 기록합니다.
- **`설정 재로드 (POST /reload)`**: 수정한 내용이 마음에 들지 않아 취소하고 싶거나, 디스크에 저장된 최신 원본 설정 파일로 시스템 전체를 초기화할 때 사용합니다.

> ⚠️ **주의 (골든 룰)**:  
> 설정을 변경한 뒤 기기를 껐다 켜도 계속 유지하고 싶다면, **반드시 `설정 저장` 버튼을 먼저 누른 후 재로드**해야 변경 사항이 보존됩니다!

## 11. 무선 펌웨어 업데이트 (OTA, Over-The-Air)

컴퓨터에 케이블을 연결하지 않고도 웹 브라우저를 통해 최신 펌웨어로 업그레이드할 수 있습니다.

1. 최신 펌웨어 파일(`firmware.bin`)을 다운로드하여 준비합니다.
2. 브라우저에서 **`System (설정)`** 페이지 하단의 **펌웨어 업데이트 (OTA)** 섹션으로 이동합니다.
3. 보안을 위해 설정된 **관리자 API 키**가 있다면 입력합니다.
4. **`파일 선택`** 버튼을 눌러 `firmware.bin` 파일을 지정하고 **`업데이트 시작`**을 클릭합니다.
5. 업로드 프로그레스 바가 100%에 도달하면 기기가 안전하게 검증 후 자동으로 재부팅됩니다 (약 15~30초 소요).

> ⚠️ **주의**: 업데이트가 진행되는 동안에는 기기 전원을 절대 끄지 마세요.

## 12. 자주 묻는 질문 (FAQ) 및 문제 해결

### Q1. 선풍기 날개가 돌지 않아요.
- **원인 1**: 설정된 모드가 `IDLE(정지)`이거나 타이머로 꺼진 상태일 수 있습니다. 대시보드에서 `수동 시작`을 눌러보세요.
- **원인 2**: 인체 감지 절전(`MOTION_BLOCKED`)이 켜져 있고 부재 중일 수 있습니다. 센서 앞쪽에서 손을 흔들어보세요.
- **원인 3**: 팬 모터의 최소 기동 전압 부족일 수 있습니다. `설정` 화면에서 `Start Percent Min` 값을 18%에서 22%로 조금 올려보세요.

### Q2. 스마트폰에서 `192.168.4.1` 화면이 열리지 않아요.
- **점검**: 스마트폰 Wi-Fi가 **`NatureWind`**에 정확히 연결되어 있는지 확인하세요. LTE/5G 모바일 데이터가 켜져 있으면 로컬 와이파이 접속을 우회할 수 있으므로, 잠시 모바일 데이터를 끄고 시도해 보세요.

### Q3. 방에 사람이 있는데도 선풍기가 꺼져요.
- **점검**: PIR 센서의 감지 각도(약 100도)와 거리(최대 5~7m) 내에 사용자가 위치하는지 확인하세요. 의자에 앉아 거의 움직이지 않는 환경이라면 `설정`에서 모션 감지 유지 시간(`holdSec`)을 기본 120초에서 300초(5분)로 넉넉하게 늘려주세요.

### Q4. 설정을 바꿨는데 전원을 껐다 켜면 초기화돼요.
- **점검**: 웹 UI에서 옵션을 변경한 후 상단의 **`설정 저장(Save Dirty Configs)`** 버튼을 누르지 않으면 플래시 메모리에 기록되지 않습니다. 중요한 변경 후에는 꼭 저장을 눌러주세요.

### Q5. 주간 스케줄 시간에 선풍기가 안 켜져요.
- **점검**: 기기가 가정 내 Wi-Fi에 연결되어 정상적인 현재 시간을 수신했는지 확인하세요. `Info & Help` 페이지에서 현재 시각이 정상적으로 표시되고 있는지(`NTP 동기화 완료`) 점검해 주세요.
